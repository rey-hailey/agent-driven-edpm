# S01 RFP분석서

> **작성 가이드**
> - **목적**: 제안요청서(RFP)를 조항 단위로 쪼개 요구사항(RFP-001)과 평가항목(EVAL-01)을 추출하고, 우리 제품·산출물로 얼마나 충족하는지 판정해 참여 여부(Go/No-Go)를 결정합니다. S02 제안서의 목차와 분량 배분은 이 문서의 평가항목 대응표에서 나옵니다.
> - **입력**: `01.자료실/제안/`의 제안요청서·과업지시서·평가표·질의응답 공고, 과거 제안서, E00(사업 유형·역량), E06(REQ), E09(F-ID), E13(안전·개인정보 판정), [[domain/세그먼트별의사결정구조]], [[domain/학사일정]]
> - **게이트**: E00이 `done`이고 `01.자료실/제안/`에 RFP 원본이 있어야 합니다. 요구사항마다 원문 페이지·조항을 적습니다(원문 없이 기억으로 쓴 행 금지). 조달 법령·계약 방식·인증 요건은 원문 또는 공식 출처로 확인 전까지 `[확인 필요]`로 둡니다.
> - **검토 패널 제안**: 영업 리드, 교사 자문(교육 현장 적합성), 법무(계약·개인정보 위탁), 마케팅(차별성 메시지)
> - **스킬**: `/edpm-doc proposal S01` — RFP 원본을 읽어 추출표 초안을 만들고, 사람이 충족도와 Go/No-Go를 판정합니다.
> - 예시 행은 가상 사업 "OO교육청 기초학력 향상 지원 플랫폼 운영 사업 (가상)"에 샘플 제품 '매스핏'(중학생 만 12~15세 수학 오답 코칭, AI 오답 해설)으로 참여하는 상황입니다. 실제 공고가 아닙니다.

## 2. 요구사항 추출표

유형: 기능 / 성능 / 보안 / 개인정보 / 교육내용 / 운영 / 산출물. 충족도: 충족 / 부분 / 개발필요 / 불가. "개발필요"는 E15 일정에, "불가"는 Go/No-Go와 Q&A에 반드시 반영합니다.

| ID | 원문 (페이지·조항) | 요구 내용 | 유형 | 대응 F-ID / E-doc | 충족도 | 대응 전략 |
|----|------------------|----------|------|-----------------|:---:|----------|
| RFP-001 | {p. / 조항} | {} | {} | {F-xxx, Exx} | {} | {} |
| 예시: RFP-001 | p.12 / 3.2.1 학습 지원 기능 | 학생 오답에 대해 단계별 해설을 제공하고 교사가 학급 단위로 오류 유형을 확인할 수 있을 것 | 기능 | F-012 (AI 오답 해설 힌트 사다리), E09, E10 SCR-004 | 충족 | 힌트 사다리 화면과 반별 막힌 유형 요약 화면을 제안서 4장에 수록, LO-01 근거 제시 |

> 추출 누락을 막기 위해 RFP 목차의 모든 "~할 것", "~하여야 한다", "제출" 문장을 한 행씩 옮깁니다. 행 수와 원문 문장 수를 대조합니다.

## 6. Go/No-Go 판단표

점수: 1(낮음)~5(높음). 리스크는 높을수록 감점입니다. 가중 합계가 기준 이상이고 "불가" 요구가 필수 항목에 없을 때 Go.

| 기준 | 질문 | 가중치 | 점수 | 근거 |
|------|------|:---:|:---:|------|

| 수익성 | 예산 대비 원가·인력 투입이 맞는가 | {0.2} | {} | {S03 원가 계산} |

## 교육과정 지식그래프 연결

> 국가 교육과정(2022 개정) 기반 제품일 때 작성합니다. 도구: `/edpm-curriculum`, `automation/kg/kg_query.py`. KG는 공식 자료가 아니며, 공식 관계와 권장 순서(후보)를 구분해 씁니다. KG 릴리스: {`kg_query.py stats` 결과}

- RFP의 교육과정 연계 요구(예: "성취기준 연계 콘텐츠", "기초학력 진단")를 RFP-ID로 뽑고, `kg_query.py coverage`·`export` 결과로 충족도를 판단합니다.
- 평가항목에 "교육과정 적합성"이 있으면 EVAL 대응표에 정합표 경로를 적습니다.

## 완료 체크리스트

- [ ] RFP 원본이 `01.자료실/제안/`에 있고 기본정보 모든 행에 원문 위치가 있다
- [ ] "~할 것" 문장 수와 RFP 행 수를 대조해 누락이 없다
- [ ] 모든 RFP 행에 유형, 대응 F-ID/E-doc, 충족도, 대응 전략이 있다
- [ ] 평가항목 배점 합계가 원문과 일치하고 EVAL마다 S02 담당 장이 지정되었다
- [ ] 교육 분야 특유 요구(개인정보 위탁, 선정 기준, 접근성, 보안 인증, 연수·운영)를 모두 판정했다
- [ ] 계약 방식·인증·조달 법령 관련 내용에 출처가 있거나 `[확인 필요]`가 붙어 있다
- [ ] Go/No-Go 판정과 결정자·결정일이 기록되었다
- [ ] Q&A 질의가 마감 전에 제출되고 답변이 반영되었다
- [ ] (교육과정 연계 요구가 있으면) 커버리지 결과로 충족도를 판단했다
