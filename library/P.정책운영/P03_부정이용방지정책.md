# P03 부정이용방지정책

> **작성 가이드**
> - **목적**: 계정 공유, 대리 수강, 진도 조작, 시험 부정, 콘텐츠 유출 같은 부정 이용을 정의하고, 탐지 신호(E12 이벤트), 통제 수단, 단계별 대응, 오탐 이의 제기 절차를 정합니다. 탐지 데이터가 개인정보 처리이므로 E13과 함께 봅니다.
> - **입력**: L03(진도율·수료 규칙), L04(시험 운영·감독), E12(이벤트·로그), E13(개인정보 영향), P01(제재 시 환불), [[domain/부정수강방지]]
> - **게이트**: 기본 게이트(L03, L04 `done`). 사업주 환급 과정을 운영하면 본인 확인·부정 수강 관리 요건 충족 여부가 출시 조건이 됩니다 [확인 필요]. 탐지 로그 수집 항목은 E13 체크리스트에 반영되어야 합니다.
> - **적용 유형**: AT01·AT02·AT03·AT08·AT09 (수료·자격 연계), AT04 (대리 출석), AT07 (계정 공유)
> - **검토 패널 (권장)**: 운영 리드, 개인정보 보호책임자, 법무, CS 리드, 보안 담당, (환급 과정) 기업교육 운영 담당
> - **스킬**: `/edpm-doc policy P03`
> - **주의**: 이 문서는 법률 자문이 아닙니다. 환급 과정 본인 확인 요건, 위치·기기 정보 수집 근거는 `[확인 필요]`로 두고 법무·개인정보 보호책임자 검토를 받습니다.
> - 표의 예시 행은 샘플 서비스 **스킬업**(성인 대상 VOD + 라이브 강의 마켓플레이스, 강사 입점·수익배분, 기업 B2B 좌석, 일부 사업주 환급 과정) 기준입니다.

## 4. 단계별 대응

| 단계 | 조건 | 조치 | 통지 | 승인 |
|------|------|------|------|------|
| 0 관찰 | 신호 1회 | 기록만 | 없음 | 자동 |

## 완료 체크리스트

- [ ] 위협마다 탐지 신호와 통제 수단이 하나 이상 연결되었다
- [ ] 탐지 신호가 E12 이벤트와 SQL 경로로 계산 가능하다
- [ ] 단계별 대응에 통지·승인 주체가 있고 자동 정지가 없다
- [ ] 오탐 소명 경로와 처리 기한이 P05와 일치한다
- [ ] 수집 항목이 E13 체크리스트에 반영되고 보존 기간이 정해졌다
- [ ] 환급 과정 본인 확인 요건 `[확인 필요]`가 법무 검토를 거쳤다 (해당 시)
- [ ] 제재 시 환불 처리가 P01과 충돌하지 않는다
