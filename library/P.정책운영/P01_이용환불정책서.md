# P01 이용·환불정책서

> **작성 가이드**
> - **목적**: 상품 유형별 청약철회·환불 기준, 쿠폰·번들·구독 처리, 약관·결제 화면 반영 범위를 정합니다. CS 응대(P05), 강사 정산(S07)의 환불 차감 기준이 됩니다.
> - **입력**: E06(판매 상품·결제 구조), S03(가격·할인), L03(진도율·수강 기간 정의), L01(번들·트랙 구성), [[domain/환불정책]], `02.wiki/market/` 경쟁사 환불 정책 (verified 180일 이내)
> - **게이트**: **G-POLICY** — 유료 판매·구독 서비스면 이 문서가 `done`이어야 E18을 완료할 수 있습니다. **실체 검증**: 환불 계산 예시(진행률·경과일별)가 3절 표와 4절 스크립트로 재현 가능해야 하고, 5절 법령 근거에 `[확인 필요]`가 남아 있으면 `done` 처리할 수 없습니다.
> - **적용 유형**: AT01·AT02·AT03·AT04·AT06·AT07·AT08·AT09 중 유료 판매가 있는 경우. 무상 공교육(AT05 B2G)은 계약서로 대체하고 `n/a` 사유를 적습니다.
> - **검토 패널 (권장)**: 법무, CS 리드, 운영 리드, 재무(환불 회계·정산), 결제 담당(PG·앱스토어)
> - **스킬**: `/edpm-doc policy P01` — 법령 확인 목록을 만들고 4절 스크립트로 환불 매트릭스를 생성합니다.
> - **주의**: 이 문서는 법률 자문이 아닙니다. 법령 조항·기간·비율은 모두 `[확인 필요]`로 두고 법무가 현행 법령을 확인한 뒤 바꿉니다. 아래 예시의 기준값(7일, 10%, 50%)은 형식을 보여주는 `[가정]`이며 법정 기준이 아닙니다.

## 4. 계산 스크립트 (재현 가능)

경로: `automation/scripts/P01_환불계산.py` (사람 승인 후 저장). 출력은 `05.outputs/P01_환불매트릭스_YYYYMMDD_HHMM.csv`.

```python
# 스킬업 VOD 단건 예시 규칙 — 모든 기준값은 [가정]. 법무 검토 후 확정한다.
PAID, PERIOD = 200_000, 100          # 실결제액(쿠폰 차감 후), 수강기간(일)
FULL_DAYS, FULL_PROG = 7, 0.10       # 전액 환불 구간
CUTOFF = 0.50                        # 진행률·경과비율 중 하나라도 이 이상이면 환불 0

def refund(paid, period, days, prog):
    if days <= FULL_DAYS and prog <= FULL_PROG:
        return paid
    used = max(prog, days / period)
    if used >= CUTOFF:
        return 0
    return int(paid * (1 - used)) // 10 * 10   # 10원 미만 절사

for p in [0.0, 0.05, 0.30, 0.60]:
    print(f"{p:.0%}", [refund(PAID, PERIOD, d, p) for d in [3, 10, 30, 50]])

# 번들: 정가 비율로 실결제액 안분 후 강의별 계산
bundle_paid, list_prices = 150_000, [100_000, 100_000]
share = [bundle_paid * lp // sum(list_prices) for lp in list_prices]
print("bundle", share, refund(share[0], PERIOD, 10, 0.30) + refund(share[1], PERIOD, 10, 0.0))
# 기대 출력: 0% [200000, 180000, 140000, 0] / 5% 같음 / 30% [140000, 140000, 140000, 0]
#           60% [0, 0, 0, 0] / bundle [75000, 75000] 120000
```
