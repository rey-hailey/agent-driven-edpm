# N02 사업타당성·투자심의서

> **작성 가이드**
> - **목적**: 탐색 심사를 통과한 기회에 대해 "얼마를, 어떤 단계로, 어떤 조건에서 투자할지"를 경영진이 결정할 수 있게 합니다. 시장 규모 근거, 수익 모델과 손익 시나리오, 단계별 투자·인력 계획, 리스크와 대안을 담고 진행/보류/중단을 요청합니다.
> - **입력**: N01(기회 가설·HY·탐색 결과), E04 시장·정책분석(규모·경쟁·규제·시즌), S06 수익모델설계서(RV·단위 경제성), E03 현장리서치(탐색 인터뷰), `02.wiki/company/`(원가·인건비 기준), [[domain/에듀테크수익모델]], [[domain/아동개인정보보호]]
> - **게이트**: N01·E04·S06이 `done`이어야 합니다. 모든 수치는 6절 계산표·스크립트로 재현 가능해야 하며 LLM 추정치는 쓸 수 없습니다. 입력값마다 출처 또는 `[가정]`을 붙이고, 손익은 반드시 하방 시나리오를 포함합니다. 투자 승인은 "전액"이 아니라 다음 단계(검증)까지의 예산과 다음 게이트 기준으로 요청합니다. 실제 재무 수치는 `02.wiki/company/`에만 둡니다.
> - **독자**: 경영진·투자심의. 1절 한 장으로 결정할 수 있어야 하고 2~8절은 근거입니다.
> - **검토 패널 제안**: 경영진, 재무, 법무·개인정보 담당, 교육 전문가, 기존 사업 리더(자원 충돌 확인)
> - **스킬**: `/edpm-doc venture case`
> - 예시 행은 가상 신사업 **리딩버디**(유아 영어 리딩 신규 앱 — 만 5~9세, 가정 구독 + 영어학원 B2B2C, AI 음성 리딩 피드백) 기준이며 **모든 수치는 형식을 보여주는 [가정] 값**입니다.

## 6. 재현 가능한 계산표

경로: `automation/scripts/N02_손익시나리오.py` (사람 승인 후 저장). 출력은 `05.outputs/N02_손익시나리오_YYYYMMDD_HHMM.csv`.

입력 변수(가격은 S06 RV, 변동비율은 스토어·PG·AI 호출 단가, 고정비는 4절)마다 출처나 `[가정]`을 주석으로 답니다.

```python
# 리딩버디 예시 변수 — 모두 [가정]
price_b2c, price_seat = 15_000, 6_000          # 월 구독료, 학원 좌석 월 단가
vc_b2c, vc_b2b = 0.35, 0.15                    # 변동비율 (스토어·PG·음성 AI 호출)
fixed = 1_340_000_000                          # 연 고정비
scenarios = {"downside": (4_000, 3_000), "base": (8_000, 6_000), "upside": (12_000, 9_000)}
for name, (subs, seats) in scenarios.items():
    rev = subs * price_b2c * 12 + seats * price_seat * 12
    cm = subs * price_b2c * 12 * (1 - vc_b2c) + seats * price_seat * 12 * (1 - vc_b2b)
    print(f"{name:8s} rev={rev/1e8:6.2f}억 cm={cm/1e8:6.2f}억 op={(cm-fixed)/1e8:6.2f}억 BEP배수={fixed/cm:.2f}")
print(f"top-down SAM={1_700_000*0.5*0.2*180_000/1e8:.0f}억 "
      f"bottom-up B2B2C={2_000*60*0.3*price_seat*12/1e8:.1f}억")
# 기대 출력:
# downside rev=  9.36억 cm=  6.52억 op= -6.88억 BEP배수=2.06
# base     rev= 18.72억 cm= 13.03억 op= -0.37억 BEP배수=1.03
# upside   rev= 28.08억 cm= 19.55억 op=  6.15억 BEP배수=0.69
# top-down SAM=306억 bottom-up B2B2C=25.9억
```
