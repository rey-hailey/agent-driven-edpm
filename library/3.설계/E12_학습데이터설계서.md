# E12 학습데이터설계서

> **작성 가이드**
> - **목적**: 어떤 학습 이벤트를 어떤 형식으로 남기고, 그것이 E07 지표로 어떻게 계산되며, 누가 볼 수 있고 언제 지우는지를 정합니다.
> - **입력**: E07 성과지표체계(M), E09 기능·권한 매트릭스, [[domain/학습분석지표]], [[domain/상호운용표준]], [[domain/아동개인정보보호]]
> - **게이트**: DATA 모듈. 이 문서의 수집 항목·보존·제3자 제공은 E13 (a) 개인정보 점검의 입력입니다(E12 → E13 해당 시). 지표 계산은 SQL·스크립트로만 하며 LLM이 수치를 추정하지 않습니다.
> - **검토 패널 (권장)**: 데이터 엔지니어, 개인정보 보호책임자, 교사 1명(교사 화면에 무엇이 보여야 하는지), 연동 기관 담당(학교·LMS)
> - 표의 첫 행은 예시 제품 **매스핏**(중학생 수학 오답 코칭, 학원 B2B2C + 학부모 결제) 기준입니다.

## 1. 데이터 원칙

| 원칙 | 이 제품의 적용 |
|------|----------------|
| 목적이 있는 것만 수집 | 모든 이벤트는 E07 지표 또는 E09 기능 동작에 쓰인다. 쓰임이 없는 이벤트는 수집하지 않는다 |
| 학습 데이터와 식별 정보 분리 | 식별 정보(이름, 연락처)는 계정 DB, 학습 이벤트는 가명 learner_key로만 저장 |
| 계산은 코드가 | 정답률·숙달·지표는 SQL로 계산하고 경로를 남긴다 |
| 보는 사람을 최소로 | 교사는 담당 반, 보호자는 자녀, 기관은 집계만 |

## 4. 데이터 모델 (주요 엔티티)

```mermaid
erDiagram
    LEARNER ||--o{ ENROLLMENT : has
    CLASS ||--o{ ENROLLMENT : has
    TEACHER ||--o{ CLASS : teaches
    GUARDIAN ||--o{ LEARNER : "consents for"
```

| 엔티티 | 핵심 필드 | 식별 정보 포함 | 비고 |

| learner | learner_key, 학년, 생년월(나이 판정용), 계정 상태 | 계정 DB에만 | 이름·연락처는 별도 테이블 |

| class | class_key, 기관, 과정 기간, 상태(운영/종료) | 아니오 | |
| enrollment | learner_key, class_key, 시작일, 종료일 | 아니오 | 반 편성 변경 이력 보존 (E09 4절) |
| item | item_id, 메타데이터 (E11 2절) | 아니오 | |
| attempt | learner_key, item_id, 시도 번호, 정오, 단계, 힌트 단계 | 아니오 | EV-04 정규화 |
| mastery | learner_key, skill, 상태, 판정 규칙 버전, 판정일 | 아니오 | 규칙 바뀌면 버전 올림 |

## 6. 동의 플래그

| 플래그 | 의미 | 기본값 | 꺼지면 | 근거 |

## 교육과정 지식그래프 연결

> 국가 교육과정(2022 개정) 기반 제품일 때 작성합니다. 도구: `/edpm-curriculum`, `automation/kg/kg_query.py`. KG는 공식 자료가 아니며, 공식 관계와 권장 순서(후보)를 구분해 씁니다. KG 릴리스: {`kg_query.py stats` 결과}

| 이벤트 | 교육과정 맥락 필드 | 용도 |
|--------|--------------------|------|
| {EV-0x} | `standard_code`, `kg_standard_id`, (선택) `kg_topic_id` | 성취기준별 숙달·정답률 집계 (SQL) |
| 예시: EV-04 attempt_submitted | standard_code=[9수02-04], kg_standard_id=kr.standard.2022.middle.d93c… | M-01을 성취기준별로 분해 |

- xAPI를 쓰면 성취기준을 `context.extensions`에 넣습니다.
- 문항 메타데이터(E11)와 같은 코드 체계를 씁니다. 코드 의미 변경(KG 갱신)에 대비해 KG 릴리스를 함께 저장합니다.

## 완료 체크리스트

- [ ] 모든 EV가 E07 지표 또는 E09 기능에 연결된다 (목적 없는 수집 없음)
- [ ] 이벤트 공통 필드에 consent_state와 ai_involved가 있다
- [ ] 모든 북극성·핵심 지표의 계산 정의와 SQL 경로가 있다
- [ ] 학습 이벤트에 이름·연락처 등 식별 정보가 직접 들어가지 않는다
- [ ] 상호운용 표준 표의 "해당 시" 열이 채워졌다
- [ ] 동의 플래그, 열람 권한, 보존·삭제 정책이 E13 (a)로 전달되었다
- [ ] 교사가 담당 반 외 학생 데이터를 볼 수 없다
- [ ] 법정 기한 관련 `[확인 필요]` 항목을 법무에 넘겼다
- [ ] (교육과정 기반이면) 학습 이벤트에 성취기준 코드와 KG ID가 포함된다
