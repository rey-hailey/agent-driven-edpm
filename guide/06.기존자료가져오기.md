# 기존 자료·진행 중 프로젝트 가져오기

회사에 이미 쌓인 문서(Confluence, Notion, Google Drive, Jira, 다른 PM 템플릿으로 만든 기획서)나 진행 중인 프로젝트를 EdPM 워크스페이스로 옮기는 방법입니다.

## 1. 원칙

- **옮기는 것이 아니라 근거로 삼는 것입니다.** 기존 문서는 `01.자료실/`에 원본으로 두고, 내용은 위키 페이지로 흩어 정리합니다. 산출물은 위키를 근거로 새로 씁니다.
- **회사 시스템이 기준이면 링크만 둡니다.** 개발팀 문서처럼 계속 회사 시스템에서 갱신되는 문서는 복사하지 말고 `02.wiki/company/`에 링크와 요약만 둡니다. 해당 B 트랙 산출물은 `n/a`로 둡니다.
- **개인정보·기밀 규칙은 그대로 적용됩니다.** 내보내기 파일에 학생 명단, 상담 기록, 고객 단가가 섞여 있으면 비식별화하거나 빼고 넣습니다.

## 2. 출처별 방법

| 출처 | 내보내기 | 자료실 위치 |
|------|----------|-------------|
| Confluence·Notion | 페이지를 Markdown 또는 PDF로 내보내기 | 성격에 따라 회사/, 기술/, 제안/ |
| Google Drive (문서·슬라이드) | PDF 또는 docx로 내려받기, 또는 Drive 연결 도구로 읽기 | 회사/, 제안/, 콘텐츠/ |
| Jira·Linear | 이슈 CSV 내보내기 (집계용) | 데이터/ |
| 분석 도구 (Amplitude, GA 등) | 집계 CSV 내보내기 | 데이터/ |
| 다른 PM 템플릿의 기획서·보고서 | 파일 그대로 | 회사/ (기획서), 회의/ (회의록) |
| 과거 제안서·RFP | PDF | 제안/ |
| 고객 VOC·CS 기록 | 비식별화한 요약본 | 현장/ |

## 3. 절차

1. **목록 만들기**: 가져올 문서를 표로 정리합니다 (제목, 출처, 기준 시스템 여부, 개인정보 포함 여부).
2. **inbox에 넣기**: 비식별화가 끝난 파일만 `00.inbox/`에 넣습니다.
3. **ingest**: `/edpm-ingest`로 하나씩 처리합니다. 기존 기획서 하나가 보통 위키 페이지 5~15개(페르소나, 경쟁사, 기능 결정, 지표 정의)로 흩어집니다.
4. **빈자리 확인**: `/edpm-lint`로 비어 있는 산출물을 봅니다. 기존 문서에서 흔히 비어 있는 것:

   | 자주 비어 있는 것 | 이유 | 먼저 할 일 |
   |-------------------|------|------------|
   | E02 이해관계자 구분 | 사용자와 구매자를 나누지 않음 | `/edpm-doc E02` |
   | E05 학습 성과 | 기능 목록에서 시작함 | `/edpm-doc E05` 후 기존 기능을 LO에 연결 |
   | E07 학습 효과 지표 | 참여·매출 지표만 있음 | `/edpm-doc E07` 진단판 |
   | E13 안전 평가 | 출시 직전에 체크리스트로만 처리 | `/edpm-doc E13` |
   | M03 위험대장 | 위험이 회의록에 흩어져 있음 | `/edpm-report M03` |

5. **진행 중인 일 이어받기**: 이미 끝난 일은 산출물을 `done`으로 두되 근거 문서를 `sources`에 적고, 기존 일정은 `/edpm-wbs create`로 M02에 옮깁니다.

## 4. 기존 번호 체계와 대응

다른 템플릿의 산출물 번호를 쓰던 팀이라면 아래처럼 대응시켜 `02.wiki/company/문서대응표.md`에 남겨 두면 팀원이 헷갈리지 않습니다.

| 흔한 문서 | EdPM |
|-----------|------|
| PRD, 서비스기획서 | E01, E02, E06 |
| 요구사항정의서 | E06 |
| 기능명세서 | E09 |
| 정보구조도, 화면설계서 | E10 |
| 시장조사 | E04 |
| 착수보고서, WBS, 주간·중간·완료보고서 | M01, M02, `/edpm-weekly`, M04, M05 |
| 시스템·API·DB·인프라·디자인 문서 | B01~B05 |
| 테스트 시나리오·결과 | B06, B07 (기능) / E16, E17 (학습 효과·파일럿) |
| 제안서, 견적서 | S02, S03 |
| AI 기획·RAG·프롬프트·평가 문서 | E14, A01~A06 |
