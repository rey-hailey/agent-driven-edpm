# AT04 라이브 클래스·튜터링

## 1. 정의와 예

강사·튜터가 실시간으로 가르치는 수업을 매칭·예약·진행·정산하는 서비스입니다. 상품의 단위가 콘텐츠가 아니라 **수업 시간(세션)**이라서 공급(튜터 시간표)과 수요(학습자 예약)를 맞추는 운영이 핵심입니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 1:1 매칭 | 학습자가 튜터를 고르고 회차 예약 | 화상 과외·어학 튜터 마켓형 |
| 소그룹 라이브 | 정원 4~10명, 정기 반 운영 | 소그룹 화상 수업형 |
| 대형 라이브 | 웨비나형 강의 + 채팅·퀴즈 | 라이브 특강형 |
| 질의응답 튜터링 | 문제 사진 업로드 → 튜터 풀이 | 문제 풀이 질의응답형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 학습자 (성인 또는 미성년) | 나에게 맞는 튜터, 원하는 시간 |
| 결제자 | 성인은 본인, 미성년은 보호자 | 회차당 가치, 노쇼·환불 기준 |
| 의사결정자 | 보호자(미성년), 학습자(성인). 체험 수업이 결정 | 튜터 신뢰(경력·후기·검증) |
| 공급자 | 튜터·강사 (프리랜서 다수) | 안정적 예약, 빠른 정산, 공정한 평가 |
| 운영 | 매칭 매니저, 품질 관리, CS | 노쇼·분쟁 최소화 |

미성년 대상이면 보호자를 결제자·의사결정자로 두고 수업 모니터링·안전 요구를 E02에 적습니다 ([[domain/세그먼트별의사결정구조]]).

## 7. 규제·리스크 포인트

- **미성년 보호**: 튜터 신원·범죄경력 확인 가능 범위와 절차 [확인 필요], 1:1 수업 녹화·모니터링 정책, 보호자 동의 ([[domain/아동개인정보보호]]).
- **학원법·개인과외교습**: 교습 형태에 따라 신고·교습비 게시·반환 기준이 적용될 수 있음 [확인 필요].
- **영상·음성 데이터**: 녹화 고지·동의, 보관 기간, AI 학습 이용 ([[domain/학습데이터프라이버시]]).
- **튜터 노동 형태**: 프리랜서 계약, 플랫폼 종사자 관련 규정 [확인 필요].
- **환불**: 회차권 잔여분 환불, 유효기간 만료 처리 [확인 필요]. [[domain/환불정책]]
- **AI 기본법**: 초·중등 학생의 수준 판정·평가에 AI를 쓰면 고영향 해당 검토 [확인 필요].
- **접근성**: 실시간 자막, 화면 낭독기 호환 ([[domain/접근성]]).

## 9. 자주 하는 실수

- 공급(튜터 가용 시간) 지표 없이 수요 마케팅만 해서 매칭 실패가 늘어난다.
- 노쇼·취소 규칙이 학습자 쪽만 있고 튜터 노쇼 보상이 없다.
- 체험 수업 전환율만 보고 학습 성과(레벨 변화)를 측정하지 않는다.
- 1:1 미성년 수업의 안전 정책(녹화·신고·보호자 확인)을 출시 후에 만든다.
- 회차 정산(S07)과 환불(P01)의 차감 기준이 달라 튜터 분쟁이 생긴다.
- 화상 품질 장애 시 회차 처리 규칙이 없다.
