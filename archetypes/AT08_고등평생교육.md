# AT08 고등교육·평생교육

## 1. 정의와 예

대학·원격대학·평생교육기관이 학점·학위·이수증과 연결된 과정을 온라인으로 운영하는 서비스입니다. 학사 시스템·성적·출석 규정과 맞물리고, 표준 연동(LTI·SCORM)과 크레덴셜(이수 인증)이 중요합니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 대학 LMS | 강의 운영·과제·성적, 학사 연동 | Canvas·Moodle·Blackboard형 |
| 공개 강좌 플랫폼 | 대학 강좌를 공개, 이수증 발급 | K-MOOC·Coursera·edX형 |
| 원격대학·학점 과정 | 온라인 학위·학점 인정 과정 | 사이버대·학점은행 원격과정형 |
| 평생교육 | 지자체·평생교육원 시민 강좌 | 평생학습 포털형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 대학생·성인 학습자 | 유연한 학습, 학점·이수 인정 |
| 핵심 사용자 | 교수·강사, 조교 | 강의 운영 부담 감소, 성적 처리 정확성 |
| 구매 결정자 | 대학 교무처·교수학습센터·정보화본부, 평생교육원장 | 학사 규정 준수, 연동·보안, 예산 |
| 결제자 | 대학 예산, 정부 재정지원 사업, 학습자(유료 강좌) | 조달·입찰 적합 |
| 감독 | 교육부·인증 기관 | 원격수업 운영 기준, 평가 인증 |

대학은 **입찰·정부 사업 예산**으로 사는 경우가 많고, 교수 개인의 채택 여부가 실제 사용을 결정합니다 ([[domain/세그먼트별의사결정구조]]).

## 6. 핵심 지표

| 대역 | 예시 지표 |
|------|-----------|
| M-01 북극성 | 학기 **강좌 학습 성과(평가 루브릭) 달성 학생 비율**, 공개 강좌는 이수 기준 평가 통과자 수 |
| M-1x 학습 효과 | 사전·사후 평가, 과제 루브릭 점수, 강의 평가의 학습 성과 문항 |
| M-2x 참여 | 주차별 학습 완료율, 토론 참여, 공개 강좌 등록 → 첫 주 학습 전환율 |
| M-3x 교수 도입 | 활성 강좌 비율, LMS 기능 활용 깊이, 교수 만족도 (교사 도입 대역을 교수로 읽음) |
| M-4x 사업 | 기관 계약 수·갱신율, 정부 사업 수주, 유료 이수증 전환 |
| M-9x 가드레일 | 성적 처리 오류, 학기 초 장애, 표절·부정 건수, 접근성 결함 |

공개 강좌의 낮은 이수율은 등록자 의도가 다양한 결과입니다. 의도별(이수 목표 vs 탐색)로 나눠 봅니다 ([[domain/학습분석지표]]).

## 7. 규제·리스크 포인트

- **원격수업 운영 기준**: 대학 원격수업 비율·출석 인정·평가 기준, 원격대학 설치 기준 [확인 필요].
- **학점은행·평생교육법**: 원격 평생교육시설 신고, 학점 인정 과정 평가 인정 요건 [확인 필요].
- **학생 개인정보**: 성적·출석은 민감도가 높음. 해외 서비스 연동 시 국외 이전, FERPA(미국 대학 협력 시) ([[domain/아동개인정보보호]], [[domain/학습데이터프라이버시]]).
- **시험 감독**: 웹캠·화면 감시형 감독은 개인정보 영향평가와 대체 수단 필요.
- **접근성**: 장애 학생 지원(자막·대본·시간 연장), 공공 기관 웹 접근성 ([[domain/접근성]]).
- **저작권**: 수업 목적 보상금 제도와 공개 강좌의 차이 ([[domain/교육저작권]]).
- **조달**: 대학·공공 입찰 절차, 보안 인증 요구 [확인 필요].

## 9. 자주 하는 실수

- 학사 시스템 연동(L05)을 늦게 시작해 개강 직전에 성적·명부가 맞지 않는다.
- 출석 인정 규정을 기관별로 설정할 수 없게 하드코딩한다.
- 공개 강좌 이수율만 보고 실패로 판단한다.
- 교수 강의 저작권(P02) 합의 없이 강의를 재사용·외부 공개한다.
- 시험 감독 기능을 개인정보 검토 없이 도입해 학생 반발을 산다.
- 성적 처리 기간에 배포한다.
