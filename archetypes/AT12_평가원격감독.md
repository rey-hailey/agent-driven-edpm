# AT12 평가·원격감독(Assessment·Proctoring) 벤더

## 1. 정의와 예

기관·기업·대학이 온라인 시험을 출제·시행·채점하고, 본인 확인과 화상·AI 행동분석 기반 원격 감독을 수행하도록 돕는 B2B 서비스입니다. 역량검사·인적성, 채용 평가, 대학 시험, 자격 평가를 지원하며 **평가 결과의 타당도·신뢰도와 응시 기회의 공정성**을 함께 책임집니다. 시험 합격을 위한 학습을 파는 AT09와 달리, 시험 시행 기관에 평가·감독 인프라와 운영을 제공합니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 온라인 평가 플랫폼 | 문항 은행, 시험지 편성, 응시 배정, 답안 수집, 채점·결과 배포 | 기관용 온라인 시험 시행형 |
| 원격감독 전문 | 실시간 화상 감독, 녹화 사후 검토, AI 이상 행동 탐지, 증거 검토 | 대학·자격시험 원격감독형 |
| 역량검사·인적성 | 직무·역량 구성개념에 따른 검사, 규준 비교, 기관용 리포트 | 기업 채용·임직원 역량평가형 |
| 평가·감독 API | 고객 LMS·채용 시스템에 시험·감독 기능을 연동 | 평가 엔진·감독 모듈 공급형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 응시자·지원자·학생·임직원 | 답안 보존, 공정한 평가, 불필요한 감시 최소화, 이의 제기 |
| 구매자·결제자 | 시험 시행 기관, 기업 인사·채용팀, 대학 평가·학사 부서 | 안정적 시행, 운영비 절감, 검증 가능한 결과 |

| 공급자 | 출제·검수 위원, 심리측정 전문가, 채점자, 감독 인력 | 문항 권리 보호, 일관된 기준, 안전한 증거 열람 |

구매 기관과 응시자의 이해가 다를 수 있습니다. E02에 **응시자와 최종 판정 책임자**를 따로 두고, 기관·벤더의 개인정보 처리 역할과 점수·감독 원본 열람 권한을 구분합니다 ([[domain/세그먼트별의사결정구조]], [[domain/학습데이터프라이버시]]).

L01은 강의가 아니라 시험·문항 묶음으로 읽고, 강의 제작이 없는 L02는 사유를 남겨 n/a로 둡니다. P04는 E11의 문항·정답 키·루브릭 검수에 적용합니다. 영상 분석 모델에 RAG·대화가 없으면 A01~A03을 억지로 켜지 않고, A06에 감독·채점 전용 평가셋과 재현 가능한 실행 결과를 연결합니다. A09는 학습이탈 예측이므로 부정 탐지 설계서로 바꾸어 쓰지 않습니다.

핵심 게이트는 G-LEARN·G-PII(공통), G-CAL(시험·채용·성적 확정), G-POLICY(계약·재시험·환불), G-EVIDENCE(실제 응시자 파일럿)입니다. 학생 개인정보·미성년 응시는 G-SAFE, AI 기능은 G-AI를 적용합니다.

## 6. 핵심 지표

| 대역 | 예시 지표 |
|------|-----------|
| M-01 북극성 | 사전에 정한 타당도·신뢰도 검증을 통과한 평가에서 **답안 보존·채점 검수·감독 판정 및 이의 처리 절차를 충족해 확정된 유효 평가 결과 수** (단순 응시 건수 제외) |
| M-1x 학습 효과 | 평가 목적별 타당도 근거(내용·구성개념·준거 관련), 신뢰도(내적 일관성·재검사·채점자 간 일치), 측정 표준오차, 문항 난이도·변별도·차별기능 |
| M-2x 참여 | 초대 대비 응시율, 기기 점검 통과율, 시작 대비 제출 완료율, 재접속 후 답안 복구율, 편의 제공 이용자의 완료율 |
| M-3x 출제·감독 도입 | 기관 관리자 활성률, 문항 검수 소요일, 감독관 교육 이수율, 의심 이벤트 검토 기한 준수율 (교사 도입 대역을 평가 담당자로 읽음) |
| M-4x 사업 | 기관 재계약률, 계약 대비 실제 응시량, 응시 건당 매출·원가, 감독 시간당 원가, 도입 소요일 |
| M-9x 가드레일 | 부정 탐지 오탐률·미탐률·정밀도와 집단별 차이, 이의 제기 인용률, 답안 유실률, 시험 중 가용성, 채점 정정률, 영상 무단 열람·파기 지연 |

타당도는 단일 점수가 아니라 **특정 집단·목적에서 점수를 해석하고 사용하는 근거**로 관리합니다. E05·E07에 평가별 검증 방법·허용 기준을 사전 정의하고 E16·E17에서 확인합니다. 역량검사 점수를 학습 효과나 채용 성과의 인과적 증거로 바꾸어 읽지 않습니다 ([[domain/과제와평가설계]], [[domain/학습분석지표]]).

오탐률은 `정상 응시 중 부정으로 탐지된 건 / 정상 응시 전체`, 미탐률은 `실제 부정 중 놓친 건 / 실제 부정 전체`로 정의합니다. 독립 검토로 라벨링한 탐지·비탐지 표본을 함께 평가하고, 의심 이벤트 단위와 응시자 단위, AI 탐지와 기관 최종 판정을 분리합니다. 이의 제기 인용률만으로 전체 오탐률을 대신하지 않습니다.

## 7. 규제·리스크 포인트

- **생체·영상 개인정보**: 웹캠 영상·음성·신분 확인 자료와 개인 식별 목적의 얼굴 특징정보를 구분합니다. 생체인식정보의 민감정보 해당성, 별도 동의 등 처리 근거, 최소 수집·보관·파기 요건은 개인정보 보호법·시행령과 개인정보보호위원회 생체정보 보호 가이드라인으로 대조 [확인 필요]. 모든 얼굴 영상을 일괄적으로 생체인식 민감정보라고 단정하지 않습니다 ([[domain/학습데이터프라이버시]], [[domain/AI개인정보보호]]).
- **기관·벤더 책임**: 위탁·제3자 제공·재위탁, 기관별 접근 권한, 국외 클라우드·AI API 이전, 계약 종료 시 반환·파기를 구분합니다. 법정 보존 기간·침해 통지 기한 등 법령 수치는 [확인 필요]. 시험 응시 동의를 모델 학습·상품 개선 동의로 대신하지 않습니다 ([[domain/학습데이터프라이버시]]).
- **AI 감독의 공정성·오탐**: 장애·보조공학, 피부색·조명·안경, 기기·통신·주거 환경에 따른 오류를 검증합니다. 시선 이탈·움직임을 곧바로 부정으로 확정하지 않고 사람 검토·소명·대체 감독을 둡니다. 차별·접근성 관련 법적 의무와 적용 범위는 [확인 필요] ([[domain/AI가드레일설계]], [[domain/접근성]]).
- **자동화된 결정**: 자동 채점·부정 판정이 응시자 권리·의무에 미치는 영향, 완전 자동화 여부에 따라 거부·설명·검토 요구의 적용과 예외를 검토 [확인 필요]. P03·P05에 사람 재검토, 판정 근거 안내, 결과 정정 흐름을 둡니다 ([[domain/학습데이터프라이버시]]).
- **AI 기본법 고영향 AI**: 채용 등 개인의 권리·의무에 중대한 영향을 미치는 판단·평가와 유아·초등·중등교육의 학생 평가는 고영향 해당성 검토 대상입니다. 대학 시험·일반 역량검사·감독 보조까지 일률적으로 해당한다고 단정하지 않고, 사용 목적·영향·실질적 판정 관여도와 생체인식 용도를 확인합니다. 해당성 확인 절차, 사전 고지·설명·위험관리·사람 감독·문서화 의무 및 시행령·고시의 적용은 [확인 필요]. E13·E14·A14·P07·P08과 G-AI에 반영합니다 ([[domain/AI가드레일설계]], [[domain/AI윤리정책]]).
- **문항·검사 권리와 평가 주장**: 기출·외부 문항·규준·검사 도구의 이용 허락, AI 생성 문항의 검수·표시, 타당도·신뢰도·부정 탐지 성능 광고의 근거를 구분합니다. 적용 법령·표시 요건은 [확인 필요] ([[domain/교육저작권]], [[domain/문항자동생성]]).
- **응시 기회·장애 대응**: 시간 연장·화면 낭독·카메라 사용 대안, 네트워크 장애 시 재접속·재시험·비용 부담을 사전에 정합니다. 미성년 응시의 동의 요건·연령 수치와 기관별 시험 규정은 [확인 필요] ([[domain/접근성]], [[domain/아동개인정보보호]]).

## 9. 자주 하는 실수

- AT09의 합격 대비 지표를 가져와 응시자의 학습 향상과 평가 도구의 측정 품질을 혼동한다.
- AI 의심 점수를 부정 확정으로 쓰고 사람 검토·소명·재심을 생략한다.
- 전체 정확도만 보고 정상 응시자의 오탐률, 집단별 차이, 비탐지 표본의 미탐을 보지 않는다.
- 영상·신분증·얼굴 특징을 한 동의·한 보관 기간으로 묶고 모델 학습에 재사용한다.
- 검사 타당도를 다른 직무·연령·기관에 그대로 일반화하거나 규준 표본·버전을 남기지 않는다.
- 답안 저장·제출 확인·재접속을 검증하지 않은 채 최대 동시 접속 수만 홍보한다.
- 고객 기관이 최종 판정 책임을 지는지, 벤더가 어디까지 검토·설명하는지 계약과 화면에서 다르게 쓴다.
- 시험 직전에 문항·정답 키·판정 임계값·모델을 바꾸어 결과 비교와 재현이 불가능해진다.
