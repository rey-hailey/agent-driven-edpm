# AT13 LXP·스킬 인텔리전스

## 1. 정의와 예

기업의 내·외부 학습 콘텐츠를 모아 임직원이 필요한 학습을 탐색하고, 직무·목표 스킬에 맞는 콘텐츠와 개인화 학습경로를 추천받는 기업 학습경험플랫폼(LXP)입니다. 스킬 택소노미·스킬 그래프로 사람·직무·콘텐츠를 연결하고, 재직자 역량개발과 커리어·인재개발을 지원합니다. 한국 기업 HRD의 연간 교육 예산으로 좌석·활성 사용자·기업 단위 구독을 계약하며, HRIS·LMS와 연동하는 형태를 기준으로 합니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 콘텐츠 애그리게이션형 | 사내 자료·외부 구독 콘텐츠를 통합 검색·추천, 원 제공처에서 학습 | 기업 통합 학습 포털형 |
| 스킬 기반 학습경로형 | 직무별 목표 스킬과 개인의 역량 차이를 연결해 학습경로 구성 | 재직자 업스킬·리스킬 플랫폼형 |
| 커리어·인재개발형 | 희망 직무·사내 기회에 필요한 스킬과 개발 활동 연결 | 사내 경력개발·인재 이동 지원형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 임직원 학습자 | 업무·희망 커리어에 맞는 학습 발견, 역량개발 기회 |
| 구매자·운영 사용자 | 기업 HRD·인재개발 담당자 | 콘텐츠 활용, 직무별 스킬 격차 파악, 개발 계획 운영 |

| 결제자 | 회사 교육·인재개발 예산 | 연간 구독, 좌석·사용량 기준과 갱신 조건의 명확성 |
| 현업 관리자 | 팀장·직무 전문가 | 팀의 목표 스킬, 개발 활동과 현업 적용 확인 |

E02에서 **학습자·HRD·현업 관리자·IT 보안의 성공 기준을 분리**합니다. 구매자의 스킬 현황 리포트 요구와 학습자의 자율 탐색·커리어 정보 공개 범위를 함께 정합니다 ([[domain/세그먼트별의사결정구조]]).

**AT02 LMS는 배정·마감·이수·증빙이 중심이고, AT13 LXP는 탐색·추천·스킬 개발이 중심**입니다. 연동형에서는 필수 교육 배정과 공식 수료 증빙은 LMS를 원장으로 두고, LXP는 이를 표시하면서 자율 학습·스킬 경로를 운영합니다. LXP의 클릭·완료·추론 스킬을 LMS의 이수·역량 인증으로 자동 승격하지 않습니다. 배정·환급·증빙까지 직접 운영하면 AT02를 조합하고, L03·L05에 원장과 책임을 명시합니다.

스킬 택소노미·추천의 **AI 방식은 기능별로 A10에서 선택**합니다. 택소노미는 전문가 승인 사전·규칙 매핑을 기준선으로 두고, NLP·임베딩으로 동의어·태깅 후보를 만들거나 LLM으로 추출 초안을 만들 때도 승인 전에는 공식 스킬 체계를 바꾸지 않습니다. 추천은 규칙·콘텐츠 기반·협업 필터링·학습 순위화와 LLM 보조 방식을 비교하고, 검색 근거를 사용하는 설명·경로 생성에만 필요에 따라 RAG를 적용합니다. 추천 자체를 LLM 호출과 동일시하지 않습니다. A10에 방식별 정확도·설명 가능성·콜드스타트·지연·비용·데이터 반출 제약을 남기고, 모델을 쓰면 A11에서 평가 결과와 민감도에 따른 라우팅을 정합니다 ([[domain/모델선택과라우팅]]). AI 추천이 없는 수동 큐레이션형은 E14·A 트랙을 n/a로 두되 근거를 E00에 남깁니다.

## 6. 핵심 지표

| 대역 | 예시 지표 |
|------|-----------|
| M-01 북극성 | 분기 개발 계획 대상 재직자 중 **목표 스킬 학습경로 수행 + 평가·현업 적용 증거 확인**까지 도달한 비율 |
| M-1x 학습 효과 | 사전·사후 역량 평가 변화, 현업 적용 확인율, 스킬 커버리지(직무별 목표 스킬 중 유효한 평가·적용 증거로 목표 수준이 확인된 스킬 비율) |
| M-2x 참여 | 활성화율(초대 후 14일 내 목표 스킬 설정 + 첫 학습 시작 인원 / 초대 대상 인원), 주간 활성 학습자, 추천 적중률(추천 노출 세션 중 추천 콘텐츠 학습 시작 세션 비율), 경로 재방문율 |
| M-3x 관리자 도입 | HRD 월간 활성, 목표 스킬·콘텐츠 매핑 승인율, 팀 개발 계획 검토율 (교사 도입 대역을 HRD·현업 관리자로 읽음) |
| M-4x 사업 | 구독 갱신율, 좌석 활성률, 순매출 유지율(NRR), 고객사당 매출, 외부 콘텐츠·AI 비용 차감 후 공헌이익 |
| M-9x 가드레일 | 직무·조직별 추천 편중, 스킬 추론 정정률, 근거 만료율, 이용 권한 없는 콘텐츠 추천률, 연동 지연·누락, 개인정보 사고 |

E07에 측정 기간·대상·분모·이벤트를 고정합니다. 스킬 커버리지는 **콘텐츠가 매핑된 비율과 구분**하고, 미평가·자기신고·AI 추론만 있는 스킬은 검증된 역량에 포함하지 않습니다. 추천 적중은 클릭률과 분리하며, 시작 이후 완료·평가·현업 적용을 함께 봅니다. 초대 코호트 활성화와 유료 좌석 활용도도 별도로 계산합니다 ([[domain/학습분석지표]]).

## 7. 규제·리스크 포인트

- **임직원 개인정보**: 학습·역량·희망 직무의 수집 목적, 관리자 열람 범위, 보관·삭제와 퇴사 처리를 E13·L05에 명시합니다. 처리 근거·위탁·국외 이전 요건은 계약별 검토 [확인 필요] ([[domain/학습데이터프라이버시]]).
- **인사 활용·자동화된 판단**: 개발용 추천과 채용·배치·승진 평가를 분리하고, 스킬 추론 근거·정정·사람 검토 경로를 제공합니다. 자동화된 결정 관련 권리와 AI 관련 의무의 적용 범위는 실제 용도별 검토 [확인 필요].
- **콘텐츠 권리**: 외부 콘텐츠의 검색 색인·미리보기·추천·임베딩·AI 이용 허용 범위, 구독 만료 후 노출·접근 처리를 P02에 남깁니다 ([[domain/강사계약과콘텐츠권리]]).
- **기업 보안**: 테넌트 간 스킬·경력·콘텐츠 권한 격리, 외부 모델 전송 제한, 고객사 보안 심사·감사 로그를 E13·B04·A11에 반영합니다.
- **추천 편향·설명**: 인기 콘텐츠만 반복 노출하거나 특정 직군의 기회를 제한하지 않는지 검증하고, 추천 이유·제외·정정 경로를 둡니다.
- **접근성**: 검색·스킬 그래프·경로 편집은 키보드와 표·목록 대체 화면으로도 이용할 수 있게 설계합니다 ([[domain/접근성]]).
- **법정교육·환급**: LXP 추천이나 외부 콘텐츠 열람만으로 이수 인정·지원금 요건을 충족했다고 표시하지 않습니다. 해당 운영은 AT02 조합으로 별도 검토 [확인 필요].

## 9. 자주 하는 실수

- AT02의 배정·수료 화면만 복제하고 자율 탐색·추천·스킬 개발의 성공 기준을 정하지 않는다.
- 스킬 택소노미를 태그 목록으로 시작해 동의어·숙련도·버전·승인 책임자가 없다.
- 콘텐츠 완료나 AI 추론을 검증된 스킬로 처리해 커버리지를 부풀린다.
- 추천 클릭률만 최적화하고 학습 도달·현업 적용·직무별 노출 편향을 보지 않는다.
- 외부 카탈로그를 권한·만료 정보 없이 합쳐 구매하지 않은 콘텐츠를 추천한다.
- HRIS·LMS와 LXP의 원장·동기화 방향을 정하지 않아 퇴사자 접근권과 이수 기록이 어긋난다.
- 개발용 스킬·커리어 정보를 별도 합의 없이 인사 평가에 사용한다.
- 추천·스킬 추출을 모두 LLM으로 구현한 뒤 A10의 기준선 비교와 구독 원가 검증을 생략한다.
