# AT03 부트캠프·직무교육

## 1. 정의와 예

수 주~수 개월의 기수제 과정으로 라이브 강의, 실습, 프로젝트, 멘토링, 취업 연계를 묶어 직무 전환·역량 향상을 목표로 하는 서비스입니다. 결과(포트폴리오·취업·현업 적용)가 상품의 핵심입니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 직무 전환 부트캠프 | 풀타임·장기, 취업 연계 | 코딩·데이터 부트캠프형 |
| 정부 지원 훈련 | 국민내일배움카드·K-디지털 트레이닝 등 지원 과정 | 국비 지원 훈련기관형 |
| 재직자 파트타임 | 야간·주말, 실무 프로젝트 | 직무 심화 과정형 |
| 기업 위탁 | 신입·전환 배치 교육 | 맞춤 부트캠프형 (AT02와 결합) |

| 역할 | 누구 | 원하는 것 |

| 결제자 | 수강생 본인, 정부 지원(훈련비), 기업 | 비용 대비 결과 |
| 의사결정자 | 수강생 (후기·취업 실적·커리큘럼 비교), 지원 과정은 선발 절차 | 실패 위험 최소화 |
| 교수진 | 주강사, 보조강사(TA), 멘토, 현업 리뷰어 | 수업 준비 부담, 질문 대응 체계 |

## 6. 핵심 지표

| 대역 | 예시 지표 |
|------|-----------|
| M-01 북극성 | 기수별 **루브릭 기준을 통과한 최종 프로젝트 완성 수강생 비율** (취업률은 M-4x 결과 지표로 분리) |
| M-1x 학습 효과 | 진입·중간·최종 역량 진단 점수, 과제 루브릭 점수 향상, 코드 리뷰 지적 감소 |
| M-2x 참여 | 라이브 출석률, 주간 과제 제출률, 질문 후 해결까지 시간 |
| M-3x 교수진 | TA당 담당 인원, 피드백 기한 준수율, 강사 만족도 |
| M-4x 사업 | 모집 충원율, 중도 포기율, 수료 후 6개월 취업률(정의 공개), 추천 유입 |
| M-9x 가드레일 | 환불 분쟁, 표절 적발, 번아웃 신호(과도한 학습 시간), 취업 실적 표기 오류 |

## 7. 규제·리스크 포인트

- **정부 지원 훈련**: 훈련기관 인정, 출석률·훈련 시간·평가 요건, 훈련비 환급·부정 수급 제재 [확인 필요]. L03·P03에 반영합니다.
- **환불**: 평생교육법·학원법 적용 여부(시설 형태에 따라 다름)와 교습비 반환 기준 [확인 필요]. [[domain/환불정책]]
- **취업 실적 광고**: 산정 기준 없는 취업률 표시는 표시·광고 위험 [확인 필요].
- **소득공유형 계약**: 금융·대부 규제 해당 여부 [확인 필요].
- **생성형 AI 사용**: 과제 정책에 허용 범위와 표기 규칙. 표절 판정 절차와 이의 제기.
- **개인정보**: 채용 파트너에게 이력·포트폴리오 제공 시 별도 동의 ([[domain/학습데이터프라이버시]]).

## 9. 자주 하는 실수

- 취업률을 북극성으로 둬서 학습 설계 개선과 연결되지 않는다.
- 개강 전 실습 환경(IDE·리포지토리) 점검 없이 첫 주에 장애가 난다.
- TA 피드백 기준(루브릭)이 사람마다 달라 공정성 민원이 생긴다.
- 지원 과정 출석 요건을 운영 화면에 반영하지 않아 사후 정정이 쌓인다.
- 생성형 AI 사용 정책 없이 과제를 내 표절 판정이 자의적이 된다.
- 기수 회고(E20)를 하지 않아 같은 이탈 지점이 반복된다.
