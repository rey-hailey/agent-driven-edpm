# AT15 영유아 교육 플랫폼

## 1. 정의와 예

만 0~7세 아동의 놀이와 일상 경험을 지원하는 앱·콘텐츠, 어린이집·유치원 운영·교사 도구, 학부모 소통·알림장과 가정연계를 제공하는 플랫폼입니다. **아동의 직접 화면 사용을 전제로 하지 않으며**, 특히 영아는 보호자·교사가 도구를 사용하고 아동은 실제 놀이에 참여하는 형태를 우선합니다. 보육·유아교육 현장과 가정에서의 발달 적합성·안전이 학습량·체류 시간보다 앞섭니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 가정 놀이·콘텐츠 구독 | 보호자가 연령·흥미에 맞는 놀이를 고르고 함께 실행, 오프라인 활동 연결 | 그림책·동요·가족 놀이 구독형 |
| 기관 놀이·교사 도구 | 어린이집·유치원의 놀이 계획, 관찰 기록, 자료 준비와 학급 운영 지원 | 누리과정 연계 놀이 자료·교사 지원형 |
| 학부모 소통·가정연계 | 기관 알림장·공지·사진 공유, 가정 놀이 제안, 보호자 응답 | 어린이집·유치원 알림장형 |
| 공공 보육·유아교육 지원 | 지자체·교육청 등의 사업으로 기관·가정에 자료와 운영 도구 제공 | 공공 놀이꾸러미·가정연계 지원형 |

누리과정을 만 0~7세 전체에 일괄 적용하지 않습니다. 만 3~5세 누리과정, 만 0~2세 표준보육과정, 만 6~7세의 재원·취학 상태를 E00에서 구분하고 적용 고시·범위를 확인합니다 [확인 필요]. 초등 교과 성취·시험 대비가 중심이면 [[archetypes/AT05_K12코스웨어]], 일반 자기주도 구독 앱이 중심이면 [[archetypes/AT07_소비자학습앱]]과 경계를 정합니다.

- 모듈: CONTENT 필수(놀이·가정연계 자료) / DATA 필수(최소한의 활동·소통·동의·권한 이벤트) / SAFE 필수(아동 개인정보·안전·스크린타임) / AI 기능 시 / GTM 필수(보호자 안내·기관 도입·공공 제안)
- 교육과정 KG: 누리과정 연계 제품이면 G-CURRIC 적용 검토. 누리과정 매핑 지식·KG 지원은 신규 필요이며, 공식 근거와 조회 가능한 매핑이 확보되기 전에는 게이트 충족으로 처리하지 않음. 알림장·운영 전용이면 교육과정 KG 해당없음

기본 표는 놀이 콘텐츠·기관 소통을 함께 제공하는 형태입니다. 운영 전용이면 L01·L02와 콘텐츠 관련 항목은 범위·전제조건을 확인해 n/a 사유를 남깁니다. AI를 실제 제공하면 E14·A10·A14, 관련 A 트랙 평가(A06), P07~P09를 활성화하고 G-AI를 적용합니다. 유료·대량 AI 사용은 A12도 필수이며, 생성 알림장은 교사 승인 없이 발송하지 않습니다.

핵심 게이트는 G-SAFE, G-POLICY, G-CAL(신학기·기관 운영), G-EVIDENCE입니다. 파일럿은 아동의 직접 조작 여부에 맞춰 교사·보호자 관찰과 실제 놀이 증거를 확보합니다. G-LEARN·G-PII는 공통 적용합니다.

## 7. 규제·리스크 포인트

- **아동 개인정보·법정대리인 동의**: 만 14세 미만 아동의 개인정보를 동의 근거로 처리할 때 법정대리인 동의를 받고 동의 여부를 확인합니다. 보호자 게이트·기관 구매·교사 초대를 동의로 간주하지 않습니다. 처리 목적·최소 항목·보유 기간·철회·삭제·동의 증적을 E13에 명시하고, 적용 조문·확인 방식은 출시 전 대조합니다 [확인 필요] ([[domain/아동개인정보보호]]).
- **사진·음성·기관 권한**: 알림장 사진·영상·음성, 건강·투약 등 민감한 기록은 수집 필요성과 처리 근거를 별도 검토합니다 [확인 필요]. 기관·반·자녀별 접근 제한, 복수 보호자 권한 확인, 전반·퇴소·퇴사 시 회수, 오발송 회수·사고 통지를 설계합니다. 마케팅·모델 학습의 목적 외 이용을 기본 허용하지 않습니다 ([[domain/학습데이터프라이버시]]).
- **스크린타임**: 영아에게 직접 화면 사용을 유도하지 않고 성인용 놀이 안내를 우선합니다. 연령별 지침과 사용 맥락을 확인해 보호자 시간 설정·쉬기·종료를 제공하고 자동재생·무한 스크롤·스트릭 상실 압박을 배제합니다. 시간 수치를 만 0~7세에 일괄 적용하거나 의학적 안전 보장으로 표시하지 않습니다. 최신 권고·기관과 가정의 합산 안내 기준은 [확인 필요] ([[domain/유아초등학습UX]], [[domain/동기설계]]).
- **광고·추적·결제 제한**: 제품 원칙으로 아동 화면의 광고·행동기반 추적·구매 유도와 제3자 광고 SDK를 배제합니다. 외부 링크·구독·설정은 보호자 게이트 뒤에 두며, 이것이 법정대리인 동의를 대신하지는 않습니다. 앱 마켓 아동·가족 정책, 광고·분석 SDK 허용 범위, 국내 표시·광고 규정은 별도 확인합니다 [확인 필요] ([[domain/유아초등학습UX]]).
- **아동 안전**: 놀이 준비물의 삼킴·질식·알레르기, 신체 활동의 낙상, 감각 자극과 연령 부적합 콘텐츠를 출시 전 검수합니다. 연령·성인 동반·대체 활동 안내, 위험 콘텐츠 즉시 중단·신고·재검수 절차를 P04·P05에 둡니다. 자유 채팅·낯선 성인 접촉·아동 프로필 공개를 기본 제공하지 않습니다. 긴급 연락·인계 확인은 알림장 열람만으로 완료 처리하지 않으며 실제 기관 절차와 책임을 정합니다.
- **보육·유아교육·교육과정**: 어린이집과 유치원의 적용 제도·운영 기록·계약 요건을 구분하고, 누리과정 연계는 공식 고시·해설서와 교사 검수로 확인합니다 [확인 필요]. 교사 놀이 관찰을 진단·치료나 아동의 우열 판정으로 포장하지 않습니다. 누리과정과놀이중심설계는 신규 필요입니다.
- **AI 사용 시**: 아동과의 무제한 대화·정서적 의존·자동 발달 판정을 기본 범위에서 제외합니다. 교사용 생성물도 개인정보 입력·외부 전송·교사 승인·연령 적합성 검수를 설계하고, 학생 평가용 AI의 고영향 해당 여부와 고지·표시 의무를 검토합니다 [확인 필요] ([[domain/아동개인정보보호]]).
- **권리·환불·접근성**: 동요·그림책·캐릭터·사진의 이용 범위와 가정·기관 배포 권리를 P02에 정합니다. 보호자 대상 자동 갱신·해지·환불 고지, 기관 계약 종료 조건, 음성·자막·감각 자극 조절·장애 아동 접근성을 확인합니다 [확인 필요] ([[domain/교육저작권]], [[domain/환불정책]], [[domain/접근성]]).

## 9. 자주 하는 실수

- 만 0~7세를 같은 직접 사용 UX·세션 길이로 묶고 영아에게도 앱 접속을 요구한다.
- 누리과정을 문제풀이 진도표로 바꾸거나 만 0~2세·취학 아동까지 같은 과정으로 분류한다.
- 교사에게 관찰 기록·알림장 이중 입력을 늘리고 보호자에게 매일 수행 인증을 요구한다.
- 북극성을 시청 시간·연속 접속으로 정해 안전한 종료와 실제 놀이를 방해한다.
- 기관 계약·보호자 게이트를 법정대리인 동의로 간주하거나 형제·전반 과정에서 사진을 오공유한다.
- 아동별 점수·순위·발달 지연 추정을 보호자에게 자동 공개해 비교·불안을 유발한다.
- 생성 알림장을 교사 확인 없이 보내거나 긴급 안전 안내를 일반 푸시 도달로만 판단한다.
