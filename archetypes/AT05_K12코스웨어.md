# AT05 K-12 코스웨어

## 1. 정의와 예

초·중·고 수업 시간에 교사가 학생과 함께 쓰는 디지털 학습 서비스입니다. 국가 교육과정 성취기준에 맞춘 콘텐츠·문항, 학생 활동 화면, 교사 대시보드(수업 운영·형성평가·피드백)가 한 묶음입니다. 학교·교육청이 사고 교사가 고르며, 학생은 미성년입니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 교과 코스웨어 | 특정 과목·학년군의 개념 학습 + 문항 + 진단 | 수학·영어 AI 코스웨어형 |
| 수업 도구 | 교과 무관 퀴즈·협업·과제 도구 | Classroom·퀴즈 플랫폼형 |
| 교과서 연계 디지털 자료 | 교과서 단원 기반 디지털 교육자료 | 디지털 교과서·교육자료형 [확인 필요: 현행 법적 지위] |
| 진단·보정 | 기초학력 진단, 보정 학습 경로 | 진단·보정 플랫폼형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 학생 (만 6~18세, 만 14세 미만 포함) | 이해되는 설명, 바로 받는 피드백, 재미 |
| 핵심 사용자·선택자 | 교사 | 수업 준비 시간 절감, 수업 흐름을 깨지 않는 도구, 학생 이해도 파악 |
| 구매 결정자 | 학교장·학교운영위원회, 교육청 담당 장학사 | 교육과정 정합성, 예산 근거, 민원 없음 |
| 결제자 | 학교 운영비, 교육청 사업 예산 | 조달 절차 적합, 연간 계약 |
| 보호자 | 학부모 | 개인정보 안전, 화면 시간, 결과 공유 |
| 행정 | 정보 담당 교사, 교육청 정보화 부서 | 계정 연동, 보안, 장애 대응 |

사용자(학생)·선택자(교사)·결제자(학교)·영향자(보호자)가 모두 다릅니다. 교사 부담이 늘면 구매돼도 쓰이지 않습니다 ([[domain/세그먼트별의사결정구조]], [[domain/교사참여설계]]).

## 7. 규제·리스크 포인트

- **AI 기본법 고영향**: 초·중등 **학생 평가**(채점·성취 판정·진단)에 쓰는 AI는 고영향 AI 영역입니다. 위험관리·설명·이용자 보호 의무 세부는 시행령·고시 [확인 필요]. E13 d8·d9, E14, A06에 반영 ([[domain/아동개인정보보호]]).
- **아동 개인정보**: 만 14세 미만 법정대리인 동의, 학교 위탁 처리 구조, 국외 이전, 외부 AI API 전송 금지 원칙 ([[domain/학습데이터프라이버시]]).
- **교육부·교육청 보안 기준**: 클라우드 보안 인증·학습 데이터 보관 요건 [확인 필요].
- **조달**: 디지털 서비스 계약 경로, 학교 단위 구매 절차, 소프트웨어 품질 인증 요구 [확인 필요].
- **교육과정 적용 학년**: 2026년 기준 중3·고3은 2015 개정 ([[domain/2022개정교육과정적용일정]]).
- **저작권**: 수업 목적 이용 범위와 상업 서비스의 차이 ([[domain/교육저작권]]).
- **접근성**: 공공 납품 시 웹 접근성 준수 요구 ([[domain/접근성]]).

## 9. 자주 하는 실수

- 성취기준을 기억으로 써서 코드·학년이 틀린다 (G-CURRIC 위반).
- 교사 수업 흐름을 무시한 학생용 기능만 만든다 (교사가 쓰지 않으면 학생도 못 씀).
- 학생 개인 성취 판정 AI를 고영향 검토 없이 출시한다.
- 신학기 3월에 신규 기능을 배포하거나 교사 연수를 잡는다.
- 전환기 격차를 학생 개인의 "뒤처짐"으로 표기한다.
- 가상 데이터로만 검증하고 실제 학급 파일럿 없이 확산한다 (G-EVIDENCE).
