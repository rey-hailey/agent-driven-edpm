# AT11 온라인학위·원격교육 위탁운영(OPM)

## 1. 정의와 예

대학·교육기관의 온라인 학위과정·원격강의를 외부 벤더가 위탁 운영하는 모델입니다. OPM(Online Program Management) 벤더는 모집·마케팅·LMS 운영·학생지원·콘텐츠 제작을 맡고, 기관이 수납한 등록금을 계약 기준으로 수익배분받습니다. 입학·교육과정·평가·학위 판단은 기관 승인 영역으로 구분하고, 벤더의 운영 범위와 승인 경계를 계약에 적습니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 온라인 학위과정 통합 운영 | 과정 출시 투자부터 모집·강의 제작·학습 지원까지 운영, 등록금 수익배분 | 대학 온라인 학위 OPM형 |
| 원격대학·사이버대학 운영 지원 | 기관의 학사 체계 아래 모집 지원·LMS·콘텐츠·학생지원 업무를 위탁 | 원격대학·사이버대학 위탁운영형 |
| 대학 평생교육원 위탁 | 기관 승인 과정의 모집·콘텐츠 제작·운영을 대행, 수강료 기준 배분 | 대학 평생교육원 연계형 |
| 선택 업무 위탁 | 제작·LMS·학생지원 등 일부만 위탁, 고정비와 수익배분 혼합 | 모듈형 OPM |

공개 서비스명을 예로 들 때는 형태 설명용 범주 표시이며, 해당 서비스의 내부 계약·배분율·운영 실적을 주장하지 않습니다. 한국 적용 시 위탁 가능 업무와 수익배분 계약의 허용 범위는 기관 유형별로 확인합니다 [확인 필요]. 평생교육원 과정이 곧 학위과정인 것은 아닙니다. 단순 LMS 공급·공개 강좌 운영은 AT08, **기관과 벤더의 운영 책임·등록금 배분이 중심이면 AT11**로 봅니다.

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 재학생·성인 학습자, 지원자 | 신뢰할 수 있는 학위·이수 안내, 학습 지속, 빠른 지원 |
| 핵심 사용자 | 교수·강사·조교, 기관 학사·학생지원 담당 | 교육적 통제권, 제작 지원, 출석·성적 정확성 |
| 구매 결정자 | 대학 본부·교무처·평생교육원장, 계약·재무 담당 | 학사 품질, 투자 부담 분담, 지속 가능한 계약 |
| 등록금·수강료 납부자 | 학습자, 장학·학비 지원 주체 | 총비용·반환 기준의 투명성, 학업 지속 가능성 |
| 계약·정산 주체 | 교육기관과 OPM 벤더 | 수납·배분 근거 일치, 비용 부담·정산 시점 합의 |
| 운영자 | 벤더의 모집·마케팅·제작·LMS·학생지원 조직 | 기관 승인 지연 감소, 역할별 권한, 예측 가능한 업무량 |
| 감독·품질 담당 | 기관 품질관리 조직, 교육부·관련 평가 주체 | 위탁 범위 적정성, 원격강의 품질·학사 증빙 [확인 필요] |

학습자가 기관에 등록금을 내고 기관이 벤더에 배분하는 구조를 기본으로 설계합니다. 실제 수납·증빙 발행·반환 주체는 계약에서 확정합니다. E02에는 **구매자인 기관·납부자인 학습자·운영자인 벤더를 분리**하고, 모집 상담과 입학 결정 권한도 나눕니다 ([[domain/세그먼트별의사결정구조]]).

## 6. 핵심 지표

| 대역 | 예시 지표 |
|------|-----------|
| M-01 북극성 | 해당 학기 시작 코호트 중 **기관 승인 평가 기준을 충족하고 예정 학점을 취득한 학생 비율** (비학위는 이수 목표 달성 비율) |

| M-4x 사업 | 문의 → 지원 → 등록 전환율, 등록생 획득비용, 코호트별 벤더 배분매출·공헌이익, 선투자 회수, 기관 계약 갱신율 |
| M-9x 가드레일 | 과장 모집 민원, 중도탈락·반환률, 정산 불일치, 학사 연동 오류, 지원 기한 초과, 강의 품질·접근성 결함 |

북극성의 분모는 학기 시작 시 확정하고 중도탈락자를 사후 제외하지 않습니다. 휴학·편입·시간제·비학위는 별도 코호트로 정의합니다. 모집 인원·등록금 매출 증가가 학습 성과 저하를 가리지 않게 학습·사업 지표를 나눕니다 ([[domain/학습분석지표]]).

## 7. 규제·리스크 포인트

- **위탁 가능 범위**: 일반대학·원격대학·사이버대학·평생교육원별 설립·운영 근거, 모집·교육 업무 위탁 및 등록금 수익배분 가능 범위 [확인 필요]. 해외 OPM 관행을 한국 계약의 허용 근거로 쓰지 않습니다.
- **학위·학점 표시**: 학위 수여·학점 인정 주체와 과정 인가·평가인정 범위 [확인 필요]. 평생교육원 수료증을 학위처럼 광고하지 않고, 입학·졸업·취업 보장 표현은 기관 승인 절차를 둡니다.
- **원격수업·품질인증**: 기관별 원격수업 운영 기준, 출석·평가·강의평가 요건, 대학 온라인강의 품질인증의 적용 여부·심사 주체·평가 항목·갱신 주기 [확인 필요]. 기관 자체 검수와 외부 인증을 구분하고 P04에 승인·개정·평가 증빙을 남깁니다 ([[domain/대학LMS운영]], [[domain/대학온라인강의품질인증]]).
- **등록금·수강료 반환**: 대학 등록금 반환과 평생교육 수강료 반환의 적용 규정·산정 기준·기한 [확인 필요]. 일반 VOD 환불표를 일괄 적용하지 않고 P01과 S07의 반환·소급 차감을 맞춥니다.
- **학생 개인정보**: 기관·벤더의 처리 역할, 위탁·재위탁 고지, 국외 이전·보유 기간 요건 [확인 필요]. 모집 정보와 성적·상담 기록의 접근 권한·이용 목적을 분리합니다 ([[domain/학습데이터프라이버시]]).
- **저작권·접근성**: 교수 강의·외주 제작물·제3자 자료의 사용 범위와 계약 종료 후 이용권을 구분합니다. 원격강의 자막·대본·대체 자료와 장애학생 편의의 적용 의무 [확인 필요]를 E13·P04에서 확인합니다 ([[domain/교육저작권]], [[domain/접근성]]).
- **계약 종속·사업 중단**: 독점·장기 계약, 최소 모집 보장, 제작비 회수 조건을 손익 시나리오로 검토합니다. 벤더 교체·파산·계약 종료 시에도 재학생 학습·기록·콘텐츠 접근이 이어지도록 인계 책임·비용·검수 기준을 정합니다.

## 9. 자주 하는 실수

- OPM을 LMS 납품으로만 보고 모집·학생지원·제작·학사 승인 책임을 빠뜨린다.
- 기관 승인 없이 입학·학위·취업을 보장하는 문구로 등록 전환율을 올린다.
- 수납액·장학금·감면·반환액의 정의 없이 배분율부터 정해 S06·S07이 어긋난다.
- 정산 확정 뒤 자퇴·반환이 생겼을 때의 소급 차감과 대사 책임을 비워 둔다.
- 기관마다 다른 출석·평가 규정을 하드코딩하고 성적의 원장을 LMS로 오인한다.
- 제작 완료를 품질인증 완료로 간주하고 기관 검수·외부 심사 증빙을 구분하지 않는다.
- 계약 종료 시 콘텐츠 권리와 학사 기록을 넘기지 못해 재학생 학습이 끊긴다.
