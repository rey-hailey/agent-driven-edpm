# AT10 AI 튜터·학습 에이전트

## 1. 정의와 예

LLM 기반 AI가 학습자·교사와 대화하며 설명·질문·피드백·자료 생성을 하는 제품 또는 기능입니다. 단독 제품이면 이 유형이 주 유형이고, 코스웨어·마켓플레이스 등에 AI를 붙이면 **보조 유형으로 조합**합니다 (예: AT05+AT10).

| 형태 | 교육적 역할 · 구성 요소 | 설명 | 범주 예시 |
|------|-------------------------|------|-----------|
| 소크라테스식 튜터 | T · 근거(+학습자상태) | 정답 대신 질문·힌트로 이끄는 튜터 | Khanmigo형 |
| 교재 근거 Q&A | T·O · 근거 | 교재·강의 근거로 답하는 도우미 | 강좌 질의응답 봇형 |
| 학습 버디 | T · 학습자상태 | 학습자를 기억하고 계획·동기를 돕는 에이전트 | 학습 코치형 |
| 교사·운영 보조 | G·O · 데이터조회·생성물 | 학습 데이터를 조회해 리포트·문항·피드백 초안 생성 | 교사용 AI 어시스턴트형 |
| 대화 연습 | T·F · 학습자상태 | 어학 말하기·롤플레이 | AI 회화 연습형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 학습자 (성인 또는 미성년), 교사 (교사·운영 보조) | 즉시 도움, 이해, 업무 시간 절감 |
| 결제자 | 주 유형을 따름 (본인·보호자·학교·기업) | AI 추가 비용 대비 가치 |
| 의사결정자 | 주 유형을 따르되, AI는 **안전·정확성 검토자**(학교 정보 담당, 기업 보안, 보호자)가 거부권을 가짐 | 잘못된 답·부적절 대화 없음 |
| 감독·검토 | 법무·개인정보 담당, 교과 전문가 | 법적 의무 충족, 내용 정확성 |
| 공급자 | LLM 제공사, 지식 소스 저작권자 | 이용 조건 준수 |

## 7. 규제·리스크 포인트

- **AI 기본법 (2026.1.22. 시행)**: 초·중등 **학생 평가**(채점·성취 판정·진단)에 쓰는 AI는 고영향 AI입니다. 고영향·생성형 AI는 사전 고지, 생성물 표시 의무(제31조). 세부 의무는 시행령·고시 [확인 필요] ([[domain/아동개인정보보호]]).
- **G-AI**: E14 done + A06 합격 전 E15 완료 불가.
- **외부 AI API 전송**: 비식별화 전 학생 데이터 전송 금지, 제공사 데이터 보존·학습 이용 조건 확인 [확인 필요] ([[domain/학습데이터프라이버시]]).
- **학습자상태(기억)**: 기억 항목 범위, 보관 기간, 학습자·보호자 열람·삭제권.
- **미성년 대화 안전**: 자해·위기 신호 에스컬레이션, 부적절 주제 차단, 보호자 고지.
- **지식 소스 저작권**: 교재·기출을 지식베이스에 넣는 이용 허락 (A01 실체 검증) ([[domain/교육저작권]]).
- **학업 정직성**: 과제 대필 도구가 되지 않게 정답 공개 규칙과 교사 설정.

## 8. 시즌 캘린더 (G-CAL 입력)

주 유형의 캘린더를 따르고, AI 고유 일정을 더합니다.

| 시기 | 이벤트 | 영향 |
|------|--------|------|
| 주 유형 성수기 직전 | 사용량 급증 | 토큰 비용 한도·속도 제한 점검 |
| 모델 버전 교체 | 제공사 모델 지원 종료·변경 | 골든셋 재평가 후 교체, 시험 기간 교체 금지 |
| 학기 시작 (K-12) | 교사 AI 사용 설정 | 고지·동의 문서 배포, 교사 연수 ([[domain/학사일정]]) |
| 법령 고시 시점 | AI 기본법 시행령·고시 | E13·E14 재검토 [확인 필요] |

## 9. 자주 하는 실수

- AI를 넣을 곳을 고르지 않고(A00 생략) 모든 화면에 채팅 창을 붙인다.
- 정답을 바로 알려주는 튜터를 출시해 학습 효과를 해친다.
- 평가 세트 없이 데모 몇 번으로 품질을 판단한다 (G-AI).
- 학생 대화를 비식별화 없이 외부 API에 보낸다.
- 기억 기능에 삭제·열람 경로를 만들지 않는다.
- 모델 교체 후 재평가 없이 배포한다.

## 10. 시작 순서

1. `/edpm-init` → E00 (주 유형, AI 대상 연령, 데이터 전송 규칙)
2. `/edpm-blueprint apply AT10` (조합이면 `apply AT05,AT10` 등)
3. `/edpm-report M01`, `/edpm-doc P1`, `/edpm-doc E05`, `/edpm-doc E06`
4. `/edpm-doc A00` (AI 적용 기회 맵)
5. `/edpm-doc E14` (역할·가드레일·평가세트 20건 이상), `/edpm-ai-design type`
6. `/edpm-ai-design A01`(구성 요소별 A01·A04·A05) → `/edpm-ai-design A02` → `/edpm-ai-design A03`
7. `/edpm-ai-design goldenset`, `/edpm-eval run 골든셋` → `/edpm-eval report` (A06)
8. `/edpm-doc E13` (고영향 여부, 미성년 대화 안전)

## AI 방식·운영

AI 튜터 제품은 LLM 하나로 끝나지 않습니다. 기능마다 방식(규칙·고전 NLP·검색·RAG·소형 모델·로컬 LLM·클라우드 LLM)을 A10에서 고르고, A11 라우팅·A12 비용·A13 운영·A14 가드레일과 P07~P09 정책을 **필수**로 둡니다. 방식 비교는 `ai_eval.py --target claude|local|cmd`, 비용은 `ai_cost.py`. 참고: 프레임워크 `guide/10.AI방식선택.md`, [[domain/AI방식스펙트럼]], [[domain/AI가드레일설계]], [[domain/AI서비스IA특수성]].
