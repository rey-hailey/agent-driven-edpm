# AT07 소비자 학습앱

## 1. 정의와 예

개인이 스마트폰·태블릿으로 스스로 배우는 구독형 앱입니다. 교사가 없으므로 **동기 유지와 습관 형성**을 제품이 대신해야 하고, 앱스토어·광고 획득 비용과 구독 유지가 사업을 좌우합니다. 대상이 아동이면 보호자가 결제자입니다.

| 형태 | 설명 | 범주 예시 |
|------|------|-----------|
| 어학 앱 | 짧은 레슨, 스트릭, 말하기·듣기 | Duolingo·스픽형 |
| 유아·초등 학습앱 | 한글·수학·독서, 보호자 결제 | 유아 학습 구독형 |
| 교과 자기주도 | 수학·과학 개념 + 문제, 학생 본인 사용 | 개념 학습 앱형 |
| 두뇌·교양 | 마이크로 러닝, 퀴즈 | 교양 마이크로러닝형 |

## 2. 이해관계자와 구매 구조

| 역할 | 누구 | 원하는 것 |
|------|------|-----------|
| 사용자 | 학습자 (성인 또는 아동) | 재미, 짧은 시간, 성장 체감 |
| 결제자 | 성인은 본인, 아동은 보호자 | 구독 가치, 쉬운 해지 |
| 의사결정자 | 앱스토어 평점·리뷰·무료 체험이 결정. 아동은 보호자 | 안전, 광고 없음, 효과 근거 |
| 플랫폼 | 앱스토어(결제·심사), 광고 매체 | 정책 준수 |
| 콘텐츠 공급 | 자체 제작, 출판사 라이선스 | 이용 범위 |

## 6. 핵심 지표

| 대역 | 예시 지표 |
|------|-----------|
| M-01 북극성 | 주간 **간격 복습 문항 정답 유지(지연 검사 통과) 학습자 수** (일일 활성이 아니라 기억 유지) |
| M-1x 학습 효과 | 레벨 진단 점수 변화, 지연 복습 정답률, 말하기·읽기 평가 점수 |
| M-2x 참여 | D1·D7·D30 리텐션, 주간 학습일 수, 레슨 완료율 |
| M-3x 보호자 | 보호자 리포트 열람률, 보호자 설정 사용률 (교사 도입 대역을 보호자로 읽음, 성인 앱은 n/a) |
| M-4x 사업 | 체험→유료 전환율, 구독 유지율, 획득 비용 대비 생애 가치, 앱 평점 |
| M-9x 가드레일 | 과도한 사용 시간, 스트릭 상실 후 이탈, 해지 실패 문의, 아동 개인정보 사고 |

스트릭·랭킹은 단기 참여를 올리지만 내적 동기를 해칠 수 있습니다. M-2x만 오르고 M-1x가 정체하면 설계를 재검토합니다 ([[domain/동기설계]], [[domain/학습분석지표]]).

## 7. 규제·리스크 포인트

- **자동 갱신 구독**: 갱신 전 고지, 해지 방법 표시, 무료 체험 후 유료 전환 동의 [확인 필요].
- **앱스토어 정책**: 결제 수단, 아동 카테고리 앱의 광고·추적 제한, 연령 등급 [확인 필요].
- **아동 개인정보**: 만 14세 미만 법정대리인 동의, 해외 서비스는 COPPA·GDPR 제8조 ([[domain/아동개인정보보호]]).
- **다크 패턴**: 해지 방해, 과도한 결제 유도, 아동 대상 보상 루프 ([[domain/학습데이터프라이버시]]).
- **청약철회**: 디지털 콘텐츠 이용 개시 후 철회 제한 고지 [확인 필요]. [[domain/환불정책]]
- **효과 광고**: "N주 만에 원어민처럼" 같은 문구는 E19 근거 없으면 금지.
- **접근성**: 색 대비, 소리 없는 모드, 화면 낭독기 ([[domain/접근성]]).

## 9. 자주 하는 실수

- DAU·스트릭을 북극성으로 두고 학습 효과를 측정하지 않는다.
- 보상·랭킹을 과하게 넣어 보상이 끝나면 학습도 끝난다.
- 아동 앱에서 보호자 게이트 없이 결제·외부 링크가 노출된다.
- 해지 경로를 숨겨 앱 평점과 민원이 나빠진다.
- 이탈 예측(A09) 결과로 과도한 푸시를 보내 해지를 앞당긴다.
- 레벨 진단 없이 모두 같은 레슨에서 시작한다.
