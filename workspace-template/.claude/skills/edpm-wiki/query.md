# edpm-wiki query

## 절차

1. `02.wiki/index.md`를 읽고 관련 페이지를 고릅니다. 필요하면 `grep`으로 본문을 찾습니다.
2. 관련 페이지를 읽고 답합니다.
   - 모든 사실 주장 뒤에 `[[위키 페이지]]` 출처를 답니다.
   - 위키에 없는 내용은 일반 지식으로 채우지 말고 "위키에 근거 없음"이라고 밝힙니다. 필요하면 어떤 자료를 ingest하면 되는지 제안합니다.
   - `confidence: low`이거나 `status: stale`인 페이지를 근거로 쓰면 그 사실을 알립니다.
   - 수치 계산이 필요하면 `01.자료실/데이터/`를 대상으로 스크립트·SQL을 작성해 계산하고, 코드를 답에 포함합니다.
3. 형식: 기본은 짧은 메모. 요청에 따라 비교표, Marp 슬라이드(`marp: true` frontmatter), 차트(matplotlib 이미지 또는 Mermaid)로 만듭니다.
4. 저장: `--save`이거나 답이 길고 다시 쓸 만하면 `05.outputs/YYYY-MM-DD_주제.md`로 저장합니다. 재생성 가능한 HTML·PPTX·PDF는 `_YYYYMMDD_HHMM` 접미사를 붙입니다.
5. 위키 되돌리기: 답에서 새로 정리된 비교·종합·결론이 있으면 "위키에 반영할까요?"라고 묻고, 승인하면 해당 위키 페이지를 갱신하거나 새로 만듭니다.
6. log: `## [YYYY-MM-DD] query | {질문 요약}`과 저장 경로·반영 페이지를 추가합니다.

## 자주 쓰는 질문 예

- "중학교 수학 교사들이 오답 노트에 대해 말한 불만을 인사이트별로 묶어줘"
- "경쟁사 3곳의 학원용 요금제를 표로 비교해줘"
- "E05의 LO-02를 뒷받침하는 현장 근거가 충분한가?"
- "다음 학기 출시 일정과 겹치는 학사 이벤트는?"
