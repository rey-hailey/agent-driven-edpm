# edpm-wiki promote

개인 Brain은 회사가 바뀌어도 가져가는 지식입니다. 그래서 무엇이 나가는지 사람이 한 줄씩 확인해야 합니다. 이 스킬은 후보를 고르고 정리할 뿐이며, 사람이 승인하지 않은 내용은 옮기지 않습니다.

## 옮길 수 있는 것과 없는 것

| 옮길 수 있음 | 옮길 수 없음 |
|--------------|--------------|
| 공개 자료에 근거한 규제·표준·정책 정리 (`domain/`) | 회사 매출, 단가, 계약 조건, 고객사 이름 |
| 학습과학 원칙을 실제로 적용해 보며 얻은 일반 교훈 | 미공개 로드맵, 기능 세부, 기술 구조 |
| 세그먼트별 의사결정 구조에 대한 일반화된 관찰 | 회사 내부 지표 수치, 실험 결과 원자료 |
| 일하는 방식 (체크리스트, 템플릿 개선, 실패 패턴) | 인터뷰 원문, 개인정보, 특정 학교·학원 식별 정보 |
| 공개된 경쟁 서비스 정보 (출처 URL 포함) | 비밀유지계약 대상 정보 전부 |

회사 고용계약·비밀유지계약 조건이 우선합니다. 애매하면 옮기지 않습니다.

## 절차

1. **후보 찾기**
   - `02.wiki/domain/`에서 Brain에 없거나 Brain보다 새 페이지
   - `02.wiki/research/`, `learners/`, `decisions/`, `03.docs/7.측정/E20_회고다음사이클.md`에서 일반화할 만한 교훈
2. **일반화 초안**: 후보마다 회사·제품·학교·사람을 지운 일반 문장으로 고칩니다.
   - 예: "OO에듀 중2 파일럿에서 오답 해설 열람률이 시험 2주 전 3배" → "시험 2주 전에는 오답 복습 기능 사용이 크게 늘어난다는 관찰이 있었다 (단일 파일럿, 일반화 주의)"
   - 출처는 공개 URL만 남기고, 내부 출처는 `내부 관찰 (YYYY, 세그먼트)`로 바꿉니다.
   - `confidence`를 보수적으로 매깁니다 (단일 관찰이면 low).
3. **검토표**: 후보마다 `원문 위치 | 일반화 문장 | 대상 Brain 페이지 | 기밀 위험 판단`을 보여주고 하나씩 승인받습니다. `--dry-run`이면 여기서 멈춥니다.
4. **반영**: 승인된 항목만 Brain에 추가합니다. 기존 페이지면 해당 섹션에 추가하고, 새 개념이면 새 페이지를 만들고 Brain의 `index.md`를 갱신합니다. Brain `log.md`에 `## [YYYY-MM-DD] promote | N건 (출처: 세그먼트·연도만)`을 추가합니다.
5. **워크스페이스 log**: `## [YYYY-MM-DD] promote | N건 승격, N건 보류`
6. **마지막 점검**: Brain 저장소에서 회사명, 제품명, 고객사명, 사람 이름을 `grep`해 0건인지 확인하고 결과를 보고합니다.
