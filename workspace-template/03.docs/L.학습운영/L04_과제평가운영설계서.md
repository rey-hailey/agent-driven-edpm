# L04 과제·평가운영설계서

> **작성 가이드**
> - **목적**: 퀴즈·시험·과제·프로젝트·동료평가를 어떤 유형(AS)으로 운영하고, 채점·루브릭·재응시·지각 제출·표절·피드백 기한·시험 감독을 어떤 규칙으로 할지 정합니다.
> - **입력**: L01 과정 구조, E05 LO와 평가 증거, E11 문항 유형(CT, 있으면), [[domain/과제와평가설계]]
> - **경계**: E11은 문항 하나를 어떻게 만들고 채점하나, L04는 과정 안에서 평가를 언제·몇 번·누가 채점하고 결과를 수료(L03)와 어떻게 연결하나입니다.
> - **게이트**: L01, E05가 `done`이어야 합니다. 모든 AS는 E05 LO 하나 이상에 연결됩니다(평가 증거). 시험 감독(웹캠·화면 녹화)을 쓰면 E13 개인정보 점검에 올리고, 부정 대응 단계는 P03과 맞춥니다.
> - **적용 유형**: AT01, AT02, AT03, AT08, AT09 필수 / AT04 해당 시 / AT05, AT06은 E11 중심 / AT07, AT10 해당 시
> - **검토 패널 (권장)**: 교수설계자, 강사 대표, 튜터·채점 리드, 개인정보 담당, 운영 매니저
> - 표의 첫 행은 예시 서비스 **스킬업**(성인 대상 VOD + 라이브 강의 마켓플레이스, 강사 입점·수익배분, 기업 B2B 좌석 판매, 일부 사업주 환급 과정) 기준입니다.

## 5. 시험 감독과 개인정보 균형

| 감독 수준 | 방식 | 부정 억제 | 개인정보 부담 | 쓰는 경우 | E13 점검 |
|-----------|------|-----------|---------------|-----------|----------|
| 0 없음 | 문항 풀·시간 제한·무작위 순서 | 낮음 | 없음 | 형성평가, B2C 일반 | 불필요 |
| 1 본인 확인 | 시험 시작 시 본인 인증 | 중간 | 낮음 | B2B 필수, 환급 과정 [확인 필요] | 인증 정보 처리 |
| 2 브라우저 잠금 | 탭 이동·복사 감지 기록 | 중간 | 낮음~중간 | 자격 연계 시험 | 행동 로그 보존 기간 |
| 3 원격 감독 | 웹캠·화면 녹화, AI 이상 탐지 + 사람 검토 | 높음 | 높음 (영상·생체 정보 가능성) | 고부담 시험만 | 필수: 동의, 보존 기간, 접근 권한, 대체 수단 |
| 예시 (스킬업) | AS-01 수준 0, AS-02 수준 1, 환급 과정 [확인 필요] | | | | |

원칙: 평가의 이해관계(stakes)가 높을 때만 감독 수준을 올리고, 수준 3은 대체 응시 수단(예: 지정 장소 응시)을 둡니다 [가정].

## 완료 체크리스트

- [ ] 모든 AS가 E05 LO에 연결되고 수료 규칙(L03)과의 관계가 있다
- [ ] 유형별 채점 방식, 루브릭, 채점자 보정 규칙이 있다
- [ ] 채널별 재응시·반영 점수·지각 제출 규칙이 있다
- [ ] 표절·AI 생성물·대리 응시 대응이 P03 단계와 일치한다
- [ ] 감독 수준별 개인정보 부담이 E13에 올라갔고 대체 수단이 있다
- [ ] 피드백 기한과 측정 방법(E12)이 있다
- [ ] 환급 과정 평가 기준에 `[확인 필요]`와 확인 담당이 있다
