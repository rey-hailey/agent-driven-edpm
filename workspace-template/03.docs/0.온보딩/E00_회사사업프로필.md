# E00 회사·사업 프로필

> **작성 가이드**
> - **목적**: 이 회사가 누구에게 무엇을 팔고, 누가 돈을 내고, 누가 결정하는지를 한 장에 정리합니다. 이 문서가 활성 모듈(CONTENT·DATA·SAFE·AI·GTM)과 이후 모든 산출물의 전제를 정합니다.
> - **입력**: `/edpm-init` 인터뷰 답변, `01.자료실/회사/`(회사 소개서, 조직도, IR 공개 자료), [[domain/세그먼트별의사결정구조]], [[domain/학사일정]], [[domain/아동개인정보보호]]
> - **게이트**: 전제조건 없음. 단, 10절 모듈 선택표가 비어 있으면 E01 이후 게이트 판정이 불가능하므로 `done` 처리하지 않습니다. 완료 후 `AGENTS.md` 2절 회사 컨텍스트를 이 문서로 채우자고 제안합니다.
> - **검토 패널 제안**: 직속 리더, 사업(영업) 담당, 개인정보 담당자
> - 아래 표의 두 번째 행은 **예시**입니다. 샘플 제품: 수학 오답 코칭 앱 '매스핏' — 중학생(만 12~15세), 학원 B2B2C + 학부모 결제, AI 오답 해설 기능. 실제 작성 시 예시 행은 지웁니다.

## 완료 체크리스트

- [ ] 사업 유형과 매출 비중이 적혀 있고, 모듈 판정 기준 유형이 하나로 정해졌다
- [ ] 학습자 연령과 미성년(만 14세 미만 포함) 여부가 명시되었다
- [ ] 사용자·구매자·결제자·의사결정자가 각각 누구인지 구분되었다
- [ ] 학사·조달 캘린더에 회사 영향(배포 금지 기간, 영업 시즌)이 1개 이상 있다
- [ ] 규제 노출 항목마다 해당 여부와 위키 링크가 있다
- [ ] 기밀 등급표가 회사 정책과 맞는지 담당자 확인을 받았다
- [ ] 모듈 선택표의 모든 행에 활성 여부와 사유가 있다
- [ ] 근거 없는 문장에 `[가정]`, 확인 필요 사실에 `[확인 필요]`가 붙어 있다
- [ ] `AGENTS.md` 2절 회사 컨텍스트 갱신을 제안했다
- [ ] 국가 교육과정 기반이면 대상 학교급·과목·학년군과 적용 교육과정 버전을 적었다
- [ ] 서비스 유형을 판정하고 `/edpm-blueprint apply`로 산출물 상태를 반영했다
- [ ] 업무 모드(N·F)를 정하고 해당 스킬로 다음 단계를 안내받았다
