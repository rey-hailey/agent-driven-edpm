# S04 세일즈플레이북

> **작성 가이드**
> - **목적**: 영업 담당이 누구를 찾아가 무엇을 묻고, 무엇을 보여주고, 어떤 반론에 어떻게 답하며, 계약 후 도입 지원팀에 무엇을 넘기는지 세그먼트별로 정합니다. 신규 영업 담당이 이 문서만 보고 첫 미팅을 할 수 있어야 합니다.
> - **입력**: E02(SH-ID, 구매 여정 vs 사용 여정), E06(가치 제안), E10(데모 화면), E13(개인정보 답변 근거), E17·E19(증거), E18(도입 지원), S03(가격·할인), `01.자료실/회의/`(영업 미팅 기록), [[domain/세그먼트별의사결정구조]], [[domain/교사참여설계]]
> - **게이트**: E02, E06이 `done`이어야 합니다. 반론 대응과 증거 자료의 효과 주장은 E19·E17 수치만 인용합니다(없으면 "파일럿 진행 중"으로 답합니다). 개인정보 답변은 E13 판정과 일치해야 합니다.
> - **검토 패널 제안**: 영업 리드, 교사 자문(데모가 수업 현실에 맞는지), 법무(개인정보·효과 표현), 마케팅(메시지 일관성)
> - **스킬**: `/edpm-content S04` — 세그먼트별 질문·데모 스크립트·반론 대응 초안을 만들고, 영업 미팅 기록이 쌓이면 반론 표를 갱신합니다.
> - 예시는 샘플 제품 '매스핏'(중학생 만 12~15세, 학원 B2B2C + 학부모 결제, AI 오답 해설) 기준입니다.

## 완료 체크리스트

- [ ] 활성 세그먼트마다 의사결정 구조, ICP, 디스커버리 질문이 있다
- [ ] 데모 스크립트가 학생 → 교사 → 보호자 순서이고 7분·15분 버전이 있으며 가상 데이터만 쓴다
- [ ] 반론 표에 개인정보, 효과 근거, 교사 업무 증가, 가격, 기존 도구가 모두 있다
- [ ] 효과 관련 답변과 증거 자료가 E19·E17 수치만 인용하고 법무 검토를 받았다
- [ ] 파일럿 성공 기준이 E07 M-ID로 사전 합의되고 학사일정과 충돌하지 않는다
- [ ] 파이프라인 전환율이 스크립트로 집계되고 M-4x와 연결된다
- [ ] E18 도입 지원 인계 항목이 정해졌다
