# S03 가격·견적서

> **작성 가이드**
> - **목적**: 세그먼트별 가격 모델, 원가 구조, 할인 정책, 견적 양식을 정하고 단위 경제성(매출총이익률)을 확인합니다. S02 12장과 S04 가격 반론 대응의 기준이 됩니다.
> - **입력**: E00(사업 유형·결제 주체), E06(범위·AI 기능), E04 3절(시장 가격), E14·A03(LLM 호출 구조), `02.wiki/market/`(경쟁 가격, verified 180일 이내), [[domain/세그먼트별의사결정구조]], [[domain/학사일정]]
> - **게이트**: E00, E06이 `done`이어야 합니다. **실체 검증**: 모든 금액은 3절 표나 6절 스크립트로 재현 가능해야 합니다. LLM이 암산한 금액은 쓸 수 없습니다. 실제 계약 단가는 회사 기밀이므로 `02.wiki/company/`에만 두고 이 문서에는 정가·공식만 둡니다.
> - **검토 패널 제안**: 영업 리드, 재무, 교사 자문(학기 단위 운영 현실), 법무(부가세·약관·조달 가격 조건)
> - **스킬**: `/edpm-proposal S03` — 원가 공식에 변수를 넣어 스크립트를 실행하고 견적서를 생성합니다.
> - 예시는 샘플 제품 '매스핏'(중학생 만 12~15세, 학원 B2B2C + 학부모 결제, AI 오답 해설) 기준이며 **모든 금액은 형식을 보여주는 [가정] 값**입니다.

## 2. 원가 구조

학습자 1인(좌석)당 월 원가를 항목별 공식으로 계산합니다.

| 항목 | 공식 | 변수 출처 |
|------|------|---------|
| LLM API | 월 활성 일수 × 일 평균 AI 요청 수 × (입력 토큰 ÷ 1,000 × 입력 단가 + 출력 토큰 ÷ 1,000 × 출력 단가) | E12 사용 이벤트, A03 프롬프트 길이, 공급사 단가표 (verified) |
| 콘텐츠 | 문항·해설 제작비 ÷ 상각 기간(월) ÷ 예상 좌석 수 | E11, 콘텐츠 계약 |
| 인프라 | 월 인프라 비용 ÷ 월 활성 학습자 수 | B04, 클라우드 청구서 |
| 지원 | (CS·연수 인건비 + 도구비) ÷ 활성 학습자 수 | E18 5장 |
| 결제 수수료 (B2C) | 결제액 × 수수료율 | PG·앱스토어 약관 [확인 필요] |

## 6. 계산 스크립트 (재현 가능)

경로: `automation/scripts/S03_가격계산.py` (사람 승인 후 저장). 출력은 `05.outputs/S03_가격계산_YYYYMMDD_HHMM.csv`.

```python
# 매스핏 예시 변수 — 모두 [가정]. 실제 값은 company/ 위키·청구서에서 가져온다.
days, req_per_day = 12, 5
tok_in, tok_out = 2000, 500
price_in, price_out = 4, 20            # 원 / 1,000토큰
infra, content, support = 400, 800, 600
list_price = 12000                      # 좌석·월
seats, months, discount, vat = 60, 6, 0.10, 0.10

llm = days * req_per_day * (tok_in / 1000 * price_in + tok_out / 1000 * price_out)
cost = llm + infra + content + support
gm = (list_price - cost) / list_price
gm_disc = (list_price * (1 - discount) - cost) / (list_price * (1 - discount))
supply = seats * list_price * months * (1 - discount)
print(f"LLM={llm:.0f} cost={cost:.0f} GM={gm:.1%} GM_disc={gm_disc:.1%}")
print(f"supply={supply:.0f} vat={supply*vat:.0f} total={supply*(1+vat):.0f}")
# 기대 출력: LLM=1080 cost=2880 GM=76.0% GM_disc=73.3% / supply=3888000 vat=388800 total=4276800
```
