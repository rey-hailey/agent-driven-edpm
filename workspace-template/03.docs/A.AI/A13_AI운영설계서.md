# A13 AI운영(MLOps·LLMOps)설계서

> **작성 가이드**
> - **목적**: AI 기능을 출시 후에도 같은 품질로 유지하기 위해 무엇을 버전 관리하고, 어떤 평가를 통과해야 배포하고, 무엇을 감시하고, 사고가 나면 어떻게 되돌리는지 정합니다. 로컬 모델(M6) 서빙·갱신과 고전 ML(M2·M5, A09) 재학습 주기도 여기서 정합니다.
> - **입력**: A10 구성도·MD, A11 MOD·RT·버전 고정 규칙, A06 평가 기준, A14 GD, A12 예산, B04 인프라·배포, E12 이벤트, E14 9절 모니터링
> - **게이트**: **G-AI** 직접 조건은 아니지만, 이 문서의 CI 평가 게이트(3절)가 A06 합격 상태를 출시 후에도 유지하는 장치입니다. P09(AI서비스운영정책)는 A12와 이 문서를 전제로 합니다.
> - **원칙**: 지표 값은 로그·SQL·스크립트로 계산합니다. 평가 실행은 `ai_eval.py`, 결과 파일 경로를 남깁니다. 작은 팀이 실제로 돌릴 수 있는 수준으로만 설계합니다.
> - **스킬**: `/edpm-ai-design ops`, 평가는 `/edpm-eval`
> - **검토 패널 (권장)**: AI 엔지니어, 보안·개인정보 담당, 교과 전문가, 재무
> - **관련 위키**: [[domain/MLOps와LLMOps]], [[domain/AI평가메트릭과AB테스트]], [[domain/로컬LLM과온프레미스]], [[domain/AI가드레일설계]], [[domain/모델선택과라우팅]]
> - 예시는 A10~A12와 같은 제품 **매스핏**(AI-01 오답 단계별 힌트 해설, M1 + M2 + M3 + M7, 민감 입력 M6)으로 이어 씁니다. 수치는 모두 [가정]입니다.

## 2. 환경

| 환경 | 용도 | 데이터 | 모델 | 접근 |
|------|------|--------|------|------|
| 개발 (예시) | 프롬프트·규칙 작성 | 가상 페르소나·평가 세트만 | 소형 모델 | 개발자 |
| 스테이징 | CI 평가, 통합 시험 | 가명 샘플 | 운영과 같은 모델·버전 | 팀 |

## 3. CI 평가 게이트

| 트리거 | 실행 | 합격 기준 | 실패 시 |
|--------|------|-----------|---------|
| 프롬프트·고정 문구 변경 PR (예시) | `python automation/scripts/ai_eval.py --set 03.docs/3.설계/E14_평가세트.csv --system {변경 프롬프트} --model {운영 모델} --judge llm` | 안전 100%, 루브릭 평균 하락 {0.1} 이내, p95 증가 {20}% 이내 [가정] | 병합 차단, 실패 행을 PR에 첨부 |
| 가드레일 규칙 변경 | 레드팀 세트 + 정상 질문 세트, `--judge exact` 병행 | 미탐 0건, 오탐률 {5}% 이하 | 병합 차단 |
| KB 재색인 | 골든셋 | 검색 적중률 기준 유지 (A06) | 이전 색인 유지 |
| 모델 교체 | A11 6절 절차 전체 | A11 회귀 기준 | 교체 보류 |
| 정기 (주 1회) | 전체 세트 | 같음 | 알림, 원인 분석 |

LLM 채점은 보조입니다. 안전 판정이 바뀐 행은 사람 1인이 확인 후 병합합니다. 평가 비용은 A12 CO-09·월 예산에 포함합니다.

## 완료 체크리스트

- [ ] 프롬프트·KB·모델·가드레일·평가 세트·고전 ML 모델의 버전 규칙과 저장 위치가 있다
- [ ] 응답 로그에 PR·KB·모델·GD 버전이 남는다
- [ ] 개발·스테이징·운영 환경과 데이터 규칙이 있다 (실제 학생 데이터는 개발 환경 금지)
- [ ] 프롬프트·가드레일·모델 변경 시 `ai_eval.py` CI 게이트와 합격 기준이 있다
- [ ] 단계 배포, 변경 동결(G-CAL), 10분 내 롤백 절차가 있다
- [ ] (M6) 로컬 모델 서빙·갱신, (M2·M5) 재학습 주기와 기준이 있다
- [ ] OP 지표(품질 샘플·신고·지연·오류·비용·드리프트·검색 적중률)의 계산 경로와 조치가 있다
- [ ] 사람 검토 큐와 사고 대응 등급이 P08·P09와 일치한다
- [ ] 작은 팀 기준 역할과 당번이 정해졌다
