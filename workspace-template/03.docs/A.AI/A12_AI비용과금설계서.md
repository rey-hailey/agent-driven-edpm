# A12 AI비용·과금설계서

> **작성 가이드**
> - **목적**: AI 기능의 원가를 요청·학습자·월 단위로 계산하고, 절감 수단(캐싱·라우팅·FAQ 우회·컨텍스트 축소·배치)의 효과를 비교하고, 사용자 과금(포함량·크레딧·요금제·공정 사용)과 마진을 S03·S06과 맞춥니다.
> - **입력**: A11 라우팅 비율(RT)·모델(MOD)·요청당 토큰, A10 구성도, A02 지연·비용 예산, S06 수익원(RV)·객단가, S03 가격 항목(PR-P), E06·E18 학습자 목표, E12 이벤트(실측 요청 수)
> - **게이트**: **G-AI** — 유료 판매이거나 대량 사용(예: 월 활성 학습자 {1,000}명 이상 [가정])이면 이 문서가 `done`이어야 E15를 완료할 수 있습니다. 실체 검증: `ai_cost.py` 실행 결과 파일이 `05.outputs/`에 있어야 합니다.
> - **원칙**: 모든 원가 수치는 `python automation/scripts/ai_cost.py --config ...` 결과에서 옮깁니다. 표에 손으로 곱셈하지 않고, LLM이 추정하지 않습니다. 단가는 `automation/scripts/model_prices.json`에 두고 계약 시점에 [확인 필요]. 로컬 모델(M6)도 GPU·운영 인력 비용을 넣습니다.
> - **스킬**: `/edpm-ai-design cost`
> - **검토 패널 (권장)**: 재무, AI 엔지니어, 사업 책임자, 보안·개인정보 담당
> - **관련 위키**: [[domain/LLM비용과토큰과금]], [[domain/모델선택과라우팅]], [[domain/로컬LLM과온프레미스]], [[domain/MLOps와LLMOps]]
> - 예시는 A10·A11과 같은 제품 **매스핏**(중학생 수학 오답 코칭, 학원 B2B2C, 학원당 좌석 구독)으로 이어 씁니다. 라우팅 비율이 A11과 연결되어야 원가가 맞기 때문입니다. 성인 이러닝(스킬업형)은 "서비스 유형별 메모"를 봅니다. 수치는 모두 [가정]입니다.

## 3. 원가 계산 (재현 가능)

```
python automation/scripts/ai_cost.py --example > 03.docs/A.AI/cost/ai_cost_base.json   # 처음 한 번, 틀 만들기
python automation/scripts/ai_cost.py --config 03.docs/A.AI/cost/ai_cost_base.json \
    > 05.outputs/ai_cost_base_{YYYYMMDD}.md                                         # 가격표 기본값: automation/scripts/model_prices.json
```

**설정 예시** (`03.docs/A.AI/cost/ai_cost_base.json`, 수치는 [가정]. 규칙·FAQ로 끝나는 요청 45%는 `deflection_ratio`, 나머지 AI 요청의 경로 비율은 `routes[].share` 합 1.0 — A11 라우팅 표와 일치)

```json
{
  "learners": 5000, "active_ratio": 0.6, "sessions_per_week": 3, "requests_per_session": 4,
  "deflection_ratio": 0.45,
  "routes": [
    {"name": "쉬운 질문 (RT-03)", "share": 0.73, "model": "claude-haiku-5-5", "input_tokens": 2200, "output_tokens": 200, "cache_hit": 0.0},
    {"name": "힌트 해설 (RT-04)", "share": 0.22, "model": "claude-sonnet-5-5", "input_tokens": 2200, "output_tokens": 300, "cache_hit": 0.68},
    {"name": "민감 데이터 → 로컬 (RT-01)", "share": 0.05, "model": "local-example", "input_tokens": 2200, "output_tokens": 200}
  ],
  "fixed_monthly_usd": {"vector_db": 50, "monitoring": 30, "human_review": 0},
  "price_per_learner_month_usd": 9.0
}
```

로컬 모델의 GPU 시간 단가·처리량·가동률과 클라우드 모델 단가는 `automation/scripts/model_prices.json`에서 바꿉니다 (공식 가격 페이지에서 확인 후 `checked` 날짜 갱신).

## 4. 절감 수단 비교

| 수단 | 바꾸는 설정 | 원가 변화 | 품질·안전 영향 | 채택 |
|------|-------------|-----------|----------------|------|
| 프롬프트 캐싱 (예시) | `routes[].cache_hit` 0.5 → 0.8 | {결과값} | 없음 (같은 프롬프트) | 채택 |
| 라우팅 (소형 모델 비중 확대) | `routes[].share` | {} | A11 2절 합격 범위 안에서만 | {} |
| FAQ·정적 힌트 우회 | `faq_m3` 비율 | {} | 오매칭 신고율 감시 (A13) | {} |
| 컨텍스트 축소 (근거 청크 수) | `input_uncached` | {} | A06 근거 인용률 재확인 | {} |
| 배치 처리 (교사용 주간 코멘트) | 배치 단가 적용 | {} | 실시간 아님, 교사 승인 흐름 유지 | {} |

## 완료 체크리스트

- [ ] 원가 항목(CO)에 토큰(입력·캐시·출력)·임베딩·검색·STT/TTS·GPU·모니터링·사람 검토가 검토되었다
- [ ] 트래픽 가정마다 근거와 실측 교체 시점이 있다
- [ ] 원가 수치는 `ai_cost.py` 결과 파일에서 옮겼고 설정 파일이 저장되어 재현 가능하다
- [ ] 라우팅 비율이 A11 4절과 일치한다
- [ ] 로컬 모델 비용에 GPU·운영 인력이 포함되었다
- [ ] 절감 수단마다 원가 변화와 품질 영향 확인 방법이 있다
- [ ] 포함량·초과 처리·공정 사용·고지가 P01·P09와 일치한다
- [ ] AI 원가 비율이 S03·S06 기준으로 점검되고 재무가 승인했다
- [ ] 예산 경보와 조치가 P09에 반영되었다 — G-AI (유료·대량 사용 시 A12)
