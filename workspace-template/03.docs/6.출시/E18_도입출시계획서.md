# E18 도입·출시계획서

> **작성 가이드**
> - **목적**: 세그먼트별로 누가 결정하고, 언제 예산이 집행되며, 도입 후 교실에서 실제로 쓰이게 하려면 무엇이 필요한지 정합니다. 에듀테크 출시는 "판매"보다 "도입 후 정착"이 성패를 가릅니다.
> - **입력**: E15 릴리즈계획서(롤아웃 단계), E17 파일럿결과보고서(권고, 근거), E02 이해관계자맵(SH-ID), E07 성과지표(M-ID), [[domain/세그먼트별의사결정구조]], [[domain/학사일정]].
> - **게이트**: G-EVIDENCE(E17에 실제 파일럿 결과 필요), G-CAL(영업·연수·캠페인 일정의 학사일정 충돌 검토). 효과 관련 문구는 E17·E19 근거 범위를 넘지 않습니다.
> - **추천 검토 패널**: 영업 리드, CS 리드, 교사 패널, 학원 원장 자문, 마케팅. 해당하지 않는 세그먼트 섹션은 "해당 없음"으로 남깁니다.

## 1. 출시 개요

| 항목 | 내용 |
|------|------|
| 대상 세그먼트 | {B2G·B2S / 학원 B2B2C / B2C / 고등교육 / 기업교육} |
| 출시 단위 | {E15 릴리즈} |
| 파일럿 근거 | {E17 권고와 핵심 결과 1~2줄} |
| 출시 시점 | {학사일정 기준} |
| 예시 | 매스핏 — 학원 B2B2C 우선, 학부모 결제. E17 조건부 Go. 2027년 3월 3주차 학원 15곳 → 1학기 기말 이후 전체 |

### 2.6 제안·영업 연결 (B2B·B2G)

제안서·견적·세일즈 플레이북은 사업 트랙에서 작성합니다. 이 문서는 도입·운영 계획(3~4장)을 그 산출물에 제공합니다.

| 필요 | 산출물 | 이 문서에서 넘겨주는 것 |
|------|--------|-------------------------|
| 교육청·학교 조달 제안 | S01 RFP분석서 → S02 제안서 (`/edpm-proposal`) | 연수 계획, 도입 체크리스트, 지원 체계 |
| 가격·견적 | S03 가격·견적서 | 도입 지원 인력·연수 비용 항목 |
| 원장·기업 영업 | S04 세일즈플레이북 (`/edpm-content`) | 데모 이후 도입 절차, 파일럿 제안 조건 |
