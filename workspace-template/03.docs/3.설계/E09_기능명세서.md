# E09 기능명세서 (스펙)

> **작성 가이드**
> - **목적**: 이 문서가 **스펙**입니다. PRD → E06 REQ를 기능(F)으로 구현 가능하게 정의하고, 인수조건(Given/When/Then), 입출력·데이터 계약, 작업 분해(T), 테스트까지 추적합니다. 개발팀이 있으면 그대로 넘기고(`/edpm-handoff dev`), 바이브코딩이면 7절의 작업 단위로 구현합니다(`/edpm-spec build`).
> - **입력**: E05 LO, E06 REQ, E08 LA, E02 이해관계자(역할), `02.wiki/company/` 개발팀 표준
> - **게이트**: G-PRD(PRD review 이상), G-LEARN — E05가 `done`이어야 완료할 수 있습니다. **G-SPEC** — 이 문서가 `done`이 되기 전에는 제품 코드(`src/`)를 쓰지 않습니다. 모든 F는 LO → REQ → F로 추적되어야 하며, LO에 연결되지 않는 기능은 "운영·지원 기능"으로 따로 표시하고 사유를 적습니다.
> - **검토 패널 (권장)**: 개발 리드, QA, 교사 1명 이상, 운영(CS) 담당
> - 이 문서가 완료되면 E10·E11·E12·E13·E14·E16을 병렬(P3)로 쓸 수 있습니다.
> - 표의 첫 행은 예시 제품 **매스핏**(중학생 수학 오답 코칭, 학원 B2B2C + 학부모 결제, AI 오답 해설) 기준입니다.

## 3. 기능 상세

> 기능마다 아래 블록을 복사합니다. 인수조건은 테스트 가능한 문장으로 쓰고, E16 검증 항목(VA)과 연결합니다.

### F-012. AI 오답 해설 (힌트 사다리) — 예시

| 항목 | 내용 |
|------|------|
| 목적 (학습 관점) | 학습자가 정답을 보기 전에 자기 풀이의 오류 단계를 찾도록 돕는다 (LO-02) |
| 사용자·맥락 | 학습자, 가정 숙제 중 오답 직후 |
| 입력 | 문항 ID, 학습자 풀이 단계(입력식 또는 사진 인식 결과), 시도 횟수 |
| 처리 | 오류 단계 판정 → 힌트 단계 결정(E08 4절) → 생성형 해설은 E14 가드레일 적용 |
| 출력 | 힌트 문구, 오류 단계 하이라이트, 재도전 버튼 |
| 관련 화면 | SCR-004 |
| 관련 이벤트 | EV-03 hint_requested, EV-04 attempt_submitted |
| 관련 AI | AI-01, GR-01~GR-04 (E14) |
| 비기능 | 힌트 응답 3초 이내 [가정], 학교·학원망에서 동작 |

**인수조건**

| AC | Given | When | Then |
|----|-------|------|------|
| AC-1 | 학습자가 문항을 처음 틀렸다 | 결과 화면이 열린다 | 정답은 보이지 않고 "다시 생각해 보기" 안내와 재도전 버튼이 보인다 |
| AC-2 | 재도전도 틀렸다 | 학습자가 "힌트" 를 누른다 | 1단계 힌트(오류 위치)만 보이고 EV-03이 기록된다 |
| AC-3 | 3단계 힌트 후에도 틀렸다 | 재도전을 제출한다 | 정답과 해설이 공개되고 담당 교사에게 막힘 알림이 간다 |
| AC-4 | 교사가 반 설정에서 "정답 공개 금지"를 켰다 | 3단계 후에도 틀린다 | 정답 대신 "선생님께 질문하기"가 보인다 |
| AC-5 | AI 응답이 실패하거나 3초를 넘는다 | 힌트를 요청한다 | 사전 저작된 정적 힌트로 대체되고 오류가 기록된다 |

## 7. 작업 분해와 테스트 추적 (스펙 → 구현)

REQ에서 테스트까지 끊기지 않게 잇습니다. 작업(T) 하나는 하루 이내, 인수조건 하나 이상을 통과시키는 단위입니다. `/edpm-spec tasks`가 이 표를 WBS·GitHub 이슈로 내보내고, `/edpm-spec check`가 끊긴 연결을 찾습니다.

| T-ID | 작업 | F | 통과시킬 AC | 테스트 (자동/수동) | 담당 | 상태 |
|------|------|---|-------------|--------------------|------|------|
| {T-01} | {} | {F-0NN} | {AC-1, AC-2} | {tests/… 또는 수동 절차} | {개발팀 / PM+LLM} | {예정/진행/완료} |
| T-07 (예시) | 힌트 응답 스키마·120자 제한 | F-012 | AC-2 | `tests/test_hint_schema.py` | 개발팀 | 예정 |

추적 예: `PRD 5절 오답 코칭 → REQ-002 → F-012 → AC-2 → T-07 → test_hint_schema`
