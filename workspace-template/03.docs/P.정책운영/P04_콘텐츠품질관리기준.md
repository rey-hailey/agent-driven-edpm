# P04 콘텐츠품질관리기준

> **작성 가이드**
> - **목적**: 콘텐츠 품질 차원과 출시 전 검수 기준, 오류 신고 → 수정 SLA, 리뷰·평점 관리, 데이터 기반 재제작·폐기 기준, 정기 점검 주기를 정합니다. L02 제작 파이프라인의 "검수" 단계 기준이자 P06 강사 등급 평가의 입력입니다.
> - **입력**: L02(제작 단계·검수자), L01(콘텐츠 유형·메타데이터), L03(완료율 정의), E12(재생·이탈 이벤트), P01(환불 사유 코드), P02(권리 확인), E13 (c) 접근성, [[domain/콘텐츠품질관리]]
> - **게이트**: 기본 게이트(L02 `done`). 재제작·폐기 기준의 수치는 모두 SQL·스크립트로 계산하고 경로를 적습니다. LLM이 추정한 완료율·평점은 쓸 수 없습니다.
> - **적용 유형**: AT01·AT02·AT03·AT07·AT08·AT09 (VOD·문항 대량 운영), AT05·AT06 (교과 정확성 검수 필수)
> - **검토 패널 (권장)**: 콘텐츠 운영 리드, 교수설계자, CS 리드, 강사 대표, 법무(리뷰 삭제·광고 표시)
> - **스킬**: `/edpm-policy P04`
> - **주의**: 리뷰 게시 중단·후기 광고 표시 관련 법적 요건은 `[확인 필요]`로 두고 법무 검토를 받습니다. 이 문서는 법률 자문이 아닙니다.
> - 표의 예시 행은 샘플 서비스 **스킬업**(성인 대상 VOD + 라이브 강의 마켓플레이스, 강사 입점·수익배분, 기업 B2B 좌석, 일부 사업주 환급 과정) 기준입니다.

## 3. 오류 신고 → 수정 SLA

| 심각도 | 정의 | 예 | 1차 조치 | 수정 완료 | 통지 |
|--------|------|----|---------|----------|------|
| S1 치명 | 학습을 막거나 잘못 가르침, 권리 침해 | 재생 불가, 틀린 공식, 무단 자료 | {n}시간 내 비공개·안내 배너 | {n}일 | 수강생 전체 |
| S2 중요 | 이해를 방해하는 오류 | 코드 오타, 자막 대량 오류 | {n}일 내 정오표 | {n}일 | 신고자 + 공지 |
| S3 경미 | 품질 저하 | 음량 불균형, 오탈자 | 백로그 | 다음 정기 개정 | 신고자 |
| 예시: S2 | 이해를 방해하는 오류 | 스킬업 SQL 강의 예제 쿼리 오류 | 2일 내 레슨 하단 정오표 [가정] | 14일 내 재촬영 또는 편집 [가정] | 신고자 + 강의 공지 |

신고 경로는 P05 문의 분류 "콘텐츠 오류"와 같습니다. 강사 대응 기한을 넘기면 P06 제재 기준에 반영합니다.

## 4. 리뷰·평점 관리

| 항목 | 정책 |
|------|------|
| 작성 자격 | {구매자 + 진행률 {n}% 이상} |
| 게시 중단 사유 | {욕설·개인정보·광고·허위 사실·무관 내용} [확인 필요: 게시 중단 절차 요건] |
| 강사 답글 | {허용, 기한 권장 {n}일} |
| 평점 조작 대응 | {대가성 리뷰 금지, 이상 패턴 탐지} |

| 예시 | 진행률 20% 이상 구매자만 작성, 리뷰 5건 미만 강의는 "신규" 표시 [가정] |

## 완료 체크리스트

- [ ] 품질 차원마다 측정 방법과 기준이 있다
- [ ] 출시 전 검수 항목마다 검수자가 정해지고 L02 검수 단계와 일치한다
- [ ] 심각도별 SLA가 P05 응답 기준과 충돌하지 않는다
- [ ] 리뷰 게시 중단·대가성 표시 `[확인 필요]`가 법무 검토를 거쳤다
- [ ] 재제작·폐기 신호마다 계산식과 SQL 경로가 있다 (LLM 추정 불가)
- [ ] 폐기 시 기존 구매자 처리와 권리 종료가 P01·P02와 일치한다
- [ ] 정기 점검 주기와 결과 기록 위치가 정해졌다
