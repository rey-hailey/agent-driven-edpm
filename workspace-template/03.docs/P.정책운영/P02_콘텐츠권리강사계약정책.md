# P02 콘텐츠권리·강사계약정책

> **작성 가이드**
> - **목적**: 강의 콘텐츠의 권리 귀속 모델, 이용 허락 범위(지역·기간·매체·2차 이용), 제3자 자료 처리, 계약 종료 후 처리, 강사 계약서에 들어갈 조항을 정합니다. L02 제작, A07 자막·번역, S07 정산, P04 폐기 결정의 권리 기준이 됩니다.
> - **입력**: L01(콘텐츠 유형·번들 구조), L02(외주·촬영 주체), S06(수익 모델), A00·A07(AI 학습·번역 계획), [[domain/강사계약과콘텐츠권리]], [[domain/교육저작권]]
> - **게이트**: 기본 게이트(L01 `done`). G-POLICY 직접 대상은 아니지만, S07(강사 정산)이 수익배분율 근거로 이 문서의 계약 모델을 참조합니다. AI 학습·생성에 콘텐츠를 쓰면 A01 지식 소스의 이용 허락 상태와 일치해야 합니다.
> - **적용 유형**: AT01·AT03·AT04·AT08·AT09 (외부 강사 콘텐츠), AT05·AT06 (교재·문항 외주), AT10 (AI 학습 데이터)
> - **검토 패널 (권장)**: 법무, 콘텐츠 운영 리드, 강사 대표(입점 강사 관점), 재무, CS(삭제 요청 대응)
> - **스킬**: `/edpm-policy P02`
> - **주의**: 이 문서는 법률 자문이 아닙니다. 저작권 귀속·저작인격권·공정 이용·교육 목적 이용 범위는 모두 `[확인 필요]`로 두고 법무 검토를 받습니다.
> - 표의 예시 행은 샘플 서비스 **스킬업**(성인 대상 VOD + 라이브 강의 마켓플레이스, 강사 입점·수익배분, 기업 B2B 좌석, 일부 사업주 환급 과정) 기준입니다.

## 완료 체크리스트

- [ ] 상품군마다 권리 귀속 모델과 사유가 있다
- [ ] 2절 매트릭스에 지역·기간·매체·독점·종료 후 처리가 모두 있다
- [ ] AI 학습·번역·더빙 등 2차 이용별 동의 방식이 정해지고 A01·A07과 일치한다
- [ ] 제3자 자료 체크리스트 전 항목에 판정이 있다
- [ ] 게시 중단 절차와 기존 구매자 처리가 P01·P05와 충돌하지 않는다
- [ ] 강사 계약서 조항 체크리스트가 법무 검토를 거쳤다
- [ ] `[확인 필요]` 항목마다 확인 담당과 기한이 있다
- [ ] [[domain/교육저작권]] 페이지의 `verified` 날짜가 180일 이내다
