# P08 AI품질·안전정책

> **작성 가이드**
> - **목적**: AI가 틀린 내용을 말하거나(할루시네이션) 대상 연령에 맞지 않거나 해로운 내용을 다룰 때, 회사가 어떻게 예방·탐지·정정·통지하는지와 사람 검토 기준, 사고 등급, 지표·검토 주기를 운영 정책으로 정합니다. A14가 "무엇을 어떻게 막는가"(기술 통제)라면, P08은 "막지 못했을 때 누가 언제 무엇을 하는가"(운영 약속)입니다.
> - **입력**: A14(입력·출력 통제 GD, 층 구성, 오탐·미탐), E14(GR, 평가 세트·합격 기준, 사람 개입), A06(평가 결과), A13(모니터링 지표 OP), E13(d1·d4·d6, b5 위기 신호 절차), P04(콘텐츠 오류 신고·수정 SLA), P05(CS 채널·민원), [[domain/할루시네이션대응]], [[domain/AI콘텐츠안전정책]], [[domain/아동개인정보보호]]
> - **게이트**: 기본 게이트(A14 `done`). **G-AI**와 연결됩니다. G-AI는 출시 전 평가 합격을 보고, P08은 출시 후에도 같은 기준(3절 환각률, 안전 100%)을 유지하는 운영 약속입니다. 2.3절 위기 신호 절차가 E13 b5·d6의 근거가 되어야 하며, 상담전화·신고 의무가 `[확인 필요]`로 남아 있으면 `done` 처리하지 않습니다.
> - **검토 패널 (권장)**: 법무, 보안 담당, AI 엔지니어, CS 리드, (보완) 콘텐츠팀장, 상담·생활지도 경험 교사
> - **스킬**: `/edpm-policy P08`
> - **주의**: 이 문서는 법률 자문이 아닙니다. 아동학대 신고 의무자 범위, 위기 상황 정보의 제3자 제공 근거, 상담전화 번호·운영 시간은 `[확인 필요]`로 두고 법무·개인정보 보호책임자가 확인합니다.
> - 표의 예시 행은 샘플 서비스 **매스핏**(중학생 만 12~15세 수학 오답 코칭 AI) 기준입니다. 수치는 `[가정]`입니다.

### 2.2 모더레이션 파이프라인

학습자 입력 → 규칙 필터(금칙어·개인정보 마스킹) → 안전 분류기(위기 신호면 2.3절, 차단 범주면 거절 문구 + 기록) → LLM 생성 → 출력 필터(연령 어휘·정답 노출·유해성, 차단 시 재생성 1회 후 정적 응답) → 학습자 화면. 세부 통제(GD-ID)와 오탐·미탐 기준은 A14에 둡니다.

- [ ] 할루시네이션 심각도가 정의되고 심각도별 정정 SLA·통지·승인자가 있다
