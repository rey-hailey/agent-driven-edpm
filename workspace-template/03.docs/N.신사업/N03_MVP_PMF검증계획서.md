# N03 MVP·PMF검증계획서

> **작성 가이드**
> - **목적**: 투자 승인을 받은 검증 단계에서 "무엇을 만들고 무엇을 만들지 않을지", "어떤 실험으로 어떤 가설을 검증할지", "어떤 신호가 나오면 확장할지"를 결과를 보기 **전에** 확정합니다. 이 문서의 GT 기준이 N04 단계 심사의 판정 기준이 됩니다.
> - **입력**: N02(승인 예산·기간·다음 게이트 기준), N01(HY 가설·중단 기준), E06 제품요구사항서(MVP REQ), E05(LO), E07(M-ID), E16 검증계획서(학습 효과 설계), E13(미성년이면), [[domain/효과크기와증거수준]]
> - **게이트**: N02·E06이 `done`이어야 합니다. 모든 HY에 실험·지표·기준·표본·기간이 있어야 하고, GT 기준은 실험 시작 전에 확정합니다(나중에 바꾸면 ADR). 미성년 대상이면 E13이 `done`이고 출시 차단 0건이어야 파일럿을 시작합니다(G-SAFE). 지표는 SQL·스크립트로 계산합니다. MVP·파일럿은 이 범위 안에서 가능하지만 정식 출시(E18)는 N04 "확장 진행" 후입니다(G-STAGE).
> - **독자**: 경영진·투자심의(3·5·8절), 제품·데이터 팀(나머지).
> - **검토 패널 제안**: 경영진 스폰서, 학습과학 자문, 데이터 분석가, 개인정보 담당, 교사·원장 패널
> - **스킬**: `/edpm-venture mvp`
> - 예시 행은 가상 신사업 **리딩버디**(유아 영어 리딩 신규 앱 — 만 5~9세, 가정 구독 + 영어학원 B2B2C, AI 음성 리딩 피드백) 기준이며 **모든 수치는 형식을 보여주는 [가정] 값**입니다.

## 4. 윤리와 동의 (미성년 파일럿)

| 항목 | 계획 |
|------|------|
| 동의 | 법정대리인 동의서(수집 항목·음성 녹음·보관 기간·철회 방법), 아동용 쉬운 말 설명 |
| 최소 수집 | {필요한 항목만, 음성 원본 보관 여부} |
| 보관·파기 | {기간, 파기 일정, 회사 승인 저장소 위치} |
| 외부 AI | 비식별화 전 음성·텍스트를 외부 API로 보내지 않음 (AGENTS.md 7장) |
| 아동 보호 | {사용 시간 상한, 광고 없음, 철회 시 데이터 삭제} |
| 예시 | 녹음은 피드백 생성 후 30일 내 삭제 [가정], 벤더 위탁 계약에 학습 이용 금지 조항 [확인 필요] |

세부 판정은 E13, 동의 절차는 E16 3.1절을 따릅니다.

## 5. PMF·학습 효과 신호 (GT)

리텐션·결제만으로 PMF를 판단하지 않습니다. 학습 효과 신호를 반드시 포함합니다.

| GT-ID | 신호 | 정의 (계산식) | 기준 | 계산 경로 | 성격 |
|-------|------|---------------|------|-----------|------|
| GT-01 | 리텐션 곡선 평탄화 | 주간 코호트 활성 비율이 n주 차 이후 감소 멈춤 | {} | {SQL} | 필수 |
| GT-02 | 활성화 | 가입 후 7일 내 핵심 행동 완료 비율 | {} | {} | 필수 |
| GT-03 | 지불 의향 | 유료 전환율·사전 결제율 | {} | {} | 필수 |
| GT-04 | 학습 효과 신호 | E16 설계의 사전·사후 지표 변화 | {} | {} | 필수 |
| GT-05 | 교사·학부모 도입 (B2B2C) | 유료 전환 기관 수, 교사 주간 사용률 | {} | {} | 해당 시 |
| GT-06 | Sean Ellis 설문 | "더 이상 못 쓰면 매우 실망" 응답 비율 | 40% 이상 | 설문 집계 스크립트 | 참고 (휴리스틱) |
| 예시: GT-04 | 학습 효과 | 4주 사용 전후 분당 정확히 읽은 단어 수(WCPM) 변화 | 효과크기 d ≥ 0.2, 비교집단 대비 [가정] | `automation/scripts/N03_wcpm.py` | 필수 |
| 예시: GT-01 | 리텐션 | 주간 활성 가구 비율이 4주 차 이후 35% 이상에서 평탄 [가정] | 35% | `automation/sql/N03_retention.sql` | 필수 |

- GT-06(Sean Ellis 40%)은 업계 휴리스틱이며 표본이 작으면 신뢰하기 어렵습니다. 단독 판정 근거로 쓰지 않습니다.
- GT-04의 연구 설계·표본 근거·타당도 위협은 E16 4절에 둡니다. 소표본이면 증거 수준을 낮춰 보고합니다([[domain/효과크기와증거수준]]).
