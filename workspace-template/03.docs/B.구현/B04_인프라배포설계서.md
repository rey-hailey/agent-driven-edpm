```mermaid
graph LR
    PR[PR 생성] --> L[lint·타입 검사] --> T[단위·통합 테스트] --> P[PII 정규식 검사] --> B[빌드] --> S[staging 배포] --> R[R05 역할별 스모크] --> A{승인·동결 확인} --> PR2[prod 배포]
```

| 단계 | 내용 | 실패 시 |
|------|------|---------|

| 동결 확인 | 배포일이 E15 FZ 기간인지 확인 | 핫픽스 절차로만 진행 |
| 롤백 | {방법, 목표 시간} | 예시: 직전 배포로 즉시 되돌리기, DB 마이그레이션은 되돌릴 수 있게 작성 |

4. 법무 검토 → 신고·통지 여부와 기한 결정
