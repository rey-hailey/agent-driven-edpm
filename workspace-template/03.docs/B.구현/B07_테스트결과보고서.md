# B07 테스트결과보고서

> **작성 가이드**
> - **목적**: B06 테스트를 실제로 실행한 결과를 모으고, 결함(DF)과 남은 위험을 정리해 릴리즈 권고를 냅니다.
> - **입력**: B06 TC 목록, 테스트 실행 기록(자동 테스트 리포트, R05·R06 결과, 수동 실행 기록), B04 모니터링·부하 결과, E13 RK
> - **게이트 (실체 검증)**: 테스트 실행 기록(`01.자료실/데이터/`의 결과 파일 또는 테스트 코드 경로)이 없으면 `done`이 될 수 없습니다. 수치는 실행 리포트에서 집계한 값만 쓰고, LLM이 추정하지 않습니다. 이 문서는 M05 완료보고서의 입력입니다.
> - **작성 스킬**: `/edpm-qa B07`
> - **검토 패널 (권장)**: QA, 개발 리드, 보안 담당, 접근성 점검자, 개인정보 보호책임자, PM
> - 표의 첫 행은 예시 제품 **매스핏**(중학생 만 12~15세, 학원 B2B2C + 학부모 결제, AI 오답 해설) 기준입니다.
