# F04 출시후효과리뷰 — {과제명}

> **작성 가이드**
> - **목적**: F02에서 정한 목표 지표를 **같은 SQL**로 다시 계산해 효과를 판정하고, 유지·개선·롤백을 결정하고, 배운 것을 백로그와 위키에 돌려줍니다. 리뷰까지가 과제입니다.
> - **입력**: F02 목표 지표, F03 실험 설계(EX)·가드레일, SQL 실행 결과(`01.자료실/데이터/`), VOC·CS 티켓, 이해관계자 의견
> - **게이트**: **G-MEASURE** — F02의 지표를 같은 SQL로 계산한 결과 경로가 없으면 완료할 수 없습니다. 판정 기준을 F03 이후 바꿨다면 ADR이 있어야 합니다. LLM이 수치를 추정하지 않습니다.
> - **분량**: 한두 쪽.
> - **검토 패널 (권장)**: PO, 데이터 분석가, CS 리드, 요청한 이해관계자 대표
> - **스킬**: `/edpm-feature review`
> - 예시는 캠퍼스온 FI-007 "과제 제출 마감 연장 신청·승인 흐름"이며 수치는 [가정]입니다.
