# F03 실험·출시계획서 — {과제명}

> **작성 가이드**
> - **목적**: 기능을 어떻게 내보내고 효과를 어떻게 판단할지를 출시 **전에** 확정합니다. 실험 설계, 기능 플래그·단계 출시, 중단·롤백 기준, 공지·CS 준비를 담습니다.
> - **입력**: F02 기능기획서(목표 지표, 영향 점검표), 학사일정·성수기 캘린더, P05 고객지원 정책
> - **게이트**: **G-IMPACT** — F02 영향 점검표가 모두 처리되어야 이 문서를 완료할 수 있습니다. **G-CAL** — 5절 시즌 점검이 필요합니다. 판정 기준은 결과를 보기 전에 정하고, 나중에 바꾸면 ADR을 남깁니다.
> - **분량**: 한두 쪽.
> - **검토 패널 (권장)**: 데이터 분석가, 개발 리드, CS 리드, 기관·교수자 대표, (학습 효과 실험이면) 학습과학 자문
> - **스킬**: `/edpm-feature launch`
> - 예시는 캠퍼스온 FI-007 "과제 제출 마감 연장 신청·승인 흐름"이며 수치는 [가정]입니다.
