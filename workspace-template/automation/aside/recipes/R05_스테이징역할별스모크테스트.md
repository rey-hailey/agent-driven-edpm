# R05. 스테이징 역할별 스모크 테스트

**목적**: 새 배포 후 학습자·교사·보호자 테스트 계정으로 핵심 흐름이 동작하는지 확인하고 증거를 남긴다.

## Aside 지시문

`{OUT}`은 실행 스크립트가 `00.inbox/R05_YYYYMMDD_HHMM.md`로 바꿉니다. 나머지 `{...}`는 처음 쓸 때 채웁니다.

```aside
{스테이징 URL}을 연다. 아래 테스트 계정으로 차례로 로그인한다. 계정은 모두 가상 데이터만 가진 테스트 계정이다: {역할: 계정 식별자 — 비밀번호는 Aside Vault에 저장된 항목 사용}.
역할마다 다음 흐름을 실행한다: {예: 학습자 — 오늘의 문제 풀기 → 오답 해설 보기 / 교사 — 반 현황 보기 → 과제 배정 / 보호자 — 주간 리포트 보기}.
단계마다 성공/실패, 걸린 시간 체감(빠름/보통/느림), 오류 메시지 원문을 기록하고, 단계 끝 화면을 데스크톱과 모바일 크기로 스크린샷한다.
실제 학생 이름이 화면에 보이면 즉시 중단하고 그 사실만 기록한다.
결과를 {OUT} 파일로, 스크린샷은 같은 이름의 폴더에 저장한다.
```

## 출력 형식

역할별 표(단계|결과|체감 속도|오류 원문|스크린샷 경로), 실패 요약, E16 VA 항목 연결

## 수동 대체

테스트 시나리오(E16)를 보고 직접 실행하거나 webapp-testing 스킬(Playwright)로 자동화한다.
