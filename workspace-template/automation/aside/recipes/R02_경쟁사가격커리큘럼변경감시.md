# R02. 경쟁사 가격·커리큘럼 변경 감시

**목적**: 경쟁 서비스의 요금제, 학원·학교용 플랜, 커리큘럼 구성 변화를 추적한다.

## Aside 지시문

`{OUT}`은 실행 스크립트가 `00.inbox/R02_YYYYMMDD_HHMM.md`로 바꿉니다. 나머지 `{...}`는 처음 쓸 때 채웁니다.

```aside
다음 경쟁 서비스의 공개 페이지를 연다: {서비스명: 요금제 URL, 커리큘럼·과정 URL 목록}.
각 서비스에서 요금제 이름, 가격, 결제 주기, 대상(개인/학원/학교/기업), 포함 기능, 무료 체험 조건, 커리큘럼(과목·학년·단원 수)을 표로 정리한다.
02.wiki/market/ 아래 해당 경쟁사 페이지의 이전 값이 아래에 주어지면 달라진 항목만 따로 표시한다: {이전 값 요약 또는 '없음'}.
로그인이 필요한 페이지는 열지 않는다.
모든 가격 옆에 그 가격을 확인한 페이지 URL을 적는다.
결과를 {OUT} 파일로 저장한다.
```

## 출력 형식

서비스별 표(요금제|가격|주기|대상|포함 기능|URL), 변경 사항 목록, 확인 불가 항목

## 수동 대체

Obsidian Web Clipper로 요금제 페이지를 클리핑해 00.inbox에 넣는다.
