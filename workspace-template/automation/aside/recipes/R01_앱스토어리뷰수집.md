# R01. 앱스토어 리뷰 수집

**목적**: 경쟁·자사 학습앱의 최근 리뷰에서 학습자·보호자의 불만과 기대를 모은다.

## Aside 지시문

`{OUT}`은 실행 스크립트가 `00.inbox/R01_YYYYMMDD_HHMM.md`로 바꿉니다. 나머지 `{...}`는 처음 쓸 때 채웁니다.

```aside
Google Play와 App Store에서 다음 앱의 리뷰 페이지를 연다: {앱 이름과 스토어 URL 목록}.
각 앱에서 최근 {14}일 안에 작성된 리뷰를 최대 {50}개 읽는다.
리뷰마다 날짜, 별점, 작성자 유형 추정(학생/보호자/교사/불명), 리뷰 본문 요약(2문장 이내), 언급된 기능, 감정(긍정/부정/혼합)을 기록한다.
작성자 닉네임과 프로필 정보는 기록하지 않는다.
결과를 마크다운 표로 만들고, 앱별로 자주 나온 불만 3개와 칭찬 3개를 정리한다.
각 앱 섹션 맨 위에 리뷰 페이지 URL과 수집 시각을 적는다.
결과를 {OUT} 파일로 저장한다.
```

## 출력 형식

앱별 섹션: 출처 URL, 수집 시각, 리뷰 표(날짜|별점|작성자 유형|요약|기능|감정), 불만 Top3, 칭찬 Top3

## 수동 대체

스토어 페이지를 직접 열어 리뷰를 복사하거나, 리뷰 분석 도구의 CSV 내보내기를 00.inbox에 넣는다.
