# R07. 집계 대시보드 주간 캡처

**목적**: 분석 도구·어드민의 집계 화면에서 주간 지표를 캡처해 주간보고와 E07 추적에 쓴다.

## Aside 지시문

`{OUT}`은 실행 스크립트가 `00.inbox/R07_YYYYMMDD_HHMM.md`로 바꿉니다. 나머지 `{...}`는 처음 쓸 때 채웁니다.

```aside
{대시보드 URL}을 연다. 이 화면은 개인 식별 정보 없이 집계 수치만 보여주는 화면이다.
기간을 {지난 7일}로 맞추고 다음 지표의 값과 지난주 대비 변화를 기록한다: {예: 주간 활성 학습자, 과제 완료율, 교사 주간 활성, 오답 해설 열람률}.
화면 전체를 스크린샷한다.
학생 목록이나 개인별 상세 화면으로 이동하지 않는다. 개인 이름이 보이면 중단하고 그 사실만 기록한다.
결과를 {OUT} 파일로 저장한다.
```

## 출력 형식

표(지표|값|지난주|변화|화면 위치), 스크린샷 경로. 수치는 참고값이며 공식 수치는 SQL 결과를 따른다

## 수동 대체

분석 도구의 CSV 내보내기를 00.inbox에 넣는 것이 더 정확하다. 가능하면 이 방법을 우선한다.
