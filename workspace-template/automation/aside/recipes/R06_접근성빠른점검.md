# R06. 접근성 빠른 점검

**목적**: 학습 화면의 기본 접근성 문제를 빠르게 찾는다. 전문 진단을 대신하지 않는다.

## Aside 지시문

`{OUT}`은 실행 스크립트가 `00.inbox/R06_YYYYMMDD_HHMM.md`로 바꿉니다. 나머지 `{...}`는 처음 쓸 때 채웁니다.

```aside
{점검할 화면 URL 목록}을 연다.
화면마다 다음을 확인한다: 키보드만으로 주요 버튼까지 이동할 수 있는지, 포커스 표시가 보이는지, 이미지에 대체 텍스트가 있는지, 글자와 배경의 대비가 낮아 보이는 곳, 터치 대상이 너무 작은 곳, 영상에 자막이 있는지, 화면 확대 200%에서 내용이 잘리는지.
문제마다 화면, 위치, 증상, 관련 WCAG 항목(추정이면 '추정'), 스크린샷 경로를 적는다.
결과를 {OUT} 파일로 저장한다.
```

## 출력 형식

화면별 표(위치|증상|WCAG 항목|심각도|스크린샷), 요약

## 수동 대체

브라우저 개발자 도구의 Lighthouse 접근성 점검과 키보드 수동 점검을 함께 한다. 결과는 E13 (c)절에 반영.
