# R08. 공개 커뮤니티 VOC 수집

**목적**: 공개 커뮤니티에서 보호자·교사·학습자가 학습 도구에 대해 말하는 내용을 모은다.

## Aside 지시문

`{OUT}`은 실행 스크립트가 `00.inbox/R08_YYYYMMDD_HHMM.md`로 바꿉니다. 나머지 `{...}`는 처음 쓸 때 채웁니다.

```aside
다음 공개 게시판·검색 결과 페이지를 연다: {커뮤니티 검색 URL 목록 — 로그인 없이 볼 수 있는 곳만}.
검색어 {예: 수학 오답 앱, 학원 숙제 앱, 자기주도학습 앱 추천}으로 최근 {14}일 글을 최대 {30}개 읽는다.
글마다 날짜, 게시판, 작성자 유형 추정(보호자/교사/학생/불명), 내용 요약(2문장), 언급된 서비스, 고민·요구를 기록한다.
작성자 닉네임, 자녀 이름·학교·지역 등 개인 정보는 기록하지 않는다. 글 원문을 길게 옮기지 않는다.
커뮤니티 이용 규칙이 자동 수집을 금지하면 그 사이트는 건너뛰고 건너뛴 사실을 적는다.
결과를 {OUT} 파일로 저장한다.
```

## 출력 형식

표(날짜|게시판|작성자 유형|요약|언급 서비스|요구), 주제별 묶음, 건너뛴 사이트

## 수동 대체

직접 검색해 링크와 요약만 메모한다. 원문 캡처는 개인정보가 섞이기 쉬우므로 피한다.
