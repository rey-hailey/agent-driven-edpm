## 레시피 작성 규칙

1. frontmatter에 `id`, `title`, `pii_risk`, `schedule`, `ingest_to`, `verified_with_aside`를 둡니다.
2. 지시문은 ```` ```aside ```` 블록 하나에 씁니다. 결과 저장 위치는 `{OUT}`으로 둡니다.
3. 지시문에 반드시 넣을 것: 열 페이지, 기간, 기록할 필드, **기록하지 말 것(개인 정보)**, 출처 URL 기록, 로그인·결제·제출 단계로 넘어가지 말 것.
4. 숫자·가격·날짜는 원문 URL과 함께 기록하게 합니다. 브라우저 에이전트 결과는 틀릴 수 있습니다.
5. `pii_risk: high`인 작업(학생 목록, 성적 상세, 상담 기록 화면)은 레시피로 만들지 않습니다.
6. 사이트 이용약관이 자동 수집을 금지하면 그 사이트는 레시피에서 뺍니다.
7. "수동 대체" 절을 꼭 씁니다. Aside가 없거나 바뀌어도 일이 멈추지 않게 합니다.
