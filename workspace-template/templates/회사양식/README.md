# 회사 문서 양식

EdPM이 만드는 산출물(`PRD.md`, `03.docs/`)은 **프레임워크 템플릿에서 출발한 초안**입니다. 템플릿의 예시 행(매스핏·리딩버디·캠퍼스온 등)은 가상이며, 절 구성은 에듀테크 PM에게 필요한 항목을 빠뜨리지 않기 위한 기본값입니다. 회사에 정해진 문서 양식이 있으면 둘 중 하나로 맞춥니다.

| 방식 | 언제 | 어떻게 |
|------|------|--------|
| **A. 회사 양식을 적용** | 회사 PRD·기획서·보고서 양식이 정해져 있고, 처음부터 그 구조로 쓰고 싶을 때 | 회사 양식을 md로 구조화해 이 폴더에 넣고(`/edpm-template import`), `양식매핑.md`에 EdPM 산출물과 짝지음. 이후 `/edpm-doc`이 그 산출물을 **회사 양식의 절 구조로** 씁니다 |
| **B. 산출물을 회사 양식으로 옮기기** | 양식이 느슨하거나, EdPM 산출물로 먼저 정리한 뒤 회사 기준에 맞춰 내보내고 싶을 때 | `/edpm-template apply <ID>` — EdPM 산출물 내용을 회사 양식 구조로 옮긴 출력본을 `05.outputs/`에 만듭니다 (docx·pptx 변환 가능) |

## 어느 방식이든 지키는 것

- **EdPM 산출물이 원본입니다.** frontmatter(`doc_id`, `status`, `requires`)와 게이트가 보는 항목(예: F02 목표 지표·영향 점검표, E13 판정, V01 성공·중단 기준)은 회사 양식에 없더라도 지우지 않습니다. 방식 A에서는 회사 양식 절 뒤에 **"EdPM 필수 항목"** 절로 남기고, 방식 B에서는 원본에 그대로 둡니다. 그래야 진행표·게이트·추적이 계속 동작합니다.
- 회사 양식에만 있는 항목(결재란, 문서 번호, 보안 등급 등)은 방식 A면 산출물에 같이 쓰고, 방식 B면 출력본에서 채웁니다.
- 회사 양식 파일에는 실제 고객·학생 정보를 넣지 않습니다 (빈 양식만).

## 파일

| 파일 | 내용 |
|------|------|
| `양식매핑.md` | 회사 문서 ↔ EdPM 산출물 ID 대응표, 방식(A/B), 회사 양식에 없는 EdPM 필수 항목 |
| `<회사 문서명>.md` | md로 구조화한 회사 양식 (절 제목, 표 열, 작성 지침, 결재·보안 항목) |
