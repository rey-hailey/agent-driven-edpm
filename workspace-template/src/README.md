# src — 제품 코드

제품 코드는 **스펙(E09)이 `done`이 된 뒤**에만 이 폴더에 씁니다 (G-SPEC, PreToolUse 훅이 막음). 검증용 spike·프로토타입 코드는 `06.prototypes/`에 둡니다.

| 개발 체계 (`AGENTS.md` 2절) | 이 폴더 |
|-----------------------------|---------|
| 개발팀 | 비워 둡니다. 코드는 개발팀 저장소에 있고, PM은 `/edpm-handoff dev`로 스펙을 넘깁니다 |
| 바이브코딩 (개발자 없이 PM이 LLM과 구현) | `/edpm-spec build T-xx`로 E09 7절의 작업 단위대로 구현합니다. 작업마다 테스트를 `tests/`에 같이 씁니다 |

규칙: 비밀값은 `.env`(커밋 금지), 작업 하나 = 커밋 하나(`[T-07] 힌트 응답 스키마`), 스펙과 다르게 만들어야 하면 스펙부터 고칩니다.
