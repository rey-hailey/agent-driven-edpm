# 에듀테크 용어집

한 줄 정의입니다. 정책 용어(늘봄학교, 디지털교과서 등)는 제도가 자주 바뀌므로 사용 전 최신 공고를 확인합니다. 관련 페이지가 있으면 링크합니다.

## 교육과정·수업

| 용어 | 정의 | 관련 페이지 |
|------|------|-------------|
| 성취기준 | 교과별로 학생이 학습 결과로 알고 할 수 있어야 하는 것을 진술한 국가 교육과정의 기준 문장 | [[domain/역방향설계]] |
| 교육과정 | 무엇을 어떤 순서·시간으로 가르칠지 정한 체계. 한국은 국가 수준 교육과정(현행 2022 개정)을 학교가 편성·운영 [확인 필요: 학년별 적용 시기] | [[domain/역방향설계]] |
| 차시 | 한 번의 수업 단위. 초등 40분, 중학 45분, 고교 50분이 일반적 [확인 필요] | [[domain/학사일정]] |
| 단원 | 여러 차시를 묶은 학습 주제 단위 | |
| 학년도 | 3월 1일부터 다음 해 2월 말일까지의 학교 운영 연도 (초·중등교육법 제24조) | [[domain/학사일정]] |
| 방과후학교 | 정규 수업 이후 학교에서 운영하는 선택형 교육 프로그램 | [[domain/세그먼트별의사결정구조]] |
| 늘봄학교 | 초등학생 대상으로 방과후 프로그램과 돌봄을 통합해 정규 수업 전후에 제공하는 정부 정책 [확인 필요: 연도별 확대 범위] | [[domain/세그먼트별의사결정구조]] |
| 디지털교과서 | 서책형 교과서를 디지털로 구현한 교과용도서. AI 디지털교과서는 2025.8.4. 국회 통과 개정안으로 교육자료로 규정됨 [확인 필요: 공포·시행일] | [[domain/세그먼트별의사결정구조]] |
| 학교운영위원회 | 학교 운영의 주요 사항을 심의하는 학교 단위 기구(교원·학부모·지역위원). 교육자료·소프트웨어 선정 심의에 관여 | [[domain/아동개인정보보호]] |

## 평가·학습과학

| 용어 | 정의 | 관련 페이지 |
|------|------|-------------|
| 진단평가 | 학습 시작 전 선수 지식과 수준을 확인하는 평가 | [[domain/숙달학습]] |
| 형성평가 | 학습 도중 이해 상태를 확인해 수업·학습을 조정하는 평가 | [[domain/형성평가와피드백]] |
| 총괄평가 | 단원·학기 끝에 성취 수준을 판정하는 평가 (중간·기말고사 등) | [[domain/형성평가와피드백]] |
| 수행평가 | 과제 수행 과정과 결과를 관찰·채점하는 평가 방식 | [[domain/역방향설계]] |
| 오개념 | 학습자가 가진, 과학적·학문적 개념과 다른 체계적인 잘못된 이해 | [[domain/형성평가와피드백]] |
| 비계 (scaffolding) | 학습자가 혼자 못하는 과제를 해내도록 주는 일시적 지원. 숙련되면 점차 거둠(fading) | [[domain/인지부하이론]] |
| 근접발달영역 (ZPD) | 혼자서는 못하지만 도움을 받으면 할 수 있는 수준의 범위 (Vygotsky) | [[domain/숙달학습]] |
| 인출연습 | 기억에서 내용을 꺼내 보는 학습 활동. 시험 효과 | [[domain/인출연습]] |
| 간격 반복 | 시간 간격을 두고 나눠 복습하는 학습법 | [[domain/간격반복]] |
| 숙달 학습 | 성취 기준을 고정하고 학습 시간을 다양화하는 수업 모델 | [[domain/숙달학습]] |
| 인지부하 | 학습 중 작업기억에 걸리는 처리 부담 | [[domain/인지부하이론]] |
| 역방향 설계 (UbD) | 목표→평가 증거→학습 활동 순서로 설계하는 방법 | [[domain/역방향설계]] |
| 메타인지 | 자신의 이해와 학습 과정을 점검·조절하는 능력 | [[domain/블룸분류체계]] |

## 측정·데이터

| 용어 | 정의 | 관련 페이지 |
|------|------|-------------|
| 적응형 학습 | 학습자 응답 데이터에 따라 콘텐츠·난이도·경로를 개인별로 조정하는 방식 | [[domain/숙달학습]] |
| 문항반응이론 (IRT) | 문항 난이도·변별도와 학습자 능력을 같은 척도에서 추정하는 측정 이론 | [[domain/학습분석지표]] |
| 지식추적 (knowledge tracing) | 응답 이력으로 학습자의 기술별 숙달 상태를 추정하는 모형 (BKT, DKT 등) | [[domain/학습분석지표]] |
| 효과크기 | 처치·비교 집단 차이를 표준편차 단위로 나타낸 값 (Cohen's d, Hedges' g) | [[domain/효과크기와증거수준]] |
| 학습 시간 (time-on-task) | 학습 과제에 쓴 시간. 로그 측정 시 비활동 기준에 따라 값이 크게 변함 | [[domain/학습분석지표]] |
| 안티 메트릭 | 최적화하면 학습이나 안전을 해칠 수 있어 목표로 삼지 않는 지표 | [[domain/학습분석지표]] |
| LRS | xAPI 학습 기록을 저장하는 Learning Record Store | [[domain/상호운용표준]] |

## 제품·시스템

| 용어 | 정의 | 관련 페이지 |
|------|------|-------------|
| 코스웨어 | 교육과정에 맞춰 학습 콘텐츠·연습·평가를 묶은 교육용 소프트웨어 | |
| LMS | 수강 등록, 과제, 성적, 콘텐츠 배포를 관리하는 학습관리시스템 | [[domain/상호운용표준]] |
| LXP | 추천·큐레이션 중심의 학습경험플랫폼. 주로 기업교육에서 LMS 보완 | [[domain/상호운용표준]] |
| LTI | LMS에서 외부 학습 도구를 안전하게 실행·연동하는 1EdTech 표준 | [[domain/상호운용표준]] |
| SSO | 한 번 로그인으로 여러 서비스를 쓰는 인증 방식. 학급 수업 시간 절약에 중요 | [[domain/교사참여설계]] |
| 교사 대시보드 | 학급·학생별 학습 상태를 교사에게 보여 주는 화면 | [[domain/교사참여설계]] |

| 학원 원장 | 학원 사업자이자 B2B2C에서 도입 결정자 | [[domain/세그먼트별의사결정구조]] |

| 좌석제 (seat-based) | 사용자(학생·교사) 수 단위로 라이선스를 판매하는 과금 방식 | [[domain/세그먼트별의사결정구조]] |
| 좌석 활성화율 | 구매한 좌석 중 실제 사용하는 비율. 갱신의 선행 지표 | [[domain/학습분석지표]] |
| NRR | 순매출유지율. 기존 고객 매출이 갱신·확대·축소·해지 후 얼마나 유지·성장했는지의 비율 | [[domain/학습분석지표]] |
| 법정대리인 동의 | 만 14세 미만 아동 개인정보 처리 시 보호자에게 받는 동의 (개인정보 보호법 제22조의2) | [[domain/아동개인정보보호]] |
| 고영향 인공지능 | AI 기본법상 생명·안전·기본권에 중대한 영향을 줄 수 있는 영역의 AI. 초·중등 학생 평가 포함 | [[domain/아동개인정보보호]] |
| 수업목적 보상금 | 저작권법 제25조에 따라 교육기관이 수업 목적 이용에 내는 보상금. 고교 이하 학교는 면제 | [[domain/교육저작권]] |

## 교육과정 데이터

| 용어 | 정의 | 관련 페이지 |
|------|------|-------------|
| 성취기준 코드 | 학년(군)·교과·영역·순번을 나타내는 코드. 예: [9수02-04] (9=중학교, 수=수학, 02=영역, 04=순번), [2국01-01] (2=초1~2학년군), [10공국1-01-01] (고교 공통국어1) | [[domain/교육과정지식그래프]] |
| 앵커 토픽 | 지식그래프에서 성취기준의 핵심을 나타내는 대표 세부 토픽 (성취기준당 1개) | [[domain/교육과정지식그래프]] |
| 공식 선수 관계 / 권장 순서 | 공식 문서가 명시한 선수 관계(official) / 데이터 작성자가 제안한 순서(candidate). 권장 순서를 필수로 쓰지 않음 | [[domain/교육과정지식그래프]] |
| 전환기 격차 | 학교급이 바뀔 때 교육과정 문서상 연계가 명시되지 않은 정도. 성취도 지표 아님 | [[domain/전환기학습격차]] |
| 교육과정 커버리지 | 우리 콘텐츠가 대상 범위 성취기준 중 몇 개를 다루는지의 비율 | [[domain/교육과정지식그래프]] |
