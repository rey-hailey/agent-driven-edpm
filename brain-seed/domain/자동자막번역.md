# 자동 자막·번역·더빙

> A07 자동자막·번역설계서를 쓸 때 참고. 자막은 "있으면 좋은 부가 기능"이 아니라 청각장애 학습자에게는 접근 자체이고, 소음 환경·비원어민 학습자에게도 학습 도구다.

## 핵심 요약

- 파이프라인: **음성 추출 → STT(음성 인식) → 용어집 기반 교정 → 분절·타이밍 → 사람 검수 → (번역) → (더빙) → 게시·피드백**.
- 강의 자막 오류의 대부분은 **전문 용어·고유명사·수식·코드**에서 생긴다. 과정별 용어집이 품질을 가장 싸게 올린다.
- 분절 기준 참고값: 넷플릭스 한국어 자막 가이드는 **한 줄 16자**(라틴 문자·공백·문장부호는 0.5자), **최대 2줄**, 읽기 속도 **성인 초당 12자, 아동 초당 9자**, 청각장애인용(SDH)은 성인 14자·아동 11자를 제시한다 (https://partnerhelp.netflixstudios.com/hc/en-us/articles/216001127). 영어 가이드는 한 줄 42자, 성인 초당 20자·아동 17자 (https://partnerhelp.netflixstudios.com/hc/en-us/articles/217350977-English-USA-Timed-Text-Style-Guide). [verified 2026-10-12] 엔터테인먼트 기준이므로 강의에는 참고값으로 쓴다.
- WCAG 2.2는 사전 녹화 영상의 자막을 A 등급 성공기준(1.2.2)으로 둔다 (https://www.w3.org/TR/WCAG22/) [확인 필요: 국내 KWCAG 대응 항목, [[domain/접근성]]].
- **AI 더빙·음성 복제**는 강사 음성·초상 권리와 동의가 선결 조건이다 ([[domain/강사계약과콘텐츠권리]]). AI 기본법상 생성형 AI 결과물 표시 의무도 검토한다 (제31조, [[domain/아동개인정보보호]]).

## 상세

### 파이프라인 단계

| 단계 | 할 일 | 도구 유형 | 품질 포인트 |
|------|-------|-----------|-------------|
| 1. 음성 준비 | 음성 트랙 분리, 잡음 제거 | 오디오 처리 | 녹음 품질이 STT 정확도를 좌우 (L02 촬영 기준) |
| 2. STT | 음성 → 텍스트 + 타임스탬프 | 음성 인식 모델(클라우드 API 또는 자체 호스팅) | 화자 분리, 단어 단위 시간 |
| 3. 용어 교정 | 용어집·강사 이름·고유명사 치환 | 사전 치환 + LLM 교정 | LLM이 내용을 "개선"해 바꾸지 않도록 제한 |
| 4. 분절·타이밍 | 줄 길이, 줄 수, 표시 시간, 장면 전환 | 규칙 엔진 | 의미 단위로 끊기, 화면 텍스트와 겹침 피하기 |
| 5. 사람 검수 | 수준별 검수 (아래 표) | 자막 편집기 | 검수 시간 측정 |
| 6. 번역 | 원문 자막 → 대상 언어 | 기계번역 + LLM 후편집 + 사람 | 용어집 다국어판, 길이 재분절 |
| 7. 더빙 | 번역 대본 → 합성 음성 | TTS, 음성 복제 | 동의 범위, 입 모양·속도 |
| 8. 게시·피드백 | 형식 변환(WebVTT, SRT), 오류 신고 | 플레이어 | 신고 → 수정 → 재게시 |

### 용어집 설계

- 항목: 표기, 발음 변형(STT가 자주 틀리는 형태), 영어 원어, 대상 언어 번역, 금지 번역.
- 범주: 과목 용어(예: "미분계수", "분산"), 코드·명령어, 강사·인물 이름, 제품·도구명, 약어.
- 교육과정 표준 용어는 교과서 용어와 맞춘다 ([[domain/교육과정지식그래프]]).
- 오류 신고에서 반복되는 단어를 용어집에 자동 추가 후보로 올린다.

### 사람 검수 수준

| 수준 | 방식 | 적합 | 상대 비용 |
|------|------|------|-----------|
| L0 | 자동 자막 그대로, "자동 생성" 표시 | 내부 자료, 임시 게시 | 최저 |
| L1 | 표본 구간 검수 + 용어집 치환 확인 | 일반 VOD | 낮음 |
| L2 | 전체 시청 검수 (1회) | 유료 강의 기본 | 중간 |
| L3 | 전체 검수 + 내용 전문가 확인 + SDH 요소(소리 묘사, 화자 표시) | 접근성 요구 과정, 공공·B2G, 자격 과정 | 높음 |

- 청각장애 학습자에게는 L3 수준(소리 정보, 화자 표시, 정확한 싱크)이 필요하다. 자동 자막만 제공하면서 "자막 제공"이라고 표시하지 않는다.
- 수식·코드는 자막만으로 전달이 어려우므로 화면 자료·스크립트 다운로드를 함께 제공한다.

### 번역·더빙

- 번역 자막은 원문보다 길어지기 쉬우므로 대상 언어 기준으로 재분절한다.
- **음성 복제 더빙** 동의서 항목: 사용 언어, 사용 과정 범위, 기간, 수익 배분, 철회 시 삭제 기한, 다른 용도(광고) 사용 금지.
- 합성 음성임을 학습자에게 표시한다 [확인 필요: AI 기본법 제31조 적용 범위].
- 문화적 예시(지명, 화폐, 제도)는 번역 시 현지화 여부를 정한다.

### 비용 모델

| 항목 | 단위 | 메모 |
|------|------|------|
| STT | 음성 분당 과금 | 업체·모델별 상이 [확인 필요: 최신 단가] |
| LLM 교정·번역 | 토큰당 | 원고 분량에 비례 |
| 사람 검수 | 영상 1분당 검수 시간 × 인건비 | 가장 큰 비용. 자동화 효과는 이 시간 감소로 측정 |
| 더빙 | 분당 또는 글자당 | 음성 복제는 별도 라이선스 |

- 계산식: 과정 1개 비용 = 총 영상 분 × (STT 단가 + LLM 단가 + 검수 분당 시간 × 시급/60) × 언어 수.

### 품질 지표

| 지표 | 정의 | 메모 |
|------|------|------|
| WER (단어 오류율) | (치환 + 삭제 + 삽입) ÷ 기준 단어 수 | 한국어는 띄어쓰기 영향이 커서 CER(글자 오류율)을 함께 본다 |
| 용어 정확도 | 용어집 항목 중 올바른 비율 | 강의에서 가장 중요한 지표 |
| 검수 시간 비율 | 검수 시간 ÷ 영상 길이 | 자동화 개선 추적 |
| 읽기 속도 위반율 | 초당 글자 수 기준 초과 자막 비율 | 분절 규칙 점검 |
| 신고 오류율 | 1,000 시청분당 확정 신고 | 게시 후 품질 |

| AT08 고등·평생교육 | 장애 학생 지원 요구, 강의 녹화 대량 처리 |

## 에듀테크 PM 적용

**체크리스트 (A07 자동자막·번역설계서)**

- [ ] 파이프라인 8단계별 도구·담당·완료 조건을 L02와 맞춘다
- [ ] 과정별 용어집 양식과 갱신 절차를 만든다
- [ ] 과정 등급별 검수 수준(L0~L3)을 정한다
- [ ] 분절 기준(줄 길이, 줄 수, 읽기 속도)을 정하고 근거를 적는다
- [ ] 음성 데이터의 외부 API 전송·보존 조건을 E13에 기록한다 ([[domain/학습데이터프라이버시]])
- [ ] 음성 복제·더빙 동의서를 P02 계약에 넣는다
- [ ] 품질 지표(용어 정확도, 검수 시간 비율)를 정하고 목표값을 [가정]으로 둔다
- [ ] 비용 계산식을 S07·S06 원가에 반영한다

**관련 산출물**: A07(주), L02, A00, P02, P04, E13.

## 흔한 오해

- "자동 자막 정확도 95%면 충분" — 틀린 5%가 핵심 용어면 학습에 치명적이다.
- "자막은 청각장애인만 쓴다" — 소음 환경, 비원어민, 복습 검색에도 쓰인다.
- "강사 음성으로 더빙은 기술 문제" — 동의·권리 문제가 먼저다.
