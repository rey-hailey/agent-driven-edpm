# AI 사용량 대시보드 설계 (학생·교사·관리자·개발자)

## 핵심 요약

- AI 기능은 요청마다 비용이 든다. 그래서 **누가 얼마나 쓸 수 있고, 얼마나 썼는지**를 역할별로 보여 주는 화면이 필요하다. 같은 데이터를 학생에게는 "남은 횟수", 교사·관리자에게는 "반별 사용량·비용", 개발자에게는 "토큰·요청·오류·지연"으로 번역한다 [가정].
- 단위 번역이 핵심이다: 토큰·원가는 내부 단위, 사용자에게는 **횟수·글자 수·크레딧** 중 하나로 일관되게 보여 준다 (A12 과금 단위와 같게).
- 한도 도달은 학습을 막는 순간이다. **사전 알림 → 도달 안내 → 대체 학습 경로**를 함께 설계한다 (P09).
- 공정한 표시: 학생 간 사용량 비교·랭킹을 보여 주지 않는다. 많이 쓴 학생이 잘하는 학생이 아니다 ([[domain/동기설계]]).

## 상세

### 역할별 대시보드

| 역할 | 핵심 질문 | 주요 지표 | 화면 위치 |
|------|-----------|-----------|-----------|
| 학생 | 오늘 얼마나 더 쓸 수 있나 | 남은 횟수, 초기화 시점 | 입력창 근처 배지, 마이 > 사용량 |
| 보호자 | 아이가 얼마나 쓰나 | 일·주 사용 시간·횟수, 주제 요약 | 보호자 앱 주간 리포트 |
| 교사 | 반에서 누가 어떻게 쓰나 | 반·학생별 사용 횟수, 기능별 비율, 한도 도달 학생 수 | 교사 대시보드 AI 탭 |
| 기관 관리자 | 예산 안에 있나 | 월 사용량·비용, 반·학년별, 예산 대비, 추세 | 관리자 콘솔 |
| 개발자(API 고객) | 서비스가 정상인가, 비용은 | 요청 수, 토큰, 오류율, 지연 p50·p95, 키별 | [[domain/AI_API개발자콘솔IA]] |
| 운영자 | 원가와 이상 징후 | 모델별 원가, 캐시 적중률, 급증 기관 | [[domain/관리자백오피스BO_IA]] |

### 화면 구성 (기관 관리자 기준)

```
+-------------------------------------------------------------+
| AI 사용량 · 2026년 10월        [기간 v] [반 v] [기능 v] [내보내기] |
|-------------------------------------------------------------|
| [이번 달 사용 62%] [예상 월말 94%] [한도 도달 학생 12명] [비용]  |
|-------------------------------------------------------------|
| 일별 사용량 추이 (막대)        |  기능별 비율 (튜터/피드백/생성)   |
|-------------------------------------------------------------|
| 반별 표: 반 | 학생 수 | 사용 | 1인 평균 | 한도 도달 | 추세       |
|-------------------------------------------------------------|
| 알림 설정: 70% · 90% · 100% 도달 시 [이메일] [앱]              |
+-------------------------------------------------------------+
```

### 컴포넌트

| 컴포넌트 | 설계 포인트 |
|----------|-------------|
| 남은 사용량 배지(학생) | "오늘 8회 남음", 근접 시 색 + 텍스트. 숫자만 쓰지 않고 의미 문장 병기 |
| KPI 카드 | 사용률, 예상 월말 사용률, 한도 도달 수, 비용. 예상값은 "예상" 표기 |
| 추이 차트 | 일별 막대, 학기 일정(시험·방학) 표시선 ([[domain/학사일정]]) |
| 분해 표 | 반·기능·모델·키별. 정렬·필터 |
| 알림 설정 | 임계값(예: 70·90·100%), 수신자, 채널 |
| 한도 관리 | 반별 배분, 일시 상향, 상향 요청 |
| 내보내기 | CSV·PDF, 기간·필터 적용 상태 그대로. 학생 단위 내보내기는 권한 제한 |
| 차트 접근성 | 차트마다 표 보기 대안, 색 외 패턴 구분 (WCAG 1.4.1, 1.1.1) |

### 한도 설계와 표시

| 한도 단위 | 예 | 도달 시 | 표시 |
|-----------|-----|---------|------|
| 학생 일 한도 | 질문 20회/일 [가정] | 튜터 일시 중지, 교재 해설·복습은 계속 | 입력창 비활성 + 초기화 시각 |
| 반 월 한도 | 교사 배분 | 교사 알림, 상향 요청 | 교사 대시보드 경고 |
| 기관 월 예산 | 계약 금액 | 정책에 따라 축소 모드(작은 모델·FAQ) 또는 차단 | 관리자 배너 + 학생에게는 축소 모드 안내 |
| API 분당 요청 | 키별 | 429 응답, 재시도 권장 | 콘솔 한도 화면 |

## 에듀테크 맥락

- 학생: 한도는 공정성 문제다. 집에서 더 쓰는 학생과 학교에서만 쓰는 학생의 격차를 고려해 학습 핵심 기능(오답 힌트)은 한도에서 제외하는 선택지도 있다 [가정].
- 교사: 사용량이 적은 학생은 "AI 미사용"이지 "학습 부족"이 아니다. 해석 문구를 붙인다.
- 보호자: 사용 시간 지표는 스크린 타임 걱정과 연결된다 ([[domain/유아초등학습UX]]).
- 관리자: 학기초·시험기 급증을 예측선으로 보여 예산 계획을 돕는다.
- 미성년: 학생 단위 사용 기록은 개인정보다. 교사·관리자 열람 범위를 정한다 ([[domain/학습데이터프라이버시]]).

## 상태·예외

| 상황 | 처리 |
|------|------|
| 데이터 없음(신규) | "아직 사용 기록이 없어요" + 기능 소개 |
| 집계 지연 | "마지막 집계 10:20" 표시, 실시간 아님을 명시 |
| AI 응답 지연·실패 | 실패 요청은 사용량에서 차감하지 않음을 표시 [가정: 정책은 A12] |
| 거절된 요청 | 차감 여부 명시 [가정] |
| 근거 없음 | 해당 없음 |
| 한도 도달 | 위 표의 대체 동작, 초기화 시점 |
| 모델 장애 | 장애 기간 표시, 사용량 그래프에 구간 음영 |
| 예산 초과 예상 | 사전 알림, 추천 조치(반별 배분 조정) |
| 내보내기 실패 | 재시도, 대용량은 이메일 링크 |

## 에듀테크 PM 적용

- [ ] 역할별 대시보드 지표와 단위(횟수·글자·크레딧)가 A12 과금 단위와 같은가
- [ ] 한도 단위·도달 시 대체 동작이 P09와 같은가
- [ ] 실패·거절 요청 차감 정책이 정해졌는가
- [ ] 학생 간 비교·랭킹이 없는가, 해석 문구가 있는가
- [ ] 차트 표 보기 대안이 E13 (c)에 있는가
- [ ] 학생 단위 데이터 열람·내보내기 권한이 E09와 같은가
- [ ] 와이어프레임 P0: 학생 남은 사용량(입력창·마이), 교사 반별 사용량, 기관 관리자 사용량·예산, 한도 도달 화면

## 흔한 오해

- "토큰 수를 보여 주면 투명하다" — 사용자는 토큰을 모른다. 행동 단위로 번역한다.
- "사용량이 많을수록 열심히 공부한 것" — AI 사용량은 학습 지표가 아니다 ([[domain/학습분석지표]]).
- "한도 도달 시 막으면 된다" — 학습이 끊긴다. 대체 경로를 같이 준다.
