# 전용 기기 학습 서비스 (태블릿 + 구독)

> 학습 전용 태블릿을 함께 제공하는 약정형 구독 서비스(**엘리하이형** 등) 범주를 다룬다. 이름은 형태 설명용이며, 특정 회사의 약정 조건·위약금·수치를 주장하지 않는다. 이 페이지는 법률 자문이 아니다.

## 핵심 요약

- 상품은 **기기 + 콘텐츠 구독 + 관리(학습 코칭·CS)**의 묶음이다. 기기 원가를 약정 기간 구독료로 회수하는 구조라 **중도 해지 정산과 약정 만료 시점 이탈**이 사업의 핵심 변수다.
- 어떤 법이 적용되는지는 **판매 경로와 계약 구조**로 갈린다 [확인 필요: 상품별 법무 검토].
  - 할부 계약: 계약서를 받은 날(공급이 늦으면 공급받은 날)부터 **7일** 내 청약 철회 (할부거래법 제8조, https://korea.legal/wiki/할부거래에-관한-법률-제8조). [verified 2026-10-12: 법령 미러]
  - 방문판매·전화권유판매: 계약서를 받은 날부터 **14일** 내 청약 철회 (방문판매법 제8조, https://korea.legal/wiki/방문판매-등에-관한-법률-제8조). [verified 2026-10-12: 법령 미러]
  - 계속거래(1개월 이상 계속 공급 + 중도 해지 시 환급 제한·위약금 약정): 소비자는 **계약기간 중 언제든 해지** 가능 (제31조), 사업자는 해지로 생기는 손실을 현저히 넘는 위약금을 청구할 수 없다 (제32조) (https://korea.legal/wiki/방문판매-등에-관한-법률-제31조). [verified 2026-10-12: 법령 미러]
  - 온라인 결제: 전자상거래법 제17조 청약철회 ([[domain/환불정책]]).
- 위약금·환급 산정기준은 공정위 고시 제2019-9호가 정한다 (2019.11.19. 시행, https://korea.legal/wiki/공정거래위원회고시-제2019-9호-계속거래-등의-해/). [확인 필요: 현행 고시 번호·학습지·기기 항목]
- 중도 해지를 아예 금지하는 약관 조항은 방문판매법 제31조를 잠탈해 무효라고 본 판결이 있다 (2015다222654, https://korea.legal/wiki/2015다222654-222661/). [verified 2026-10-12: 2차 출처]

## 상세

### 기기 묶음의 경제성

| 요소 | 설계 질문 |
|------|-----------|
| 기기 원가 회수 | 약정 기간 중 몇 개월 차에 기기 원가를 회수하나 |
| 기기 소유권 | 판매(할부)인가, 대여인가, 약정 만료 후 소유 이전인가 |
| 해지 정산 | 남은 기기 대금, 사은품, 할인 반환을 어떻게 계산하나 |
| 재사용 | 반납 기기 초기화·재생 비용과 재고 |
| 형제·추가 기기 | 한 기기 다계정, 추가 기기 가격 |

- 기기 대금과 콘텐츠 이용료를 계약서·청구서에서 분리 표기하면 해지 정산과 분쟁 대응이 쉬워진다 [가정].
- "기기 무료" 표시는 약정·해지 조건을 함께 알리지 않으면 표시광고 분쟁 위험이 있다 [확인 필요].

### 약정·해지 흐름

1. 상담(전화·방문·온라인) → 2. 계약서 교부(철회 기간 안내) → 3. 기기 배송·개통 → 4. 철회 기간 → 5. 구독 진행 → 6. 중도 해지 요청 → 7. 정산(이용분 + 위약금 한도 내 + 기기 처리) → 8. 기기 반납 또는 잔여 대금 → 9. 계정·데이터 처리.
- 해지 접수 채널을 계약 채널보다 어렵게 만들지 않는다(앱·웹·전화).
- 정산 계산은 규칙 엔진으로 두고 CS 화면에 근거와 함께 보여 준다 (P01, P05).

### MDM과 유해 콘텐츠 차단

- 기기 관리(MDM): 학습 앱 고정(키오스크 모드), 외부 앱 설치 제한, 웹 필터, 사용 시간 제한, 원격 잠금·초기화, 분실 신고.
- 보호자가 허용 앱·시간을 조정할 수 있게 하되 기본값은 보수적으로 [가정].
- 웹 필터·검색 차단 목록의 갱신 주기와 오차단 신고 처리.
- MDM으로 수집하는 기기 정보(위치 포함 시)는 아동 개인정보로 최소 수집 ([[domain/아동개인정보보호]]).

### OS 업데이트와 기기 수명

- 기기 제조사의 보안 업데이트 지원 기간과 약정 기간을 맞춘다. 약정 중 OS 지원 종료는 큰 리스크다.
- 앱 최소 지원 OS 정책, 구형 기기 성능 저하 시 기능 축소 모드.
- 배터리·충전 단자·화면 파손이 주요 AS 사유가 된다 [가정].

### 보호자 앱

- 오늘 학습 완료 여부, 주간 학습 시간·과목, 성취 리포트, 기기 사용 시간, 알림 설정, 해지·결제 관리.
- 보호자 앱의 알림이 아이 압박 도구가 되지 않게 표현을 설계한다 ([[domain/동기설계]]).

### 초등 학습 습관 설계

- 매일 같은 시간 짧은 학습 세트(오늘의 학습), 완료 표시, 주간 돌아보기. 스트릭·벌점보다 회복 가능한 목표 ([[domain/유아초등학습UX]]).
- 학교 진도와 맞춘 단원 순서 ([[domain/2022개정교육과정적용일정]], [[domain/교육과정지식그래프]]).
- 학습 코칭(전화·메시지) 주기와 내용은 운영 정책으로 정한다 (P05).

### CS·AS 물류

- 배송·개통, 고장 접수 → 택배 회수 → 수리·교체 → 재발송, 대체 기기 제공 여부, 수리 기간 중 학습 이어 하기(다른 기기 로그인).
- 반납 기기 검수 기준(파손 시 비용 청구 기준)을 계약서에 명시한다.

## 핵심 비즈니스 로직

- 고객 생애 가치 = 월 이용료 × 평균 유지 개월 − 기기 원가 − 물류·AS·코칭 비용 − 획득 비용 ([[domain/에듀테크수익모델]]).
- **약정 만료 이탈**: 만료 1~2개월 전 재약정 제안, 학년 전환(초→중) 시점 이탈이 겹친다 [가정].
- 학년 진급 시 콘텐츠 연속성(다음 학년 과정)이 재약정의 근거가 된다.

## 주요 화면·기능

- 학습자 기기: 오늘의 학습, 과목 홈, 학습 플레이어, 평가, 보상, 기기 설정 잠금. 보호자 앱: 리포트, 사용 시간, 결제·해지. CS 콘솔: 계약·정산 계산기, 기기 상태(MDM), AS 티켓.

## 지표

| 구분 | 지표 |
|------|------|
| 학습 | 주간 학습 일수, 오늘의 학습 완료율, 단원 성취 |
| 유지 | 월 해지율, 철회 기간 내 철회율, 약정 만료 재약정률 |
| 운영 | AS 접수율·처리 기간, 기기 반납 회수율, 해지 정산 분쟁 건수 |
| 사업 | 기기 원가 회수 개월, 고객당 공헌이익 |

## 규제·리스크

- 판매 경로별 청약 철회·해지 규정 차이를 상품 설계 전에 확인한다 [확인 필요: 법무].
- 위약금이 법령·고시 한도를 넘으면 분쟁·제재 위험. 정산 예시를 약관과 함께 공개한다.
- 아동 기기 데이터(사용 기록·위치), 보호자 동의, MDM 수집 범위 ([[domain/아동개인정보보호]]).
- 기기 안전(배터리), 전자파 인증 등 제품 규제는 제조·수입 단계에서 확인한다 [확인 필요].

## 에듀테크 PM 적용

**체크리스트**

- [ ] 판매 채널별(온라인·전화·방문) 적용 법령과 철회 기간을 표로 만든다 (P01)
- [ ] 기기 대금·이용료 분리와 해지 정산 계산 예시를 쓴다 (P01, S06)
- [ ] 해지 접수 채널을 계약 채널만큼 쉽게 만든다 (P05, E10)
- [ ] MDM 기본값과 수집 기기 정보를 E13에 적는다
- [ ] OS 지원 기간과 약정 기간을 대조한다 (B04, M03)
- [ ] 약정 만료 이탈 예측·재약정 흐름을 설계한다 (A09, F01~F04)

**관련 산출물·유형**: AT07 + AT05. P01, P05, S06, E09, E10, E12, E13, B04, M03, A09, F00~F04(학습 습관 알림, 해지 흐름 정비), N01~N03(중등 확장 상품).

## 흔한 오해

- "약정 상품이니 중도 해지를 막아도 된다" — 계속거래에 해당하면 언제든 해지할 수 있다.
- "위약금은 회사가 정하기 나름" — 손실을 현저히 넘는 위약금은 청구할 수 없고 고시 기준이 있다.
- "기기가 있으니 습관은 저절로" — 기기는 접근성일 뿐, 학습 루틴 설계가 유지율을 만든다.
