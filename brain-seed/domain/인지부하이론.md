# 인지부하이론 (Cognitive Load Theory)

## 핵심 요약

- John Sweller가 1980년대 후반 제안한 이론. 작업기억은 용량과 지속시간이 제한되므로, 수업 설계는 학습과 무관한 처리 부담을 줄이고 스키마 형성에 자원을 쓰게 해야 한다 (Sweller, 1988, https://doi.org/10.1207/s15516709cog1202_4).
- 전통적으로 세 가지 부하를 구분한다: 내재적(과제 자체의 복잡성), 외재적(나쁜 설계로 생기는 불필요한 부담), 본유적(germane, 스키마 형성에 쓰는 부담). 최근 문헌은 본유적 부하를 별도 유형보다 내재적 부하 처리에 쓰는 자원으로 재정의하는 경향이 있다 (Sweller, van Merriënboer & Paas, 2019, https://doi.org/10.1007/s10648-019-09465-5).
- 학습 화면 UX 설계의 직접적 근거다. "예쁜 UI"보다 "학습자의 작업기억을 덜 쓰는 UI"가 기준이다.

## 상세

### 대표적 설계 효과

| 효과 | 내용 | 제품 적용 |
|------|------|-----------|
| 풀이된 예제 효과 | 초보자는 문제 풀이보다 단계별 풀이 예제를 학습할 때 효율적 | 처음엔 예제, 이후 부분 풀이, 마지막에 독립 풀이 |
| 주의 분산 효과 | 서로 참조해야 하는 정보(그림과 설명)가 떨어져 있으면 부하 증가 | 도형 옆에 설명 배치, 별도 팝업 지양 |
| 중복 효과 | 같은 정보를 불필요하게 반복 제시(화면 글 + 동일 내레이션)하면 부하 증가 | 자막 정책 설계 (접근성 요구와 구분) |
| 양식 효과 | 시각 자료 + 청각 설명이 시각 자료 + 화면 글보다 유리한 경우가 있음 | 애니메이션 설명에 내레이션 |
| 전문성 역전 효과 | 초보자에게 도움 되는 지원이 숙련자에게는 오히려 방해 | 숙련도에 따라 비계(힌트·예제)를 줄이는 적응형 설계 |

출처: Sweller, van Merriënboer & Paas (2019); Mayer의 멀티미디어 학습 원리 (Mayer, *Multimedia Learning*, 3rd ed., 2020, Cambridge University Press).

## 에듀테크 PM 적용

- [ ] 학습 화면에서 학습과 무관한 요소(광고, 과도한 애니메이션, 보상 팝업)를 문제 풀이 중에 띄우지 않는다
- [ ] 초보자용 풀이 예제와 단계적 힌트 → 숙련자는 힌트 축소 (전문성 역전 효과 대응)
- [ ] 문제와 관련 그림·표는 한 화면, 가까운 위치에 둔다 (태블릿·모바일 화면 크기 검증 포함)
- [ ] 영상 강의는 짧은 단위로 분절하고 학습자가 속도를 조절할 수 있게 한다 [Mayer 분절 원리]
- [ ] AI 튜터 응답 길이를 제한하고 한 번에 한 단계씩 안내한다 (E14)
- [ ] 접근성 요구(자막, 대체 텍스트)와 중복 효과는 충돌이 아니다. 자막은 끄고 켤 수 있게 하고, 기본값을 사용자 집단에 맞춘다 ([[domain/접근성]])

## 흔한 오해

- "인지부하는 낮을수록 좋다" — 내재적 부하가 적절해야 학습이 일어난다. 줄여야 할 것은 외재적 부하다.
- "학습 스타일(시각형·청각형)에 맞추면 된다" — 학습 스타일 맞춤 교수의 효과를 지지하는 근거는 약하다 (Pashler et al., 2008, https://doi.org/10.1111/j.1539-6053.2009.01038.x). 양식 효과와 혼동하지 않는다.
- "멀티미디어는 많을수록 좋다" — 일관성 원리: 흥미 위주 부가 자료가 학습을 방해할 수 있다.
