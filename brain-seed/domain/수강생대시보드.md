# 수강생 대시보드 (다음 행동·진도·숙달)

## 핵심 요약

- 수강생 대시보드의 첫 질문은 "지금 무엇을 하면 되나"다. **다음 행동 1개**를 가장 크게, 그다음 마감·일정, 그다음 진도·숙달 순서로 배치한다.
- 진도(얼마나 봤나)와 숙달(얼마나 할 수 있나)을 구분해서 보여 준다. 진도 100%가 숙달을 뜻하지 않는다 ([[domain/학습분석지표]], [[domain/숙달학습]]).
- 동기 장치는 자율성·유능감·관계성을 해치지 않게 쓴다. 스트릭·랭킹·포인트는 기본 강도를 낮추고 끌 수 있게 한다 ([[domain/동기설계]]).
- 숫자는 정직해야 한다. 정의가 불분명한 %, 반올림으로 생긴 "100%", 소수 데이터로 계산한 숙달도는 학습자와 보호자를 오도한다.

## 상세

### 정보 우선순위와 배치

```text
수강생 대시보드
├─ 1. 다음 행동 카드: "이어 보기: 3강 7분부터" 또는 "오늘의 복습 5문항"
├─ 2. 마감·일정: 과제 마감 D-n, 라이브 수업 시작 시각, 수강 기간 만료 임박
├─ 3. 이번 주 목표: 학습자가 정한 목표 대비 진행(일수·분·레슨)
├─ 4. 과정별 진도: 과정 카드(진도 바, 다음 레슨, 남은 기간)
├─ 5. 숙달 현황: 기술·성취기준별 수준(근거 문항 수와 함께)
└─ 6. 성취 기록: 수료증, 배지, 완료 과정
```

### 주요 컴포넌트

| 컴포넌트 | 설계 포인트 |
|----------|-------------|
| 다음 행동 카드 | 버튼 하나. 우선순위 규칙: 마감 임박 과제 > 이어 보기 > 복습 예정 > 추천 [가정] |
| 마감·일정 | 날짜와 상대 시간(D-2) 병기, 타임존 표시, 캘린더 추가 |
| 주간 목표 | 학습자가 목표를 직접 정하고 바꿀 수 있음(자율성). 달성 못 한 주에 비난 문구 금지 |
| 스트릭(선택) | 일 단위보다 주 단위 목표, 유예일, 끊겨도 누적 기록 유지 ([[domain/동기설계]]) |
| 과정 진도 | 진도 정의는 L03과 같은 값. "완료 레슨 12/30"처럼 분자·분모 병기 |
| 숙달 현황 | 기술·성취기준별 수준, 근거 문항 수, "아직 데이터 부족" 상태. 색만으로 수준 표시 금지 |
| 성장 비교 | 비교 대상은 과거의 나. 타인 순위는 기본 끔 |
| 수료증 | 발급 조건까지 남은 항목 목록, 발급 후 다운로드·공유 (L06) |

### 데이터 정직성 원칙

- 진도율은 정의를 툴팁으로 공개한다 (예: "완료 처리된 레슨 수 기준").
- 99.5%를 100%로 반올림하지 않는다. 완료 조건 미충족이면 100%를 표시하지 않는다.
- 숙달도는 최소 근거 문항 수 미만이면 수준 대신 "더 풀어 보면 알 수 있어요"로 표시한다 [가정: 최소 문항 수는 E12에서].
- 예측("합격 가능성 80%")은 근거·불확실성 없이 표시하지 않는다. AI 예측이면 E14 검토 대상이다.
- 학습 시간은 학습 효과의 지표처럼 강조하지 않는다.

### 역할별 변형

| 역할 | 보는 것 | 다르게 할 것 |
|------|---------|--------------|
| 학습자 | 다음 행동, 내 진도·숙달 | 행동 유도 중심 |
| 보호자 | 주간 요약(학습 일수, 완료 과제, 숙달 변화, 교사 코멘트) | 실시간 감시보다 주간 리포트. 비교·순위 없음. 자녀가 무엇을 보는지 투명하게 [가정] |
| 교사 | 반 전체 분포, 도움이 필요한 학생, 학생 상세 | 학생 대시보드와 같은 지표 정의를 써서 대화가 가능하게 ([[domain/교사참여설계]]) |
| 기업 관리자 | 개인 대시보드가 아니라 집계 리포트 | [[domain/기업관리자LMSIA]] |

## 서비스 유형별 차이

| 유형 | 차이 |
|------|------|
| AT01 마켓플레이스 | 여러 과정 동시 수강. 과정 카드와 이어 보기 중심, 숙달은 약함 |
| AT02 기업교육 | 필수 교육 마감이 최상단. 이수 상태와 수료증 |
| AT03 부트캠프 | 주간 일정, 과제·프로젝트 상태, 출석, 멘토 피드백 |
| AT05·AT06 K-12·학원 | 오늘의 과제(교사 배정), 큰 버튼, 보상은 절제, 보호자·교사 변형 필수 |
| AT07 소비자 학습앱 | 일일 목표·스트릭 비중이 크다. 과도한 압박 알림 주의 |
| AT09 시험대비 | 시험일 D-day, 영역별 숙달, 모의고사 추이 |
| AT10 AI 튜터 | 대화 기반 학습의 요약(무엇을 다뤘나, 남은 약점)을 대시보드로 |

## 상태·예외

| 상황 | 처리 |
|------|------|
| 신규 사용자 | 빈 차트 대신 "첫 레슨 시작" 카드 + 목표 설정. 0%를 크게 보여 주지 않음 |
| 데이터 부족 | 숙달·추이는 "데이터가 쌓이면 보여 드려요" |
| 로딩 | 다음 행동 카드 우선 로드, 나머지 스켈레톤 |
| 오류 | 부분 실패 허용(진도는 보이고 숙달만 오류) + 다시 시도 |
| 오프라인 | 마지막 동기화 시각과 캐시 데이터 |
| 권한 없음 | 보호자·교사는 연결된 학습자만, 동의 철회 시 데이터 숨김 ([[domain/아동개인정보보호]]) |
| 수강 기간 만료 | 과정 카드를 "만료" 그룹으로, 기록·수료증은 유지 |
| 장기 미접속 복귀 | 밀린 일 목록 대신 "다시 시작하기" 한 가지 행동 [가정] |

## 에듀테크 PM 적용

- [ ] 대시보드 1순위가 다음 행동 1개인가, 우선순위 규칙이 E09에 정의되었는가
- [ ] 진도·숙달·수료 지표 정의가 L03·E07·E12와 같은 값인가
- [ ] 데이터 부족·신규 사용자 상태가 E10 3절에 정의되었는가
- [ ] 게임 요소마다 SDT 영향 검토를 했고, 랭킹은 기본 끔인가 (E08)
- [ ] 보호자·교사 변형의 열람 범위와 동의 조건이 E13에 반영되었는가
- [ ] 예측·AI 지표가 있다면 E14 검토를 거쳤는가
- [ ] 와이어프레임: 학습자 대시보드(신규·활성·복귀 3상태), 보호자 주간 리포트를 P0로

## 흔한 오해

- "지표를 많이 보여 줄수록 동기부여된다" — 정보 과잉은 다음 행동을 흐린다 ([[domain/인지부하이론]]).
- "스트릭은 리텐션의 정답" — 끊기는 순간 이탈하는 패턴이 생길 수 있다.
- "진도 100% = 다 배웠다" — 진도는 노출 지표, 숙달은 증거 지표다.
