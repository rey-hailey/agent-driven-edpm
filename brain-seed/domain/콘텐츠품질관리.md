# 콘텐츠 품질 관리

> 강의·문항 콘텐츠의 품질은 "출시 전 검수"로 끝나지 않는다. 출시 후 데이터(완주, 이탈 지점, 평점, 환불 사유, 오류 신고)로 계속 판정하고 재제작·폐기까지 이어지는 순환으로 관리한다.

## 핵심 요약

- 품질은 다섯 차원으로 본다: **정확성, 교수 설계, 제작(음성·영상), 접근성, 최신성**.
- 출시 전 검수는 체크리스트와 역할(내용 전문가, 교수설계자, 편집자, 접근성 담당)을 분리한다. 강사 본인 검수만으로는 오류를 놓친다.
- 출시 후에는 **오류 신고 → 심각도 분류 → SLA 내 수정 → 신고자 회신** 흐름을 둔다.
- 재제작·폐기는 감이 아니라 데이터 기준(완주율, 구간 이탈, 평점, 환불 사유, 법령·버전 변경)으로 정한다. 단, 평점은 강사 호감도·난이도에 끌리므로 학습 성과 지표와 같이 본다 ([[domain/학습분석지표]]).

## 상세

### 품질 차원과 기준 예

| 차원 | 기준 | 확인 방법 |
|------|------|-----------|
| 정확성 | 사실·풀이·코드 오류 없음, 정답 키 일치 | 내용 전문가 교차 검토, 코드 실행 테스트 |
| 교수 설계 | 학습목표 명시, 목표-활동-평가 정렬, 인출 연습 포함 | [[domain/역방향설계]] 정렬표, [[domain/인출연습]] |
| 인지 부하 | 한 화면 한 개념, 불필요한 장식 제거, 적절한 분량 (짧은 단위) | [[domain/인지부하이론]] 점검 |
| 제작 | 음량 균일, 잡음·에코 없음, 화면 글자 가독, 판서·커서 보임 | 편집 검수표, 모바일 화면 확인 |
| 접근성 | 자막 정확도, 색 대비, 화면 낭독기 호환 자료, 대체 텍스트 | [[domain/접근성]], [[domain/자동자막번역]] |
| 최신성 | 법령·소프트웨어 버전·교육과정 반영 | 버전 태그, 만료 예정일 |

- 자막 기준 예: 넷플릭스 한국어 자막 가이드는 한 줄 16자, 최대 2줄, 성인 프로그램 초당 12자 읽기 속도를 제시한다 (https://partnerhelp.netflixstudios.com/hc/en-us/articles/216001127). 강의는 화면 텍스트와 겹치므로 그대로 쓰지 말고 참고 기준으로 쓴다. [verified 2026-10-12]

### 출시 전 QA 체크리스트

- [ ] 학습목표와 평가 문항이 정렬되어 있다 (E05·E11)
- [ ] 내용 전문가 1인 이상이 강사와 독립적으로 검토했다
- [ ] 문항 정답 키를 두 번 검증했다 (사람 + 자동 채점 실행)
- [ ] 코드·수식·실습 파일이 안내대로 실행된다 (클린 환경)
- [ ] 음량 기준, 잡음, 화면 해상도, 모바일 가독을 확인했다
- [ ] 자막 검수(용어집, 고유명사, 싱크)를 마쳤다
- [ ] 제3자 자료 권리 원장을 확인했다 ([[domain/강사계약과콘텐츠권리]])
- [ ] 메타데이터(난이도, 선수 과정, 소요 시간, 버전)를 입력했다 (L01)
- [ ] 맛보기 구간과 상품 설명이 실제 내용과 일치한다 (표시·광고와 다르면 환불 사유, [[domain/환불정책]])
- [ ] 접근성 최소 점검(자막, 대비, 키보드 조작)을 통과했다

### 오류 신고와 수정 SLA (예시, [가정])

| 심각도 | 정의 | 예 | 1차 대응 | 수정 |
|--------|------|-----|----------|------|
| S1 치명 | 학습자에게 틀린 지식·정답을 가르치거나 법적 문제 | 정답 키 오류, 저작권 침해 자료 | 24시간 내 비공개·공지 | 3일 |
| S2 높음 | 학습 진행 불가 | 실습 파일 깨짐, 영상 재생 불가 | 1영업일 | 5영업일 |
| S3 보통 | 이해 방해 | 오탈자 많은 자막, 음량 불균일 | 3영업일 | 다음 정기 개정 |
| S4 낮음 | 개선 제안 | 예제 추가 요청 | 접수 회신 | 백로그 |

- 신고자에게 처리 결과를 회신하면 신고 참여가 늘어난다. 확정된 오류는 과정 공지("2026-10 개정: 3강 예제 수정")로 남긴다.

### 평점·리뷰 관리

- **가짜 리뷰**: 강사·업체가 대가를 주고 쓴 리뷰는 표시·광고 규제 대상이 될 수 있다. 공정위 "추천·보증 등에 관한 표시·광고 심사지침"의 경제적 이해관계 표시 요건을 확인한다 [확인 필요: 현행 개정판].
- 수강 인증 리뷰만 허용, 진도 일정 비율 이상일 때 작성 가능, 리뷰 대가 이벤트는 표시.
- 부정 리뷰 삭제는 정책 위반(욕설, 개인정보, 광고)만 근거로 한다. 불리한 리뷰 선별 삭제는 소비자 기만 소지가 있다 [확인 필요].
- 강사 답변 기능을 두고, 답변 기한을 P06 강사 운영정책에 둔다.

### 재제작·폐기 판단 (데이터 기준 예)

| 신호 | 계산 | 판단 예 [가정] |
|------|------|----------------|
| 완주율 | 수강자 중 수료 비율 | 같은 카테고리 중앙값 대비 크게 낮으면 점검 |
| 구간 이탈 | 레슨별 시청 지속 곡선의 급락 지점 | 특정 강에서 급락 → 해당 강 재촬영 후보 |
| 평점·리뷰 키워드 | "음질", "오래됨", "설명 부족" 빈도 | 제작 차원 문제 분리 |
| 환불 사유 | 환불 요청 사유 분류 | "내용 다름", "수준 안 맞음" 비율 증가 시 상품 설명·난이도 태그 수정 |
| 오류 신고 | 1,000 수강당 확정 오류 수 | 기준 초과 시 전면 검수 |
| 최신성 | 버전·법령 변경 | 변경 시 강제 점검, 만료일 도래 시 판매 중지 |
| 학습 성과 | 사후 평가 점수, 숙달 비율 | 평점은 높아도 성과가 낮으면 교수 설계 재검토 |

- 판단 결과: 유지 / 부분 수정 / 재촬영 / 판매 중지(기존 수강생 기간 보장) / 폐기.

### 정기 점검과 강사 피드백 루프

- 분기별 상위 매출·하위 지표 과정 점검, 연 1회 전체 최신성 점검.
- 강사에게 월간 리포트(완주율, 구간 이탈 그래프, 리뷰 요약, 오류 신고)를 보낸다. 비교 지표는 카테고리 중앙값으로 보여 주고 공개 랭킹은 피한다.
- 강사가 수정 요청을 거부할 때의 절차(협의 → 비공개 → 계약 조항)를 P06·P02에 둔다.

| AT01 마켓플레이스 | 입점 심사 기준, 대량 강의의 표본 검수, 리뷰 관리 |
| AT02 기업교육 | 고객사 검수·승인 단계, 사내 규정 반영 |

| AT09 자격증 | 출제 기준·법령 개정 즉시 반영, 정답 오류 S1 처리 |
| AT10 AI 튜터 | 지식베이스 원천 콘텐츠 품질이 AI 답변 품질을 결정 (A01) |

## 에듀테크 PM 적용

**체크리스트 (P04 콘텐츠품질관리기준)**

- [ ] 품질 차원 5개별 기준과 검수 담당 역할을 정한다
- [ ] 출시 전 체크리스트를 L02 파이프라인의 검수 단계 완료 조건으로 넣는다
- [ ] 오류 신고 심각도·SLA표를 정하고 P05 CS 흐름과 연결한다
- [ ] 리뷰 작성 조건, 삭제 기준, 대가 표시 규칙을 정한다
- [ ] 재제작·폐기 신호와 임계값을 정하고 분기마다 판정 회의를 연다
- [ ] 강사 월간 리포트 양식을 만든다 (P06)
- [ ] AI로 생성·번역한 콘텐츠는 사람 검수 수준을 따로 정한다 (A07, A08, E14)

**관련 산출물**: P04(주), L02, L01, E11, P05, P06, A01(지식베이스 품질), A07(자막 품질), A08(생성 문항 검증).

## 흔한 오해

- "평점 높으면 좋은 강의" — 평점은 재미·쉬움에 끌린다. 학습 성과와 함께 본다.
- "출시 검수만 잘하면 된다" — 법령·버전 변경으로 품질은 시간이 지나며 떨어진다.
- "나쁜 리뷰는 지우면 된다" — 기만 소지가 있고 신뢰를 잃는다.
- "AI 자막이면 검수 불필요" — 전문 용어·고유명사 오류가 남는다.
