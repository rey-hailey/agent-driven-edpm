# 대화형 AI 인터페이스 설계 (메시지 화면 세부)

## 핵심 요약

- 대화 화면은 **메시지 목록 + 입력 영역 + 보조 패널(근거·힌트 단계)** 3영역이다. IA는 [[domain/대화형AI서비스IA]], 이 페이지는 화면 안의 컴포넌트를 다룬다.
- 학습용 대화의 핵심 장치는 **힌트 사다리 버튼**이다. 학생이 "정답 보기"가 아니라 "다음 힌트"를 누르게 하고, 정답 공개는 시도 후·교사 설정에 따라 연다 ([[domain/AI튜터설계]]).
- 스트리밍 응답은 기다림을 줄이지만 스크린리더 사용자에게는 소음이 된다. 완료 시점 공지와 일시정지 수단이 필요하다 (WCAG 2.2.2, 4.1.3).
- 수학·과학은 수식 렌더링, 코딩은 코드 블록, 저학년은 음성 입출력이 기본 요건이다.

## 상세

### 화면 배치

```
+--------------------------------------------------+
| [<] 중2 수학 · 일차방정식 과제 3번      [근거][...] |
| AI 도우미예요. 틀릴 수 있어요.  (고지 배너, 접기 가능) |
|--------------------------------------------------|
|  (학생) 3x + 5 = 20 어떻게 풀어?                    |
|  (AI) 먼저 x만 남기려면 무엇을 옮겨야 할까?           |
|       [힌트 1/3 사용] [도움됐어요] [헷갈려요] [신고]   |
|  ----------------------------------------------  |
|  [다음 힌트]  [내 풀이 보여 주기]  [선생님께 물어보기] |
|--------------------------------------------------|
| [+첨부] [마이크]  메시지를 입력하세요...     [보내기] |
+--------------------------------------------------+
```

### 메시지·컴포넌트 표

| 컴포넌트 | 설계 포인트 |
|----------|-------------|
| 메시지 레이아웃 | 학생/AI 구분은 정렬·배경·라벨 병기(색만 쓰지 않음, WCAG 1.4.1). AI 메시지에 "AI" 표시 |
| 타이핑·생성 중 표시 | "생각 중" 표시 후 스트리밍. 일정 시간 초과 시 "조금 더 걸려요" [가정: 시간은 A03] |
| 스트리밍 | 단어 단위 표시, 사용자가 위로 스크롤하면 자동 스크롤 멈춤. 완료 시 스크린리더 공지 |
| 정지 | 생성 중 입력창 위치에 "정지" 버튼. 정지 후 부분 답변 보존 + "이어서" 선택 |
| 재생성 | "다른 설명 보기". 이전 답변은 접어서 보존(1/2, 2/2 넘기기) |
| 근거·인용 | 문장 끝 번호 [1] → 근거 패널(교재 쪽수, 영상 시점). 근거 없는 답에는 라벨 |
| 힌트 사다리 | [다음 힌트] 버튼, 사용 단계 표시(1/3), 정답 공개는 시도 횟수·교사 설정 조건 |
| 되묻기 칩 | "내 풀이 보여 주기", "어디까지 했는지 말하기" 등 학생 사고를 끌어내는 응답 칩 |
| 수식 렌더링 | LaTeX → 화면 렌더링, 스크린리더가 읽을 수 있는 형식(MathML 등). 수식 복사 |
| 코드 블록 | 구문 강조, 복사, 실행 결과 분리 ([[domain/코딩실습IDE]]) |
| 이미지 답변 | 그래프·도형은 대체 텍스트 필수 (WCAG 1.1.1) |
| 음성 입력 | 마이크 버튼 길게 누르기/탭 토글, 인식 결과 확인 후 전송. 권한 거부 시 안내 |
| 음성 출력 | 메시지별 "읽어 주기", 속도 조절. 저학년 기본 켜기 [가정] |
| 피드백 | 메시지별 2버튼 + 신고 ([[domain/AI생성결과피드백UI]]) |
| 선생님께 물어보기 | 대화 요약 미리보기 → 학생 확인 → 전송 → "답변 대기 중" 상태 |

### 오류·거절 메시지 원칙

| 유형 | 나쁜 문구 | 좋은 문구 |
|------|-----------|-----------|
| 생성 실패 | "오류가 발생했습니다(500)" | "답을 만들지 못했어요. 다시 해 볼까요?" [다시 시도] |
| 정답만 요구 | "정답을 알려 줄 수 없습니다" | "답보다 푸는 길을 같이 찾아보자. 첫 단계부터 볼까?" [힌트 1] |
| 시험 중 | "차단됨" | "지금은 시험 시간이라 쉬어요. 3시 이후에 다시 만나요" |
| 범위 밖 주제 | "답변할 수 없는 질문입니다" | "그건 내가 도와줄 수 없는 주제야. 공부 질문이라면 언제든 좋아" |
| 근거 없음 | (추측 답변) | "교과서에서 찾지 못했어. 선생님께 물어볼까?" [선생님께] |
| 위기 신호 | 일반 답변 계속 | 대화 중단, 도움받을 곳 안내, 지정 교사 알림 (P08) |

원칙: 학생 탓 금지, 다음 행동 하나 제시, 기술 용어 금지 (E10 3절 오류 문구 원칙과 같다).

### 연령별 변형

| 항목 | 초등 저학년 | 초등 고학년·중학 | 고등·성인 |
|------|-------------|------------------|-----------|
| 입력 | 음성·버튼 선택 중심, 자유 입력 최소 | 텍스트 + 칩 | 텍스트 중심 |
| 답변 길이 | 1~2문장 + 그림 [가정] | 3~4문장 [가정] | 제한 완화 |
| 캐릭터 | 친근하되 사람처럼 속이지 않음 | 선택 | 없음 또는 선택 |
| 힌트 | 단계 버튼 크게, 정답 공개 없음 | 시도 후 공개 | 학습자 선택 |
| 글자 크기 | 18px 이상 [가정] | 16px 이상 | 16px |

## 에듀테크 맥락

- 학생: 정답 복사 도구가 되지 않도록 힌트·되묻기가 화면의 주 버튼이어야 한다.
- 교사: 반별로 정답 공개 조건·힌트 단계 수·음성 사용을 설정 ([[domain/모델설정화면설계]]).
- 보호자: 저학년은 보호자가 옆에서 함께 쓰는 경우가 많다. 음성 출력과 큰 글씨 [가정].
- 미성년: 외부 링크는 승인된 도메인만, 이미지 업로드 시 얼굴·개인정보 경고.

## 상태·예외

| 상황 | 처리 |
|------|------|
| AI 응답 지연 | 생성 중 표시 → 시간 초과 시 안내 + 정지 |
| 생성 실패 | 입력 보존, 다시 시도, 정적 힌트 제공 |
| 거절 | 위 문구 원칙, 대안 버튼 |
| 근거 없음 | 라벨 + 선생님께 넘기기 |
| 한도 초과 | 입력창 비활성, 남은 시간·초기화 시점, 교재 해설로 이동 버튼 (P09) |
| 모델 장애 | 상단 배너, FAQ·정적 힌트 모드, 기존 대화 열람 |
| 네트워크 끊김 | 미전송 메시지 표시 + 재전송 |
| 콘텐츠 신고 | 신고한 메시지 흐림 처리 선택, 접수 확인 |
| 음성 인식 실패 | "잘 못 들었어요. 다시 말해 줄래요?" + 텍스트 대안 |

## 에듀테크 PM 적용

- [ ] 힌트 사다리 단계 수·정답 공개 조건이 A03·E14와 같은가
- [ ] 거절·근거 없음·위기 신호 문구가 A14·P08 정의와 같은가
- [ ] 스트리밍 완료 공지·일시정지, 수식 읽기, 대체 텍스트가 E13 (c)에 들어갔는가
- [ ] 연령별 변형 값이 E10 4절과 일치하는가
- [ ] 한도·장애 시 입력창 상태가 P09와 같은가
- [ ] 와이어프레임 P0: 대화 기본, 힌트 사용 중, 근거 패널 열림, 거절 응답, 한도 초과, 저학년 음성 모드

## 흔한 오해

- "스트리밍이면 접근성도 해결" — 스크린리더는 매 토큰을 읽거나 아무것도 못 읽는다. 완료 공지가 필요하다.
- "거절은 짧을수록 좋다" — 대안 없는 거절은 학생을 다른 앱으로 보낸다.
- "캐릭터가 사람 같을수록 몰입" — AI임을 흐리면 투명성 원칙과 고지 의무에 어긋난다.
