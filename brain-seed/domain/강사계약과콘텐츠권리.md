# 강사 계약과 강의 콘텐츠 권리

> **법률 자문이 아니다.** 계약서 문구는 반드시 법무 검토를 받는다. 교육 목적 저작물 이용 제한 규정(제25조)은 [[domain/교육저작권]]에서 다룬다. 이 페이지는 **강사·플랫폼 간 권리 배분**에 집중한다.

## 핵심 요약

- 권리 구조는 크게 셋이다: **(1) 플랫폼 귀속**(업무상저작물 또는 양도), **(2) 강사 귀속 + 플랫폼 이용허락**(독점 또는 비독점), **(3) 공동 소유**(권리 행사가 복잡해 비권장).
- **업무상저작물**: 법인등의 기획 하에 업무에 종사하는 자가 업무상 작성하고 법인 명의로 공표하면, 계약·근무규칙에 다른 정함이 없는 한 법인이 저작자다 (저작권법 제9조, https://casenote.kr/법령/저작권법/제9조). 외부 프리랜서 강사가 이 요건을 충족하는지는 사실관계에 따라 다투어질 수 있다 [확인 필요: 판례]. [verified 2026-10-12: 조문]
- **양도해도 2차적저작물작성권은 특약 없으면 빠진 것으로 추정**된다 (제45조 제2항, 프로그램은 예외. https://casenote.kr/법령/저작권법/제45조). 클립·번역·더빙·요약본을 만들려면 계약에 명시해야 한다. [verified 2026-10-12]
- **영상저작물 특례**: 영상제작에 협력하기로 약정한 자의 권리 중 영상저작물 이용에 필요한 권리는 특약이 없으면 영상제작자가 양도받은 것으로 추정한다 (제100조 제1항, https://casenote.kr/법령/저작권법/제100조). 강의 영상에 이 특례가 어디까지 적용되는지는 [확인 필요]. [verified 2026-10-12: 조문]
- **저작인격권**(공표권·성명표시권·동일성유지권)은 저작자 일신에 전속해 양도할 수 없다 (제11~14조) [확인 필요: 조문 대조]. 편집·AI 더빙·요약이 동일성유지권 문제를 낳을 수 있으므로 불행사 약정이나 범위 합의를 둔다 [확인 필요: 불행사 특약의 유효 범위].

## 상세

### 소유 모델 비교

| 모델 | 구조 | 장점 | 위험 | 맞는 경우 |
|------|------|------|------|-----------|
| 플랫폼 귀속 (양도·업무상저작물) | 제작비 전액 플랫폼 부담, 강사는 고정 강사료 | 재편집·2차 이용·재판매 자유 | 강사 이탈 후 갈등, 2차적저작물작성권 누락 시 추정 규정으로 불리 | 오리지널 제작, 사내 강사 |
| 강사 귀속 + 독점 이용허락 | 강사가 권리 보유, 플랫폼이 기간·매체 독점 | 강사 유치 쉬움, 경쟁사 유출 방지 | 기간 만료 시 상품 소멸, 해지 분쟁 | 유명 강사, 수익 배분형 |
| 강사 귀속 + 비독점 이용허락 | 오픈 마켓 입점 | 공급 확대 | 동일 강의 다른 플랫폼 저가 판매 | AT01 마켓플레이스 |
| 공동 소유 | 지분 공유 | 공동 제작 반영 | 공동저작물 행사에 전원 합의 필요 [확인 필요] | 비권장 |

### 이용허락 범위 항목

| 항목 | 정할 것 | 예 |
|------|---------|-----|
| 지역 | 국내·전 세계 | 해외 한인 대상 판매 포함 여부 |
| 기간 | 계약 기간, 수강생 이용 기간(존속 조항) | 계약 종료 후에도 기존 수강생 수강 기간까지 서비스 |
| 매체·채널 | 웹, 앱, B2B LMS 납품(SCORM 패키지), 오프라인 상영, IPTV | B2B 재판매 시 별도 수익 배분 |
| 2차적저작물 | 클립·쇼츠, 요약본, 번역 자막, 더빙, 교재화, 문항화 | 마케팅 클립은 허용, 유료 축약판은 별도 합의 |
| AI 이용 | 자막·번역 자동화, AI 더빙·음성 복제, AI 튜터 지식베이스(RAG), 모델 학습 | 각각 별도 체크박스로 동의 |
| 성명·초상·음성 | 강사 이름·사진·목소리를 홍보와 AI 합성에 쓰는 범위 | 퍼블리시티·초상 관련 별도 조항 [확인 필요: 국내 법적 근거] |
| 수정 권한 | 오류 수정, 법령 개정 반영, 재편집 | 내용 변경은 강사 확인 후 |

- **AI 학습 이용**은 가장 분쟁이 많은 신규 항목이다. "콘텐츠 개선 목적" 같은 포괄 문구보다 (a) 서비스 내 RAG 근거로 사용, (b) 자체 모델 미세조정, (c) 외부 업체 모델 학습 제공을 나누고 각각 동의·보상을 정한다.
- **음성 복제·AI 더빙**은 저작권 외에 음성·초상 권리, 딥페이크 오용 문제가 있어 별도 동의서와 사용 범위(언어, 기간, 회수 방법)를 둔다.

### 제3자 자료 (강의 안에 들어가는 남의 것)

| 자료 | 확인 | 메모 |
|------|------|------|
| 이미지·도표·스크린샷 | 출처, 라이선스, 상업 이용 | 소프트웨어 화면 녹화는 해당 업체 정책 확인 [확인 필요] |
| 음원·효과음 | 영상 동기화(싱크) 권리 포함 여부 | 무료 음원도 유튜브용과 유료 강의용 조건이 다를 수 있음 |
| 폰트 | 영상·인쇄물·웹 임베딩 허용 범위 | 개인용 무료 폰트의 상업 영상 사용 여부 |
| 교재·논문·기사 인용 | 인용 요건(제28조), 분량 | 교육 목적이라는 이유만으로 허용되지 않음 ([[domain/교육저작권]]) |
| 기출문제 | 출제기관 권리 | 시험 주관 기관별 정책 [확인 필요] |
| 생성형 AI 산출물 | 도구 이용약관, 표시 의무 | AI 기본법 생성물 표시 ([[domain/아동개인정보보호]]) |

- 강사 진술·보증 조항: 강사가 제3자 권리 침해가 없음을 보증하고, 침해 시 책임과 플랫폼의 즉시 비공개 권한을 둔다.

### 계약 종료와 게시 중단

- 종료 사유: 기간 만료, 강사 귀책(품질·물의), 플랫폼 귀책(정산 지연), 합의 해지.
- 종료 후 처리: (1) 신규 판매 중단일, (2) 기존 수강생 이용 보장 기간, (3) 클립·마케팅물 회수 기한, (4) AI 지식베이스·파생 데이터 삭제 여부, (5) 원본 파일 반환·보관.
- 강사 물의(사회적 논란)로 인한 게시 중단: 판매 중단 시 수강생 환불 기준([[domain/환불정책]])과 강사 정산 환입을 함께 정한다.
- 권리 침해 신고(게시 중단 요청)를 받으면 임시 비공개 → 강사 소명 → 복원 또는 삭제 절차를 둔다 (온라인서비스제공자 책임 제한 규정 적용 여부는 [확인 필요]).

## 서비스 유형별 차이

| 유형 | 주된 모델 | 특이 사항 |
|------|-----------|-----------|
| AT01 마켓플레이스 | 강사 귀속 + 비독점(일부 독점 프로모션) | 표준 약관형 계약, 대량 입점, 침해 신고 처리 |
| AT02 기업교육 | 고객사 맞춤 제작물은 고객사 귀속 요구가 많음 | 기존 강의 재사용분과 신규 제작분을 분리 |
| AT03 부트캠프 | 커리큘럼은 회사, 실시간 강의 녹화본 권리는 계약별 | 수강생 프로젝트 결과물 권리도 정함 |
| AT04 라이브·튜터링 | 튜터 자체 자료가 많음 | 녹화본 보관·재사용 동의, 수강생 초상 |
| AT06 학원 | 강사 이적 시 교재·영상 권리 분쟁 | 강사 개인 브랜드와 학원 브랜드 분리 |
| AT10 AI 튜터 | 콘텐츠를 지식베이스로 씀 | AI 이용 범위 조항이 핵심 |

## 에듀테크 PM 적용

**체크리스트 (P02 콘텐츠권리·강사계약정책)**

- [ ] 상품군별 소유 모델을 정한다 (오리지널, 입점, B2B 맞춤)
- [ ] 2차적저작물(클립, 번역, 더빙, 교재, 문항)을 항목별로 열거해 허락받는다 (제45조 제2항 추정 대비)
- [ ] AI 이용 범위를 RAG·미세조정·외부 제공으로 나눠 별도 동의를 받는다 (A01, A07, A08과 연결)
- [ ] 음성 복제·AI 더빙은 별도 동의서와 회수 절차를 둔다 (A07)
- [ ] 제3자 자료 원장(이미지·음원·폰트·인용)을 L02 파이프라인 검수 단계에 넣는다
- [ ] 저작인격권(성명 표시, 편집 범위) 합의 문구를 법무와 검토한다
- [ ] 종료 후 처리 5항목을 계약서와 P06 강사 운영정책에 반영한다
- [ ] 권리 침해 신고 처리 흐름을 P05 CS 정책에 넣는다
- [ ] 정산(S07)과 권리(수익 배분 근거)가 일치하는지 확인한다

**관련 산출물**: P02(주), P06, L02, S07, A01(지식베이스에 넣을 수 있는 콘텐츠 범위), A07(번역·더빙), A08(문항 원천 자료), E14(AI 이용 범위).

## 흔한 오해

- "돈 주고 만들었으니 회사 것" — 외부 강사는 업무상저작물 요건이 다투어질 수 있고, 양도 계약이 있어도 2차적저작물작성권은 추정상 빠진다.
- "자막·번역은 단순 부가 작업" — 번역은 2차적저작물 작성에 해당할 수 있다.
- "강의 콘텐츠를 AI 튜터에 넣는 건 내부 이용" — 계약 범위에 없으면 분쟁 소지가 크다.
- "무료 음원·무료 폰트라 괜찮다" — 상업·영상 이용 조건이 따로 있다.
