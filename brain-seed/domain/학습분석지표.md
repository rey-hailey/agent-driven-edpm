# 학습 분석 지표 (학습 지표 vs 참여 지표)

## 핵심 요약

- 에듀테크 지표는 **학습 지표**(무엇을 배웠나), **참여 지표**(얼마나 썼나), **사업 지표**(돈이 되나), **가드레일 지표**(해를 끼치지 않나)로 나눈다. EdPM 프레임워크는 학습 지표를 북극성으로, 참여·사업을 보조로, 안전을 가드레일로 둔다 (E07).
- 참여는 학습의 필요조건일 수 있지만 충분조건이 아니다. 접속 시간·세션 수가 늘어도 학습은 늘지 않을 수 있다 [가정: 제품별 검증 필요].
- 학습 시간(time-on-task)은 로그로 측정할 때 측정 방식 선택(비활동 컷오프 등)에 따라 값과 결론이 크게 달라진다 (Kovanović et al., 2015, LAK, https://doi.org/10.1145/2723576.2723623).

## 상세

### 지표 층위

| 층위 | 예시 | 주의 |
|------|------|------|
| 학습 성과 | 사전·사후 검사 향상, 지연 검사 정답률, 성취기준별 숙달률, 외부 시험 성적 | 비교군 없으면 인과 주장 불가 ([[domain/효과크기와증거수준]]) |
| 학습 과정 | 문항 정답률 추이, 힌트 사용 후 독립 정답, 오개념 해소율, 재시도 후 성공 | 문항 난이도 변화와 혼동 주의 |
| 숙달 | 지식추적 모형의 숙달 확률, 숙달 도달까지 문항 수·시간 | 모형 가정과 임계값 문서화 |
| 참여 | DAU/WAU, 주간 학습일수, 세션 길이, 과제 완료율 | 보상·강제 과제로 부풀려짐 |
| 교사 사용 | 주간 활성 교사, 수업당 사용 차시, 과제 배포 수 | B2S 갱신의 선행 지표 [가정] |
| 사업 | 유료 전환, 갱신율, NRR, 좌석 활성화율 | [[domain/세그먼트별의사결정구조]] |
| 가드레일 | 야간 사용 비율, 과도 사용, 신고·민원, 개인정보 사고, 오답 AI 응답률 | 아동 대상이면 필수 |

### 숙달 측정

- 베이지안 지식추적(BKT): 학습자가 기술을 숙달했는지 은닉 상태로 두고 정답·오답 응답으로 확률을 갱신하는 모형 (Corbett & Anderson, 1994, https://doi.org/10.1007/BF01099821).
- 문항반응이론(IRT): 문항 난이도·변별도와 학습자 능력을 같은 척도에서 추정. 시험 점수 비교에 유용하다.
- 정답률 단순 평균은 문항 난이도가 다르면 비교가 왜곡된다.

### 학습 시간 측정의 함정

- 로그 기반 시간은 탭을 열어두기, 다른 일 하기를 구분하지 못한다. 비활동 컷오프(예: 5분, 30분)를 어떻게 잡느냐에 따라 같은 데이터에서 다른 결론이 나올 수 있다 (Kovanović et al., 2015).
- 학습 시간 증가는 "효율이 떨어졌다"는 뜻일 수도 있다. 같은 숙달에 걸린 시간 감소가 더 나은 지표인 경우가 많다 [가정].

### 안티 메트릭 (최적화하면 안 되는 지표)

- 단순 체류 시간, 세션 수: 학습 효율 개선과 반대 방향일 수 있다
- 퀴즈 즉시 정답률: [[domain/인출연습]]처럼 어려운 학습 활동이 낮출 수 있다
- 포인트·배지 획득 수: 시스템 착취 행동과 섞인다 (Baker et al., 2004, https://doi.org/10.1145/985692.985741)
- 영상 시청 완료율: 재생만 켜 둔 경우와 구분 불가

## 에듀테크 PM 적용

- [ ] E07에서 북극성(학습) 1개, 보조(참여·사업) 2~4개, 가드레일 2~3개를 정하고 각 지표의 계산식·데이터 출처를 SQL 수준으로 적는다
- [ ] 참여 지표 개선 실험에는 학습 지표 또는 가드레일을 반드시 같이 본다
- [ ] 학습 시간 지표를 쓸 때 비활동 컷오프 규칙을 문서화한다
- [ ] 숙달 판정 모형(BKT/IRT/규칙 기반)과 임계값을 E12에 기록한다 ([[domain/숙달학습]])
- [ ] 학생 개인 수준 지표를 외부 공유할 때 비식별·집계 원칙을 따른다 ([[domain/아동개인정보보호]])

## 흔한 오해

- "사용 시간이 늘면 학습도 는다" — 상관이 있을 수 있어도 인과는 별도 검증이 필요하다.
- "앱 내 정답률 상승 = 학습 효과" — 문항이 쉬워졌거나 같은 문제 반복일 수 있다.
- "대시보드 지표가 많을수록 좋다" — 행동으로 이어지는 소수 지표가 낫다.
