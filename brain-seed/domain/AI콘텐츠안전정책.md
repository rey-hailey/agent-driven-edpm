# AI 콘텐츠 안전 정책

> **법률 자문이 아니다.** 위기 개입 절차는 학교·기관의 기존 학생 보호 절차와 맞춰야 하며, 상담 전문가 검토를 받는다. 상담 번호는 바뀔 수 있으므로 출시 전 공식 안내로 재확인한다.

## 핵심 요약

- 학습자 대상 AI의 유해 콘텐츠 범주를 먼저 정의한다: **폭력, 성적 콘텐츠, 자해·자살, 혐오·차별, 위험 행동(약물·무기·위험한 실험), 연령 부적합(도박, 음주 등), 괴롭힘, 개인정보 노출** [가정: 범주 틀].
- 위기 신호(자해·자살 암시, 학대·폭력 피해 진술)는 **AI가 상담하지 않고 사람에게 넘기는** 흐름이 기본이다. 국내 안내 번호: 자살예방 상담전화 **109**(2024.1.1.부터 운영, 기존 1393 대체), 청소년상담 **1388**(9~24세 청소년과 보호자, 365일 24시간), 정신건강 위기상담 **1577-0199**, 생명이 위급하면 **119·112** (보건복지부 109 보도 https://www.etoday.co.kr/news/view/2312343 ; 여성가족부 1388 https://www.mogef.go.kr/cc/ccy/cc_ccy_f001.do ; 서울시 복지 https://news.seoul.go.kr/welfare/archives/561837). [verified 2026-10-12: 보도·기관 안내 기준] 1388 문자 발송 방식(1388 vs #1388)은 출처마다 달라 [확인 필요].
- 모더레이션은 **분류기 + 규칙 + 사람 검토**의 층으로 만든다. 입력·출력 양쪽에 건다.
- 이미지·음성 생성은 텍스트보다 위험이 크다. 실제와 구별하기 어려운 가상 음향·이미지·영상은 AI 생성물임을 분명히 알 수 있게 고지·표시해야 한다 (AI 기본법 제31조 ③, https://casenote.kr/법령/인공지능_발전과_신뢰_기반_조성_등에_관한_기본법/제31조). [verified 2026-10-12]

## 상세

### 범주별 정책 표 (P08 초안 틀)

| 범주 | 입력 대응 | 출력 대응 | 사람 연결 |
|------|-----------|-----------|-----------|
| 자해·자살 | 위기 흐름 전환, 일반 대화 중단 | 생성 차단 | 즉시 (지정 담당자·보호자 절차) |
| 학대·폭력 피해 진술 | 공감 + 도움 안내, 캡처 보존 | 조언 생성 금지 | 즉시 (학교 절차에 따름) |
| 성적 콘텐츠 | 차단·경고 | 차단 | 반복 시 |
| 혐오·차별 | 경고, 교육적 응답 | 차단 | 반복 시 |
| 위험 행동 | 안전 안내로 대체 | 절차·방법 생성 금지 | 필요 시 |
| 연령 부적합 | 연령별 허용 목록 | 필터 | 아니오 |
| 괴롭힘(또래 대상) | 경고 | 차단 | 교사 알림 |
| 개인정보 노출 | 마스킹 ([[domain/AI개인정보보호]]) | 차단 | 아니오 |

- 학습 맥락의 예외를 명시한다: 역사 수업의 전쟁, 보건 수업의 성교육, 문학의 폭력 묘사. 과목·학년별 허용 규칙으로 과차단을 줄인다.

### 위기 신호 처리 흐름

```
신호 탐지(규칙·분류기) → AI 응답 전환(공감 + 도움 번호 안내, 상담 시도 금지) → 담당자 알림(교사·상담교사·운영팀) → 사람 확인 → 기관 절차에 따른 보호자 연락 → 기록(최소 정보) → 사후 검토
```

- 누가 알림을 받는지는 고객 유형별로 다르다: 학교(담임·상담교사·학교 절차), 학원(원장·보호자), B2C(운영팀·보호자 연락처). 야간·주말 대응 공백을 계약·정책에 명시한다.
- 오탐(위기 아닌데 알림)보다 미탐이 치명적이다. 위기 분류기는 재현율을 우선해 기준을 잡고 사람 확인으로 오탐을 거른다.

### 모더레이션 파이프라인

| 층 | 내용 |
|----|------|
| L1 규칙 | 금칙어·패턴, 연령별 목록, 우회 표기(초성·띄어쓰기) |
| L2 분류기 | 범주별 점수, 임계값 기능별 조정 |
| L3 LLM 판정 | 맥락 판단(교육적 예외), 고위험만 |
| L4 사람 검토 | 위기·신고·이의 제기 건 |

- 업체가 제공하는 안전 필터는 범주 정의·한국어 성능이 우리 기준과 다를 수 있으므로 우리 평가세트(한국어, 학년별 은어 포함)로 측정한다.

### 이미지·음성 생성

- 위험: 실존 인물 합성(교사·학생 얼굴), 성적 이미지, 딥페이크 괴롭힘, 음성 사칭.
- 통제: 실존 인물·사진 업로드 기반 생성 차단 또는 제한, 생성물 표시(제31조 ③), 메타데이터 기록, 학생 대상 기능은 허용 주제 목록 방식.

### 신고와 이의 제기

- 학습자·교사·보호자 모두 신고 가능. 처리 결과 회신. 과차단 이의 제기(예: 성교육 질문 차단) 경로를 둔다.

### 기록과 프라이버시

- 위기 건은 최소 정보(시각, 범주, 조치, 담당자)를 기록하고 대화 원문 접근은 지정 인원으로 제한한다. 보존 기간을 정한다 ([[domain/학습데이터프라이버시]]).

## 에듀테크 맥락

- **미성년**: 기본값은 엄격하게, 학년이 오를수록 완화. 아동은 위험을 우회 표현으로 말하는 경우가 많아 분류기 평가에 실제 표현을 넣는다 [가정].
- **학생 평가**: 서술형 답안에 위기 신호가 섞일 수 있다. 채점 파이프라인에도 위기 탐지를 둔다.
- **고객 요구**: 학교·교육청은 학생 보호 절차와의 연계, 알림 수신자 지정, 사고 보고를 요구하는 경우가 많다. 기업 고객은 직장 내 괴롭힘·혐오 표현 정책 연계를 본다 [가정].

## 방식별 차이

| 방식 | 안전 특성 |
|------|-----------|
| 규칙·NLP | 빠르고 설명 가능, 우회에 약함 |
| RAG | 근거 문서 자체의 부적합 내용 점검 |
| 로컬 LLM | 안전 튜닝이 약할 수 있어 외부 필터 층 필수 |
| 클라우드 LLM | 업체 필터가 있지만 범주·언어 성능 확인 필요 |

## 에듀테크 PM 적용

- [ ] 범주 정의와 연령·과목별 허용 규칙을 P08에 적는다
- [ ] 위기 흐름과 알림 수신자, 야간·주말 대응을 고객 유형별로 정한다 (E13, P08)
- [ ] 상담 번호를 출시 전 공식 안내로 재확인한다
- [ ] 모더레이션 층과 임계값, 오탐·미탐 기준을 A14에 둔다
- [ ] 한국어·학년별 표현을 담은 안전 평가세트를 만든다 (A13, E14)
- [ ] 이미지·음성 생성 기능은 별도 위험 검토를 받는다 (P07, E13)
- [ ] 신고·이의 제기 처리 SLA를 P05·P08에 넣는다

**관련 산출물**: P08(주), A14, E13, E14, A13, P07, P09(장애 시에도 위기 흐름 유지), A12(안전 호출은 비용 하향 제외), P05.

## 흔한 오해

- "업체 필터를 켰으니 끝" — 한국어 은어·우회 표현·교육적 예외는 우리가 평가해야 한다.
- "AI가 공감해 주면 상담 효과" — 위기 상황에서 AI 상담은 위험하다. 사람에게 연결한다.
- "엄격할수록 안전" — 과차단은 성교육·역사 학습을 막고 신뢰를 잃게 한다.
