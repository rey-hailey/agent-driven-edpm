# 부정 수강 방지

> 부정 이용 대응은 매출 보호와 공정성(수료·자격 신뢰)을 지키는 일이지만, 과도한 감시는 정상 학습자를 내쫓고 개인정보 위험을 만든다. **탐지 정확도, 대응 강도, 개인정보 부담**을 같이 설계한다.

## 핵심 요약

- 부정 유형은 다섯 갈래다: **계정 공유·동시 접속, 대리 수강, 진도 조작, 시험 부정, 콘텐츠 유출**.
- 기술 통제(기기 제한, DRM, 본인인증)는 비용을 올릴 뿐 완전히 막지 못한다. 화면 녹화 차단은 OS·기기마다 한계가 있고 외부 카메라 촬영은 막을 수 없다. 그래서 **추적(포렌식 워터마크) + 단계적 대응 + 이의 제기**가 함께 필요하다.
- **환급 과정**(사업주 직업능력개발훈련 원격훈련)에서는 대리·허위 수강 시 훈련비 지원을 받을 수 없다고 훈련기관들이 공지한다. 본인 명의 휴대폰 본인인증, mOTP 인증을 수강·평가 시점에 요구하는 사례가 확인된다 (https://winspec.co.kr/careful/careful.html , https://www.kpc.or.kr/PTWCC013_com10_index.do). 고용노동부·한국산업인력공단의 공식 원격훈련 운영 기준, 모사답안 판정 기준은 [확인 필요].
- 자동 탐지로 계정을 정지하면 **자동화된 결정**에 해당할 수 있다. 개인정보 보호법 제37조의2는 완전히 자동화된 결정이 권리·의무에 중대한 영향을 미칠 때 거부·설명 요구권을 준다 (2024.3.15. 시행, https://www.jipyong.com/newsletter_alert/240329_2/index.html). 계정 정지가 "중대한 영향"인지는 [확인 필요]. [verified 2026-10-12: 시행일]

## 상세

### 유형별 탐지·통제 수단

| 유형 | 신호 (탐지) | 통제 | 한계 |
|------|-------------|------|------|
| 계정 공유·동시 접속 | 동시 세션 수, 짧은 시간 내 원거리 IP·국가 변경, 기기 지문 수 급증 | 동시 재생 1개, 등록 기기 N대(예: 2~3대) + 교체 횟수 제한 | 가족 공유·회사 VPN·이동통신 IP 변동으로 오탐 |
| 대리 수강 | 학습 패턴 급변(시간대, 속도, 기기), 평가 시점 기기 불일치 | 수강·평가 시점 본인인증, 무작위 확인 질문 | 본인인증 후 넘겨주기는 못 막음 |
| 진도 조작 | 재생 속도 이상, 백그라운드 탭 재생, 이벤트 간격이 기계적으로 일정, 다수 강의 동시 재생 | 서버측 진도 계산, 재생 위치 무작위 확인 이벤트, 창 비활성 시 진도 정지 | 정상적인 "틀어 놓고 듣기"와 구분 어려움 |
| 시험 부정 | 응시 시간 비정상, 답안 유사도, 문항별 시간 분포, 다수 계정 동일 IP 동시 응시 | 문항 은행 무작위 출제, 보기 섞기, 시간 제한, 온라인 감독 | 감독 강화는 개인정보·접근성 부담 |
| 콘텐츠 유출 | 외부 사이트·커뮤니티 모니터링, 워터마크 추적 | DRM(재생 암호화), 다운로드 제한, 가시·비가시 워터마크 | 카메라 촬영, 일부 환경의 화면 녹화 |

### 시험 감독 선택지 (강도 순)

| 수준 | 방식 | 개인정보 부담 | 적합 |
|------|------|---------------|------|
| 0 | 설계로 방지: 문항 은행, 개방형 과제, 시간 제한 | 없음 | 형성평가, 저부담 퀴즈 |
| 1 | 응시 서약 + 사후 통계 분석(유사도·시간) | 낮음 | 일반 수료 평가 |
| 2 | 브라우저 잠금, 본인인증 | 중간 | 환급 과정 평가 [확인 필요: 요건] |
| 3 | 웹캠 녹화 + 사후 사람 검토 | 높음 (영상·얼굴) | 자격 연계 시험 |
| 4 | 실시간 감독관 + AI 이상 탐지 | 매우 높음 (생체정보 쟁점) | 고부담 시험만 |

- 얼굴 인식으로 본인 확인을 하면 생체인식정보·민감정보 처리 문제가 생긴다 [확인 필요: 개인정보 보호법 제23조·시행령 해석]. 대체 수단(감독관 확인)을 준비한다.
- 웹캠 감독은 장애 학습자(시선 추적 오탐), 공용 공간 응시자, 저사양 기기 사용자에게 불리하다 ([[domain/접근성]]).

### DRM·워터마크

- **DRM**: 다운로드 파일 암호화와 재생 앱 통제. 구현 비용과 재생 호환성(브라우저·OS) 문제가 있다.
- **포렌식(비가시) 워터마크**: 사용자별 식별자를 영상에 심어 유출 원본 계정을 추적한다. 억지 효과는 "추적된다"는 사실을 알릴 때 커진다.
- **가시 워터마크**: 화면 구석에 이메일 일부·ID를 반투명 표시. 학습 방해와 개인정보 노출 사이 균형.
- 화면 녹화 차단은 플랫폼별로 지원 범위가 다르므로 "완전 차단"을 약속하지 않는다.

### 환급 과정 (사업주 훈련) 주의 [확인 필요]

- 훈련기관 공지 기준 원격훈련 수료 요건 예: 진도율 80% 이상, 평가 60점 이상, 진행·최종 평가 응시, 과제 제출 (https://winspec.co.kr/careful/careful.html). 공식 기준 원문은 HRD-Net·고용노동부 고시로 확인한다.
- 본인인증 시점 예: 회원가입, 수강신청, 최초 학습 시작, 평가 응시, mOTP 최초 로그인 (위 공지).
- 과제·평가 **모사답안**(다른 수강생과 유사한 답안) 판정 기준과 처리(수료 제외·지원 제외)는 공식 문서로 확인한다. 유사도 임계값을 임의로 정해 공지하지 않는다.

### 단계적 대응 (graduated response)

| 단계 | 조건 | 조치 | 사람 검토 |
|------|------|------|-----------|
| 1 안내 | 약한 신호 1회 | 화면 안내("다른 기기에서 재생 중") | 불필요 |
| 2 경고 | 반복 또는 중간 신호 | 이메일 경고, 다른 기기 세션 종료 | 불필요 |
| 3 제한 | 강한 신호 | 동시 재생 차단, 기기 재등록 요구, 추가 인증 | 권장 |
| 4 정지 | 확정 증거(워터마크 추적, 명백한 대리) | 계정 일시 정지, 수료 보류 | **필수** |
| 5 해지 | 상업적 유출, 반복 위반 | 계약 해지, 법적 조치 검토, 환불 기준 적용 | **필수** + 법무 |

- 정지·해지 전에 **소명 기회**를 준다. 이의 제기 창구, 처리 기한, 복원 절차를 P03·P05에 쓴다.
- 오탐 비율을 지표로 관리한다: 이의 제기 후 복원 비율이 높으면 규칙을 고친다.

## 서비스 유형별 차이

| 유형 | 주된 위험 | 우선 통제 |
|------|-----------|-----------|
| AT01 마켓플레이스 | 계정 공유, 강의 유출 | 동시 재생 제한, 포렌식 워터마크 |
| AT02 기업교육·환급 | 대리 수강, 진도 조작 → 지원금 문제 | 본인인증, 서버측 진도, 모사답안 점검 |
| AT03 부트캠프 | 과제 표절, AI 대필 | 코드 유사도, 구술 확인, 프로젝트 기반 평가 |
| AT07 소비자 앱 | 가족 계정 공유 | 공유를 막기보다 가족 요금제로 전환 |
| AT08 고등·평생교육 | 시험 부정, 학점 신뢰 | 문항 은행, 감독 수준 단계화 |
| AT09 자격증 | 문제 유출, 모의고사 공유 | 문항 노출 관리, 워터마크 PDF |

## 에듀테크 PM 적용

**체크리스트 (P03 부정이용방지정책)**

- [ ] 유형 5가지별 신호·통제·한계 표를 만든다
- [ ] 진도는 클라이언트 보고가 아니라 서버에서 계산한다 (L03, E12)
- [ ] 동시 재생·기기 수 정책과 예외(가족, 회사 공용 PC)를 정한다
- [ ] 시험 감독 수준을 평가 종류별로 정한다 (L04)
- [ ] 환급 과정이면 공식 원격훈련 기준(본인인증, 모사답안)을 원문으로 확인한다
- [ ] 단계적 대응표와 사람 검토 지점, 이의 제기 절차를 둔다
- [ ] 탐지 로그의 보존 기간과 접근 권한을 E13에 기록한다
- [ ] 얼굴·영상 수집은 대체 수단과 별도 고지를 둔다 (E13)
- [ ] 오탐률·복원률·유출 건수를 월간 지표로 본다

**관련 산출물**: P03(주), L03, L04, E12(이벤트), E13(감시 데이터 영향평가), P05(이의 제기). AI 감독·이상 탐지를 도입하면 A00에서 위험을 평가하고, 판정은 사람이 내린다.

## 흔한 오해

- "DRM이면 유출이 막힌다" — 촬영·녹화 우회가 있어 추적 수단이 함께 필요하다.
- "감독을 세게 할수록 공정하다" — 오탐과 접근성 문제로 정상 학습자가 피해를 본다.
- "탐지되면 자동 정지" — 확정 증거와 사람 검토, 소명 기회 없이 정지하면 분쟁·법적 위험이 커진다.
- "AI 대필은 표절 검사로 잡는다" — AI 생성 탐지기는 오탐이 많아 단독 근거로 쓰지 않는다 [확인 필요: 최신 연구].
