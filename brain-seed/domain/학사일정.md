# 한국 K-12 학사일정과 에듀테크 일정

## 핵심 요약

- 학교의 **학년도**는 3월 1일에 시작해 다음 해 2월 말일에 끝난다 (초·중등교육법 제24조 제1항). **학교회계연도**도 같은 기간이다 (같은 법 제30조의3 제1항) (조문 확인: https://ko.wikisource.org/wiki/초·중등교육법 , 현행 원문은 https://www.law.go.kr). [verified 2026-10-12]
- 구체적인 개학일·방학일·시험일은 **학교마다 다르다**. 학교장이 학교운영위원회 심의 등을 거쳐 정하며, 아래 시기는 일반적 패턴을 나타낸 근사치다 [확인 필요: 대상 학교·교육청 학사일정으로 매번 확인].
- 2027학년도 대학수학능력시험은 **2026년 11월 19일(목)** 시행, 성적 통지는 2026년 12월 11일이다 (https://www.heraldk.com/article/2026062919000082154). [verified 2026-10-12]

## 상세

### 연간 패턴 (근사치)

| 시기 | 학교 상황 | 비고 |
|------|-----------|------|
| 2월 | 신학년 준비 기간, 교사 업무분장·교육과정 편성, 학교회계 연말 | 새 도구 도입 결정이 이뤄지기 쉬운 시기 [가정] |
| 3월 | 1학기 개학(대체로 3월 초), 학급 편성, 계정 생성, 학부모 총회 | 계정·로그인 문제가 집중 [가정] |
| 4월 말~5월 초 | 1학기 중간고사 (중·고) | 시험 기간 전후 수업 변동 |
| 6월 말~7월 초 | 1학기 기말고사 (중·고) | |
| 7월 중순~하순 | 여름방학 시작 | |
| 7월 말~8월 | 여름방학 (대략 3~5주) | 교사 연수 가능 시기 |
| 8월 중순~말 | 2학기 개학 | 2학기 도입·재선정 |
| 9~10월 | 2학기 중간고사 (중·고), 고3 수시 원서 | |
| 11월 | 수능 (11월 중순 목요일이 관례) | 고3 수업 사실상 종료 |
| 12월 | 2학기 기말고사 (중·고) | |
| 12월 말~1월 초 | 겨울방학 시작 (학교별 편차 큼) | 일부 학교는 1월 초까지 수업 후 졸업식과 함께 2월까지 방학 |
| 1~2월 | 겨울방학, 졸업식(1월 또는 2월), 봄방학을 두지 않는 학교 증가 [확인 필요] | 다음 학년도 예산·구매 준비 |

- 초등학교는 지필 중간·기말고사를 보지 않는 경우가 많고 수행평가 중심이다 [확인 필요: 교육청별 정책].
- 수능은 통상 11월 셋째 주 목요일 전후에 시행된다 [확인 필요: 매년 교육부 발표 확인].

### 예산 시기

- 학교회계는 3월~2월이지만, 교육청(교육비특별회계)과 국가 예산은 1월~12월 회계연도를 따른다 [확인 필요: 지방재정법·국가재정법 조문 대조]. 따라서 교육청 사업 예산은 전년도 하반기에 편성되고, 학교 예산은 학년도 시작 전후로 확정되는 이중 구조다 [가정].
- 학교 운영비 집행은 학기 초에 집중되고 학년도 말(1~2월)에는 잔액 집행이 생기는 경향이 있다는 현장 통념이 있다 [가정: 회사 데이터로 검증].

## 에듀테크 PM 적용 (G-CAL 점검)

- [ ] **출시**: 학교 대상 대규모 변경은 학기 중·시험 기간을 피하고, 방학 중 배포 후 개학 전 안정화한다
- [ ] **신학기 대비**: 2월 말까지 계정·명단 연동, 교사 매뉴얼, 고객지원 증원을 끝낸다. 3월 첫 2주는 장애 대응 우선
- [ ] **영업·도입**: 다음 학년도 도입은 전년도 11~2월에 결정되는 경우가 많다 [가정]. 교육청 사업은 전년도 예산 편성 시기를 확인
- [ ] **파일럿**: 한 학기 단위로 설계하고, 사전검사는 3월 중순·9월 초, 사후검사는 기말 전으로 잡는다. 시험 주간 측정은 피한다
- [ ] **교사 연수**: 여름·겨울방학, 2월 신학년 준비 기간
- [ ] **B2C·학원**: 시험 기간 직전(4월, 6월, 9~10월, 11~12월)이 수요 피크, 방학은 특강·선행 수요 [가정]
- [ ] **수능 연계 제품**: 수능 이후 고3 이탈, 신학기 전 예비 고3 유입을 리텐션 지표 해석에 반영
- [ ] 대상 지역 교육청·샘플 학교의 실제 학사일정을 `01.자료실/정책/`에 저장하고 이 페이지와 대조한다

## 흔한 오해

- "모든 학교가 같은 날 개학한다" — 3월 개학은 공통이지만 방학·시험 날짜는 학교별로 다르다.
- "방학 = 사용 중단" — 방학 과제·자기주도 학습으로 B2C 사용은 오를 수 있다 [가정].
- "회계연도 = 1월 시작" — 학교회계는 3월 시작이다.
