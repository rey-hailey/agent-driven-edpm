# AI 글쓰기 첨삭 도구 사례 (가상, W사형)

> **가상 사례입니다.** "W사"는 설명을 위해 만든 가상의 회사이며, 실존하는 어떤 기업·제품의 구조나 수치도 설명하지 않습니다. 모든 수치와 결과는 예시이며 [가정]입니다.

## 핵심 요약

- 가상의 W사는 중학생 국어·사회 서술형 글쓰기에 **AI 피드백 → 학생 수정 → 교사 확인** 흐름을 붙인 도구를 만든다. 핵심 결정은 "AI가 글을 고쳐 주지 않고, 무엇을 고칠지 묻는다"였다 [가정].
- 학생은 AI 피드백을 루브릭 기준별로 받고 스스로 수정한다. 점수는 AI가 확정하지 않고 교사가 확정한다(학생 평가 = 고영향 AI 검토 대상, [[domain/AI적용기회맵]]).
- 이 사례는 앞의 5원칙과 IA 페이지를 한 제품에 적용해 보는 연습용이다.

### 핵심 설계 결정과 트레이드오프

| 결정 | 선택 | 포기한 것 | 근거 |
|------|------|-----------|------|
| 피드백 형태 | 질문형("이 문단의 주장 근거는 무엇일까?") + 근거 문장 강조 | 바로 고친 문장 제시(학생 만족도↑ 예상) | 학생이 스스로 고쳐야 쓰기 능력이 는다 [가정], 대필 우려 |
| 피드백 횟수 | 과제당 2회 [가정] | 무제한 반복 | 반복 요청으로 AI 문장을 맞추는 행동 방지, 비용 |
| 점수 | AI는 초안만, 교사가 확정 | 즉시 점수 | 고영향 AI 검토, 교사 책임 |
| 루브릭 연결 | 피드백을 루브릭 기준별로만 생성 | 자유 코멘트 | 근거 있는 피드백, 교사 검토 속도 |
| 확신 낮음 분리 | 교사 큐에서 먼저 보여 줌 | 일괄 승인 버튼 | 오채점 위험 집중 관리 |
| AI 표시 | 피드백 패널·결과에 "AI 피드백" 라벨, 제출 화면 고지 | 깔끔한 화면 | AI 기본법 제31조, 투명성 |
| 붙여넣기 | 허용하되 기록, 교사 화면에 표시 | 붙여넣기 차단 | 접근성(보조기기 입력)과 학업 윤리 균형 [가정] |

### 지표 (예시)

| 구분 | 지표 | 주의 |
|------|------|------|
| 학습 | 초안→최종 루브릭 점수 변화(교사 채점 기준) | AI 채점 기준으로 재면 순환 논리 |
| 행동 | 피드백 후 실제 수정 비율, 수정 분량 | 분량이 질을 뜻하지 않음 |
| 교사 | 채점 검토 시간, AI 초안 수정률 | 수정률이 낮다고 좋은 것만은 아님(검토 생략 가능) |
| 품질 | AI 피드백 신고율, 근거 없음 비율 | [[domain/AI생성결과피드백UI]] |
| 가드레일 | 대필 요청 거절 수, 개인정보 감지 수 | A14 |

### 피한 실수

- 학생이 "다 고쳐 줘"를 누르면 완성 글이 나오는 버튼을 넣지 않았다.
- AI 점수를 학생에게 먼저 보여 주지 않았다. 교사 점수와 다르면 분쟁이 된다.
- "AI 탐지" 점수를 교사 화면에 넣지 않았다. 오탐 위험이 커서 근거로 쓰기 어렵다 ([[domain/과제와평가설계]]).
- 피드백을 한 번에 10개씩 주지 않았다. 기준별 최대 1~2개로 인지 부하를 줄였다 [가정] ([[domain/인지부하이론]]).

## 에듀테크 맥락

- 학생: 피드백은 "지금 어디 있고, 어디로 가며, 다음에 무엇을 할지"를 담는다 (Hattie & Timperley 3질문, [[domain/형성평가와피드백]]).
- 교사: 확신 낮음 우선 큐와 수정 이력이 검토 시간을 줄이는 장치다.
- 보호자: 만 14세 미만 학생은 보호자 동의 후 사용, 가정 안내문에 AI 역할 설명.
- 관리자: 학생 글 보관 기간과 모델 개선 활용(기본 끔) 설정.

## 상태·예외

| 상황 | 처리 |
|------|------|
| AI 응답 지연 | 피드백 생성 중 표시, 편집은 계속 가능 |
| 생성 실패 | 횟수 차감 없음 + 다시 시도, 루브릭 자기 점검표 제공 |
| 거절(대필 요청·유해 내용) | "글은 네가 쓰고, 나는 질문으로 도와줄게" + 기준별 점검 질문 |
| 근거 없음 | 루브릭 기준과 연결 못 한 피드백은 표시하지 않음 |
| 위기 신호(글 내용) | AI 피드백 중단, 교사·지정 담당자에게 알림 (P08) [가정: 절차는 학교 정책] |
| 횟수 소진 | 남은 시간 동안 자기 점검표, 교사 질문하기 |
| 모델 장애 | 피드백 버튼 비활성 + 배너, 제출 마감 연장 여부는 교사 결정 |
| 콘텐츠 신고 | 피드백 단위 신고, 교사에게도 표시 |

## 흔한 오해

- "AI가 고쳐 주면 글이 좋아진다" — 글은 좋아져도 학생 쓰기 능력이 늘었는지는 모른다 [가정].
- "AI 채점이 일관되니 교사보다 낫다" — 일관되게 틀릴 수 있다. 확정은 사람이.
- "사례 회사가 실제로 이렇게 했다" — 이 페이지는 가상 사례다.
