# 학습 진도 관리 (진도율·완료·수료 규칙)

## 핵심 요약

- "진도율"은 정의하기 나름이다: **시청 비율**, **학습 시간(time-on-task)**, **완료한 항목 수**. 정의마다 조작 가능성과 학습 의미가 다르다.
- 진도율은 수료·환불·정산·정부 지원금 산정에 그대로 쓰이므로 **사업 규칙**이다. 데이터 정의(E12)와 정책(P01·P03)을 함께 설계한다.
- 한국 사업주 직업능력개발훈련의 인터넷원격훈련 지원요건은 **학습활동 참여율 80% 이상 + 훈련실시자가 수립한 별도 수료요건 충족**이다 (한국산업인력공단, https://www.hrdkorea.or.kr/1/1/2/2) [verified 2026-10-12].
- 훈련기관 안내문들은 원격훈련 수료를 "진도율 80% 이상 + 최종평가 응시 + (환산) 총점 60점 이상"으로 설명한다 (https://www.kdedu.co.kr/main/page.jsp?pid=worker.worker04, https://winspec.co.kr/careful/careful.html). 60점 기준의 고시 원문은 이 페이지에서 확인하지 못했다 [확인 필요].

## 상세

### 진도 정의 3가지

| 정의 | 계산 예 | 장점 | 약점 |
|------|---------|------|------|
| 시청 비율 | 실제 재생된 구간 합 / 영상 길이 | 직관적 | 틀어 놓기, 음소거 재생 |
| 학습 시간 | 활성 학습 시간 / 기준 학습 시간 | 정부 훈련 기준과 유사 | 탭 방치, 측정 기준 논쟁 |
| 항목 완료 | 완료 항목 수 / 전체 항목 수 | 다양한 유형 통합 | "완료" 기준이 유형마다 다름 |

- 원격훈련 기관 안내에서는 진도율을 "전체 학습시간 / 전체 소정훈련시간 × 100"으로 설명하기도 한다 (https://www.kdedu.co.kr/main/page.jsp?pid=worker.worker04) [기관 안내 기준].

### 시청 비율 계산의 세부 규칙

- **구간 기록**: 재생 위치를 일정 간격으로 기록하고, 이미 본 구간은 중복 집계하지 않는다.
- **건너뛰기(seek)**: 앞으로 건너뛴 구간은 미시청 처리. 첫 수강 시 건너뛰기 금지 여부를 정책으로 정한다.
- **배속**: 배속 재생 시 실제 경과 시간과 영상 시간 중 무엇을 학습 시간으로 칠지 정한다. 정부 지원 과정은 배속·인정 학습시간 규정을 따로 확인한다 [확인 필요].
- **차시 인정 기준**: 차시별 일정 비율 이상 학습해야 진도에 반영하는 방식이 있다. 훈련기관마다 "차시 85% 이상", "인정 학습시간 50% 초과" 등 기준이 다르게 안내된다 (https://winspec.co.kr/support/notices/268) [기관별 상이, 확인 필요].
- **비활성 감지**: 일정 시간 입력이 없으면 재생 일시정지 또는 확인 팝업.

### 완료·잠금·기간

- **완료 규칙**: 레슨 완료 → 섹션 완료 → 과정 완료. 퀴즈·과제 합격을 조건에 넣을지 정한다 ([[domain/과제와평가설계]]).
- **순차 잠금**: 이전 레슨 완료 전 다음 레슨 잠금. 복습·선택 학습을 막지 않도록 범위를 좁힌다.
- **하루 학습량 제한**: 원격훈련 기관은 하루 새로 진도를 나갈 수 있는 차시 수(예: 8차시)를 제한한다고 안내한다 (https://winspec.co.kr/careful/careful.html) [확인 필요: 고시 원문].
- **수강 기간**: 구매 후 N일, 평생 소장, 구독 기간 동안. 만료 후 열람 가능 여부와 연장 상품을 정한다.
- **라이브 출석**: 입장 시각, 체류 시간 비율, 카메라·응답 확인. 녹화본 시청을 출석으로 인정할지 정한다.

### 넛지(nudge)

- 미학습 N일 알림, 마감 임박 알림, 진도 요약 메일. 알림 과다는 해지·차단으로 이어진다 ([[domain/동기설계]]).
- 미성년 대상은 야간 알림 제한, 보호자 리포트 동의 등을 E13에서 확인한다 ([[domain/아동개인정보보호]]).

### 원격훈련(환급 과정) 운영 시 주의 (한국)

- 원격훈련 지원금은 **훈련수료인원** 기준으로 산정된다 (https://www.hrdkorea.or.kr/1/1/2/2) [verified 2026-10-12]. 진도율 계산 오류는 곧 지원금 오류다.
- 훈련기관 안내에 따르면 최종평가는 진도율 80% 이상일 때 응시 가능하고, 60점 미만이면 종료일 다음 날부터 1주일 안에 재평가 기회를 준다 (https://www.kdedu.co.kr/main/page.jsp?pid=worker.worker04) [확인 필요: 고시 원문].
- 국민내일배움카드 원격훈련에서 진도율 80% 미만 제적·중도 포기 시 계좌 한도 차감이 있다. 차감액은 안내문마다 다르게 적혀 있다(1회 20만원 vs 횟수별 4·10·20만원) [확인 필요, 상충하는 근거 참고].
- 대리 수강·동시 접속·진도 조작은 부정 수급 문제로 이어질 수 있어 본인 인증·모니터링이 요구된다 [확인 필요: 모니터링 요건 고시] (P03).

## 서비스 유형별 차이

| 유형 | 진도 규칙 특징 |
|------|----------------|
| AT01 이러닝 마켓플레이스 | 느슨한 진도(자유 탐색), 진도율은 환불 기준과 수료증 조건에 쓰임 |
| AT02 기업교육 LMS | 법정·환급 과정은 엄격(배속·건너뛰기 제한, 일일 제한, 본인 인증), 관리자 리포트 |
| AT03 부트캠프 | 라이브 출석 + 과제 제출 중심, 출석률이 국비 지원 조건일 수 있음 [확인 필요] |
| AT04 라이브·튜터링 | 회차 출석, 노쇼 처리, 녹화 시청 |
| AT05 K-12 | 교사가 배정한 과제 완료율, 학급 단위 집계 ([[domain/교사참여설계]]) |
| AT07 소비자 앱 | 일일 목표·스트릭, 진도보다 재방문이 핵심 지표 |

## 에듀테크 PM 적용

- [ ] 진도 정의(시청 비율·학습 시간·항목 완료)를 하나로 정하고 L03·E12에 수식으로 썼다
- [ ] 건너뛰기·배속·비활성 처리 규칙을 정했다 (L03)
- [ ] 진도율이 환불 계산(P01), 수료증(L06), 정산(S07)에 쓰이는 지점을 표로 정리했다
- [ ] 환급·국비 과정이면 최신 고시·훈련기관 운영 기준 원문을 확인하고 출처를 L03에 남겼다
- [ ] 부정 수강 탐지 규칙을 P03과 연결했다
- [ ] 진도율을 학습 효과 지표로 쓰지 않도록 E07에 표시했다 ([[domain/학습분석지표]])

## 흔한 오해

- "진도율 100% = 학습 완료" — 재생 기록일 뿐이다. 학습 증거는 평가로 본다.
- "배속을 막으면 학습이 깊어진다" — 근거가 없다. 규정 준수가 필요한 과정에서만 제한한다 [가정].
- "원격훈련 기준은 한 번 정하면 끝" — 기준·차감 규정이 자주 바뀐다. `verified` 날짜를 지킨다.

## 상충하는 근거

- 내일배움카드 원격훈련 미수료 차감액: "1회 지원한도 20만원 차감"(https://www.kdedu.co.kr/main/page.jsp?pid=worker.worker04) vs "1회 4만원, 2회 10만원, 3회 이상 20만원"(타 기관 안내). 시점 차이로 보이며 고용24 최신 공고로 확인한다.
- 차시 진도 인정 기준: "차시 85% 이상" vs "인정 학습시간 50% 초과"(https://winspec.co.kr/support/notices/268 및 같은 기관의 이전 공지). 기관·시점별로 다르다.
