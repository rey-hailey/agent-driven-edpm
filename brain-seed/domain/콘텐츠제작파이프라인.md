# 콘텐츠 제작 파이프라인

## 핵심 요약

- 이러닝 과정 제작은 대체로 **기획 → 강사 섭외 → 원고·스토리보드 → 촬영·녹음 → 편집 → 자막 → 검수 → 인코딩·DRM·업로드 → 출시 → 개정** 순서로 흐른다.
- 일정과 비용은 제작 방식(스튜디오 촬영 vs 강사 자가 촬영 vs 화면 녹화), 분량, 편집 수준에 따라 크게 달라진다. 이 페이지는 공개 근거가 확인된 수치가 없어 **구체적 기간·단가를 적지 않는다**. 실제 값은 회사 워크스페이스에서 관리한다.
- 병목은 보통 **강사 원고 지연과 검수 반려**에서 생긴다 [가정].
- AI 보조(원고 초안, TTS·아바타, 자동 자막, 번역)는 시간을 줄이지만, 사실 오류·발음 오류·저작권·초상권 위험이 있어 **사람 검수 규칙**이 함께 있어야 한다.

## 상세

### 단계별 산출물과 체크 포인트

| 단계 | 산출물 | 체크 포인트 |
|------|--------|-------------|
| 1. 과정 기획 | 과정 기획서(대상, LO, 목차, 차시 수, 분량) | 학습 목표와 평가 먼저 ([[domain/역방향설계]]) |
| 2. 강사 섭외·계약 | 계약서, 일정 | 저작권 귀속·2차 이용·정산 조건 (P02, [[domain/강사정산모델]]) |
| 3. 원고·스토리보드 | 차시별 원고, 화면 구성안, 실습 자료 | 제3자 자료 사용 허락 ([[domain/교육저작권]]) |
| 4. 촬영·녹음 | 원본 영상·음성 | 스튜디오 예약, 리허설, 재촬영 기준 |
| 5. 편집 | 편집본, 자막 파일용 대본 | 템플릿(인트로·하단 자막), 화면 확대 |
| 6. 자막·접근성 | 자막(SRT·VTT), 대체 텍스트 | 청각장애 학습자 대응 ([[domain/접근성]]) |
| 7. 검수(QA) | 검수 체크리스트 결과 | 내용 정확성, 음질, 오탈자, 링크, 퀴즈 정답 |
| 8. 인코딩·DRM·업로드 | 해상도별 인코딩, DRM·워터마크 적용 | 유출 방지(P03), 재생 호환성 |
| 9. 출시 | 상세페이지, 미리보기 레슨, 가격 | 메타데이터 완성 ([[domain/학습콘텐츠구조]]) |
| 10. 개정 주기 | 오류 수정, 재촬영, 버전 업 | 오류 신고 SLA, 정기 점검(P04) |

### 제작 방식 비교

| 방식 | 장점 | 단점 |
|------|------|------|
| 스튜디오 촬영 | 품질 균일, 브랜드 통일 | 비용·일정 부담, 강사 이동 필요 |
| 강사 자가 촬영(가이드 제공) | 빠름, 규모 확장 쉬움 | 품질 편차, 재촬영 요청 많음 |
| 화면 녹화 중심(슬라이드·코드) | 저비용, 실습형에 적합 | 몰입도 낮을 수 있음 |
| 라이브 녹화 재가공 | 콘텐츠 재활용 | 편집 부담, 질의응답 맥락 손실 |

### 역할

기획 PM(과정 매니저), 교수설계자(ID), 강사(SME), 촬영·편집, 자막·번역, 검수자, 운영(업로드·상세페이지). 작은 조직은 한 사람이 여러 역할을 겸한다.

### 외주

- 외주 범위를 단계별로 쪼개 계약한다 (촬영만, 편집만, 일괄).
- 납품 기준(해상도, 파일 형식, 자막 정확도, 수정 횟수)과 원본 파일 귀속을 계약에 적는다 [가정].

### 일정·비용 산정 방법 (수치 없이)

- 최종 영상 1분당 원고·촬영·편집 시간 비율을 회사 실적으로 측정해 둔다 [가정].
- 비용 항목: 강사료(선지급 또는 수익 배분), 스튜디오, 편집 인건비, 자막·번역, 검수, 인코딩·저장·전송(CDN), DRM 라이선스.
- 공개 근거 없는 업계 평균 단가를 제안서·견적(S03)에 쓰지 않는다.

### AI 보조 제작과 검수 규칙

| AI 용도 | 위험 | 검수 규칙 |
|---------|------|-----------|
| 원고·퀴즈 초안 | 사실 오류, 출처 없는 주장 | 강사·SME가 전 문장 확인, 출처 표시 |
| TTS·AI 아바타 | 발음·용어 오류, 초상·음성권 | 용어 사전, 실존 인물 음성·외모는 서면 동의 [가정] |
| 자동 자막 | 전문 용어·고유명사 오인식 | 사람 교정 후 배포, 정확도 샘플 점검 |
| 자동 번역 | 맥락 오역 | 원어민 또는 해당 분야 검수 |
| 요약·하이라이트 클립 | 맥락 왜곡 | 강사 승인 |

- 생성형 AI 산출물의 저작권 귀속 문제는 [[domain/교육저작권]]의 AI 생성물 쟁점을 따른다.
- AI 사용 여부를 학습자에게 표시할지 정한다. 국내 AI 기본법의 생성형 AI 표시 의무가 교육 콘텐츠에 어떻게 적용되는지는 [확인 필요] ([[domain/아동개인정보보호]]의 AI 기본법 항목 참고).

## 서비스 유형별 차이

| 유형 | 차이 |
|------|------|
| AT01 이러닝 마켓플레이스 | 강사가 직접 제작. 플랫폼은 가이드·검수·품질 기준만 운영 |
| AT02 기업교육 LMS | 맞춤 제작(고객사 요구) + 기성 과정 라이선스. 환급 과정은 심사 일정이 제작 일정을 제약 [확인 필요] |
| AT03 부트캠프 | 라이브 수업이 중심, VOD는 사전 학습용. 실습 환경 제작 비중 큼 |
| AT05 K-12 | 교육과정 정렬·감수, 학기 시작 전 출시 마감 ([[domain/학사일정]]) |
| AT07 소비자 앱 | 짧은 인터랙티브 레슨 대량 제작, 템플릿·자동화 비중 큼 |

## 에듀테크 PM 적용

- [ ] 10단계별 담당·산출물·완료 기준을 L02에 표로 정했다
- [ ] 강사 계약에 저작권·2차 이용(클립·번역·AI 학습) 조항을 넣었다 (P02)
- [ ] 검수 체크리스트와 반려 기준을 P04에 정했다
- [ ] 자막 제공 범위와 정확도 기준을 정했다 (E13 접근성)
- [ ] AI 보조 산출물마다 사람 검수자를 지정했다 (L02, A07)
- [ ] 개정 주기와 오류 신고 처리 SLA를 정했다 (P04)
- [ ] 제작 원가 추정은 회사 실적 기반으로 S03에 반영했다

## 흔한 오해

- "촬영이 제일 오래 걸린다" — 원고 확정과 검수 반복이 더 길어지는 경우가 많다 [가정].
- "자동 자막이면 접근성 해결" — 교정하지 않은 자막은 오히려 오해를 만든다.
- "출시하면 끝" — 개정·오류 수정 비용을 처음부터 예산에 넣어야 한다.
