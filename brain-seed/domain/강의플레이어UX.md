# 강의 플레이어 UX (재생·진도·자막·오프라인)

## 핵심 요약

- 플레이어는 "영상 재생기"가 아니라 **진도·수료 규칙(L03)이 실행되는 곳**이다. 무엇을 진도로 셀지(재생 시간, 고유 시청 구간, 끝까지 도달, 퀴즈 통과)를 먼저 정하고 UI를 그린다.
- 학습자 편의(배속·건너뛰기·이어 보기)와 정책 요구(환급 과정의 건너뛰기 제한, 부정 수강 방지 P03)는 충돌한다. 충돌은 과정 유형별 설정으로 풀고, 제한이 있으면 이유를 화면에 알린다.
- 접근성 최소선: 녹화 영상 자막(WCAG 1.2.2, A), 오디오 해설 또는 대체 자료(1.2.3 A / 1.2.5 AA), 키보드 조작(2.1.1), 자동 재생 콘텐츠 정지 수단(2.2.2), 컨트롤의 이름·역할 제공(4.1.2) ([[domain/접근성]]).
- 오프라인 다운로드는 DRM·라이선스 만료·기기 수 제한과 함께 설계한다. "다운로드 가능"은 기술 결정이 아니라 콘텐츠 계약(P02) 결정이기도 하다.

## 상세

### 화면 구조 (PC 기준)

```text
학습 플레이어
├─ 상단: 과정명 > 섹션 > 레슨명, 닫기, 진도(이 과정 n%)
├─ 영상 영역
│  ├─ 컨트롤 바: 재생/일시정지, 10초 앞뒤, 탐색 바(챕터 마커), 시간
│  ├─ 배속, 자막(언어·스타일), 화질, PIP, 전체 화면
│  └─ 오버레이: 영상 내 퀴즈, 다음 레슨 카운트다운
├─ 우측 패널(탭): 목차 | 대본 | 노트·북마크 | 질문 | 자료
└─ 하단: 이전/다음 레슨, 완료 표시(규칙에 따라 자동 또는 수동)
```

모바일은 우측 패널을 영상 아래 탭으로 내리고, 가로 모드에서 전체 화면 전환.

### 컨트롤과 설계 포인트

| 기능 | 설계 포인트 |
|------|-------------|
| 배속 | 0.5~2배 단계. 과정 정책상 상한이 있으면 상한 표시와 사유 |
| 이어 보기 | 마지막 위치를 주기적으로 서버 저장, 다른 기기에서 "이어서 보기 / 처음부터" 선택 |
| 챕터 | 탐색 바 마커 + 목차 패널의 시간 링크. 강사가 CMS에서 입력 |
| 대본·자막 | 대본 클릭 시 해당 시각 이동, 현재 문장 강조, 대본 검색. 자막 크기·색·배경 조절 (MAUR 권고) |
| 노트·북마크 | 타임스탬프 자동 첨부, 노트 목록에서 해당 시각으로 이동, 내보내기 |
| 화질 | 자동(적응형 스트리밍) 기본, 수동 선택, 데이터 절약 모드 |
| PIP·백그라운드 오디오 | 브라우저 PIP API, 모바일 OS 정책에 따름. 백그라운드 재생 시 진도 인정 여부를 정책으로 정한다 |
| 다음 레슨 자동 재생 | 카운트다운 + 취소. 퀴즈·과제 레슨 앞에서는 멈춤. 아동용은 기본 끔 [가정] |
| 영상 내 퀴즈 | 일시정지 후 문항, 응답 후 재개. 오답 시 해당 구간 다시 보기 제안 ([[domain/인출연습]]) |
| 타임스탬프 질문 | 현재 시각 자동 첨부, 같은 구간의 기존 질문 먼저 보여 주기 |

### 진도·완료 트리거 (L03에서 확정)

| 방식 | 장점 | 위험 |
|------|------|------|
| 누적 재생 시간 ≥ n% | 단순 | 배속·반복 재생으로 왜곡 |
| 고유 시청 구간 ≥ n% | 실제 시청에 가까움 | 구현 복잡, 오프라인 동기화 필요 |
| 끝 지점 도달 | 단순 | 건너뛰기로 조작 가능 |
| 퀴즈 통과 | 학습 증거 | 퀴즈 품질 의존 |
| 수동 "완료" 버튼 | 자율성 | 증빙 약함 (환급·법정교육 부적합) |

### 건너뛰기 제한 (정책 요구 시)

- 처음 볼 때만 미시청 구간 탐색을 막고, 이미 본 구간은 자유 탐색 [가정].
- 제한 사실을 탐색 바(미시청 구간 음영)와 툴팁으로 알린다. 이유 없는 비활성화는 불만을 키운다.
- 일정 시간 무입력 시 "계속 보고 계신가요" 확인, 동시 재생 기기 수 제한은 P03 기준을 따른다.
- 제한 기능은 접근성 기능(대본 열람, 키보드 탐색)을 막지 않는다.

## 서비스 유형별 차이

| 유형 | 차이 |
|------|------|
| AT01 마켓플레이스 | 자유 탐색·배속·다운로드가 기본 기대. 미리보기 레슨 |
| AT02 기업교육·환급 과정 | 건너뛰기 제한, 본인 확인, 진도 증빙, 동시 접속 제한 (L03·P03) |
| AT03 부트캠프 | 영상 + 실습 분할 화면, 코드 복사 ([[domain/코딩실습IDE]]) |
| AT05·AT06 K-12·학원 | 짧은 영상 + 즉시 문제. 자동 재생 끔, 교사가 배정한 영상만 노출 |
| AT07 소비자 학습앱 | 짧은 세션, 세로 영상, 오디오 전용 모드 |
| AT09 시험대비 | 해설 강의를 문항과 연결, 구간 반복 |

## 상태·예외

| 상황 | 처리 |
|------|------|
| 로딩·버퍼링 | 스피너 + 화질 자동 하향 제안. 진도 타이머는 버퍼링 중 정지 |
| 재생 오류 | "영상을 재생하지 못했어요" + 다시 시도 + 오류 신고(레슨 ID 자동 첨부) |
| 오프라인 | 다운로드한 레슨만 재생, 진도는 로컬 저장 후 연결 시 동기화. 충돌 시 큰 값 우선 [가정] |
| 다운로드 만료 | DRM 라이선스 만료 시 "온라인으로 다시 확인해 주세요" |
| 권한 없음 | 미구매·미배정 레슨은 잠금 화면 + 미리보기 여부 + 구매·승인 요청 |
| 수강 기간 만료 | 재생 차단, 노트·대본 열람 허용 여부는 정책 결정, 연장 CTA |
| 순차 잠금 | "이전 레슨을 먼저 완료해 주세요" + 이전 레슨 바로가기 |
| 동시 재생 초과 | 다른 기기 재생 중 안내, 이 기기에서 계속 선택 (P03) |
| 자막 없음 | 자막 버튼 비활성 대신 "자막 준비 중" 표시 |

## 에듀테크 PM 적용

- [ ] 진도·완료 트리거를 L03에 정의하고 플레이어 이벤트(재생, 일시정지, 탐색, 배속, 종료)를 E12 이벤트 명세에 연결했는가
- [ ] 건너뛰기·배속 제한이 과정 유형별 설정인가, 제한 사유를 화면에 알리는가 (P03)
- [ ] 자막·대본·키보드 조작·자막 스타일 조절이 P0 요구인가 (E13 (c))
- [ ] 오프라인 다운로드 가능 여부가 콘텐츠 계약(P02)·DRM 정책과 일치하는가
- [ ] 수강 기간 만료·순차 잠금·동시 재생 초과 화면이 E10 3절 상태표에 있는가
- [ ] 와이어프레임: PC 플레이어, 모바일 세로·가로, 영상 내 퀴즈 오버레이를 `sb-lowfi-pptx`로

## 흔한 오해

- "재생 시간 = 학습 시간" — 틀어 놓기·배속으로 왜곡된다 ([[domain/학습분석지표]]).
- "건너뛰기를 막으면 부정이 사라진다" — 탭 방치로 우회된다. 퀴즈·본인 확인과 조합해야 한다.
- "자막은 청각장애 학습자용" — 소음 환경, 비원어민, 복습 검색에도 쓰인다.
