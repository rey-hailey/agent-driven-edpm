# 교사 대시보드 IA (K-12·학원)

## 핵심 요약

- 교사 대시보드의 목적은 **수업 중·수업 전후 몇 분 안에 다음 행동을 정하게 하는 것**이다. 데이터를 많이 보여주는 화면이 아니라, "누구를, 무엇을, 지금" 돕는지를 보여주는 화면이다 [가정].
- 강사 대시보드(이러닝 강사)와 다른 점: 판매·정산이 없고, 반·학급 단위 운영, 성취기준 기반 진단, 보호자 소통, 학교·학원 관리자 권한이 핵심이다.
- 교사 업무를 늘리면 쓰지 않는다. 기본 화면은 한 화면, 조작 1분 이내를 목표로 둔다 ([[domain/교사참여설계]]).

## 상세

```mermaid
graph TD
    H[오늘] --> H1[오늘 수업할 반·차시]
    H --> H2[도움이 필요한 학생 (근거 표시)]
    H --> H3[반 전체가 막힌 문항·성취기준]
    C[반 관리] --> C1[학생 명단·초대 코드]
    C --> C2[과제 배정·마감]
    C --> C3[수준별 그룹]
    R[리포트] --> R1[성취기준별 숙달]
    R --> R2[학생별 학습 기록]
    R --> R3[보호자 공유용 요약]
    L[수업 도구] --> L1[수업 모드 (화면 공유·실시간 응답)]
    L --> L2[문항·자료 고르기]
    L --> L3[AI 생성 자료 검토·승인]
    S[설정] --> S1[보호자 알림 범위]
    S --> S2[AI 기능 켜기·끄기]
```

| 화면 | 목적 | 핵심 요소 | 연결 산출물 |
|------|------|-----------|-------------|
| 오늘 | 수업 전 1분 준비 | 반별 미완료 과제 수, 도움 필요 학생 3명(이유: 연속 오답, 미접속), 반 공통 막힘 Top 3 | E08 교사 개입 지점, E07 M-3x |
| 반 관리 | 학생·과제 운영 | 초대 코드, 명단, 과제 배정(대상·마감·재응시), 수준별 그룹 | E09, L04 |
| 성취기준 리포트 | 진단과 다음 수업 계획 | 성취기준·영역별 숙달 분포, 공식 선수 성취기준 연결 | E11 매핑, 교육과정 KG |
| 학생 상세 | 개별 지도·상담 | 학습 기록 타임라인, 오답 유형, 최근 활동, 메모 (교사만) | E12, E13 |
| 보호자 공유 | 상담·가정통신 | 요약 리포트(교사가 확인 후 발송), 공유 범위 설정 | E13, P05 |
| 수업 모드 | 교실에서 실시간 활용 | 학생 응답 모아보기, 익명 표시, 정답 공개 시점 제어 | E08, L04 |
| AI 자료 검토 | 생성물 승인 | 생성된 워크시트·피드백 초안, 수정·승인·폐기 | A05, E14 |

## 서비스 유형별 차이

| 유형 | 차이 |

| AT10 AI 튜터 | AI 대화 요약, 위기 신호 알림, AI 사용 범위 설정 |
| AT03 부트캠프 | 교사 대신 멘토·TA: 과제 채점 대기열, 출석, 프로젝트 진행 |

## 상태·예외

| 상태 | 처리 |
|------|------|
| 학생 데이터 부족 (가입 직후, 활동 3건 미만) | 숙달 판정·추천 숨김, "자료가 더 필요합니다" 표시 |
| 전학·반 이동 | 이전 반 기록은 원래 교사에게서 숨기고, 새 교사에게는 정책(E12 보존)에 따라 이관 |
| 학기 종료 | 반 보관 처리, 다음 학기 반 생성 안내, 데이터 보존·파기 일정 표시 |
| 보호자 동의 없음 (만 14세 미만) | 해당 학생 데이터 수집 기능 제한 표시, 동의 요청 안내 (E13) |
| 공용 기기·교실 PC | 교사 화면 자동 잠금, 학생 이름 가리기 옵션 |
| AI 기능 꺼짐 | 관련 위젯 숨김, 대체 기능 안내 |

## 에듀테크 PM 적용

- [ ] "오늘" 화면이 교사의 다음 행동 3가지 이내를 보여주는가 (E08 교사 개입 지점과 일치)
- [ ] 도움 필요 학생 표시에 근거(연속 오답, 미접속 기간)가 함께 나오는가 — 낙인처럼 보이지 않게 표현
- [ ] 성취기준 리포트가 매핑 파일(E11)과 같은 코드를 쓰는가
- [ ] 교사는 자기 반 학생만 보는가, 관리자 권한 범위가 명확한가 (E09·B02 권한 표)
- [ ] 보호자 공유는 교사가 확인 후 발송하는가
- [ ] AI 생성물은 승인 전 학생에게 노출되지 않는가 (A05)
- [ ] 와이어프레임 우선 화면 (PC 시나리오): 오늘, 성취기준 리포트, 과제 배정, 학생 상세, AI 자료 검토 → `sb-lowfi-pptx`

## 흔한 오해

- "데이터가 많을수록 교사가 좋아한다" → 수업 준비 시간은 짧다. 행동으로 이어지는 몇 가지만 남긴다.
- "학생 순위를 보여주면 동기가 오른다" → 반 안 비교는 낙인과 불안을 만들 수 있다. 개인 성장 중심으로 ([[domain/동기설계]]).
- "AI가 진단했으니 맞다" → 진단 근거와 데이터 양을 함께 보여주고 교사 판단을 우선한다.
