# AI 비용 관리 정책

> 원가 계산과 과금 설계는 A12가 맡는다. 이 페이지는 **운영 중 비용이 새지 않게 하는 정책**(예산, 한도, 알림, 하향 규칙, 승인)을 다룬다. 업체 단가는 자주 바뀌므로 이 페이지에 숫자를 두지 않는다.

## 핵심 요약

- AI 비용은 **사용량에 비례해 늘어나는 변동비**다. 무제한 요금제, 학기초 사용 폭증, 반복 재생성, 긴 대화 맥락이 마진을 무너뜨리는 대표 경로다 [가정: 실무 관찰].
- 정책의 뼈대: (1) 조직·기능·월 단위 예산, (2) 사용자·기관 한도, (3) 단계별 알림, (4) 예산 압박 시 모델 하향 규칙, (5) 고비용 기능 승인 절차, (6) 비용 귀속(누가 썼나), (7) 마진 가드레일.
- 비용 절감은 방식 선택이 가장 크다. 정답이 정해진 일은 규칙·검색으로 처리하고, 쉬운 요청은 작은 모델·FAQ로 보낸다 (가이드 10, A11 라우팅).
- 비용 압박이 **안전·품질 조치를 줄이는 방향으로 가지 않게** 한다. 위기 탐지·가드레일 호출은 예산 하향 대상에서 제외한다.

## 상세

### 예산과 알림

| 단위 | 예산 예 | 알림 단계 [가정] |
|------|---------|------------------|
| 전사 월 | AI 총비용 | 50%·80%·100% 도달, 일일 급증 |
| 기능별 | 튜터, 문항 생성, 자막 | 기능 담당 PM에게 |
| 고객 기관별 | 학교·학원·기업 계약 | 계약 포함량 대비 |
| 실험·개발 | 평가 실행, 프롬프트 실험 | 실험별 상한 |

- 일 단위 이상 탐지(전주 같은 요일 대비 급증)를 둔다. 반복 호출 버그, 자동화 남용, 프롬프트 길이 회귀가 원인인 경우가 많다 [가정].

### 사용자·기관 한도

| 대상 | 한도 방식 | 메모 |
|------|-----------|------|
| 학습자 | 일·월 요청 수 또는 크레딧 | 요금제 포함량과 연결 (A12) |
| 교사 | 자료 생성 횟수 | 수업 준비 피크(일요일 밤 등) 고려 [가정] |
| 기관 | 계약 포함량, 초과 시 정책(차단·과금·하향) | 계약서에 명시 |
| API 키 | 연동 파트너별 상한 | [[domain/RateLimiting정책]] |

### 비용 귀속

- 모든 AI 호출에 기관 ID, 기능 ID, 모델, 입력·출력 토큰(또는 GPU 시간), 캐시 적중 여부를 기록한다 (A13 로그).
- 기관별·기능별 원가를 월 단위로 보고, 계약 단가와 비교한 **기관별 공헌이익**을 본다 ([[domain/에듀테크수익모델]]).

### 모델 하향 규칙

| 상황 | 하향 동작 | 제외 |
|------|-----------|------|
| 기능 예산 80% | 쉬운 요청을 소형 모델로 | 평가·위기 탐지 |
| 기능 예산 100% | 캐시·FAQ 우선, 신규 생성 제한 | 핵심 학습 흐름 |
| 기관 포함량 소진 | 계약 정책대로 (안내 후 하향 또는 추가 구매) | 안전 기능 |

- 하향 모델도 같은 평가세트 합격선을 넘은 것만 쓴다 (A06). 하향 사실은 사용자에게 품질 차이가 클 때 안내한다.

### 캐싱·배치

- **응답 캐시**: 같은 문항 해설, FAQ성 질문, 공통 자료는 생성 결과를 재사용. 학습자 개인 정보가 섞인 응답은 캐시 금지.
- **프롬프트 캐시**: 긴 시스템 프롬프트·근거 문서를 업체 캐시 기능으로 재사용 [확인 필요: 업체별 지원·과금].
- **배치 처리**: 문항 대량 생성, 자막, 야간 리포트는 실시간이 아닌 배치로 [확인 필요: 업체별 배치 할인].
- **사전 생성**: 해설·힌트를 미리 만들어 검수 후 저장하면 비용과 환각을 같이 줄인다 ([[domain/할루시네이션대응]]).

### 고비용 기능 승인

- 출시 전 A12 원가 추정(요청당·학습자당·월)과 가격 반영 여부를 확인하고, 학습자당 월 원가가 기준을 넘으면 검토 위원회 승인 [가정: 기준은 회사별].
- 이미지·음성·영상 생성, 긴 맥락 대화, 에이전트형 다단계 호출은 기본적으로 승인 대상.

### 대시보드

| 지표 | 용도 |
|------|------|
| 일·월 총비용, 예산 대비 | 재무 |
| 기능별·기관별 원가 | 마진 관리 |
| 요청당 평균·p95 토큰 | 프롬프트 회귀 탐지 |
| 캐시 적중률 | 절감 효과 |
| 모델별 호출 비중 | 라우팅 점검 |
| 학습자당 월 원가 분포 | 과사용자 탐지 |

### 마진 가드레일

- 요금제별 "학습자당 AI 원가 / 학습자당 매출" 상한을 정하고 넘으면 포함량·라우팅·가격을 재검토한다 (A12, S06).
- 과사용 상위 구간이 원가 대부분을 차지하는지 분포를 본다. 무제한 표현은 공정 사용 기준과 함께 쓴다.

## 에듀테크 맥락

- **미성년**: 아동은 재생성 버튼을 반복해 누르는 경향이 있을 수 있다 [가정]. 재생성 제한과 대기 안내를 둔다.
- **학생 평가**: 시험 기간 채점·피드백 비용 급증을 예산에 미리 반영한다. 평가 기능은 하향 대상에서 제외하거나 별도 예산.
- **고객 요구**: 교육청·학교는 연간 고정 예산이므로 초과 과금보다 포함량 내 운영을 선호하는 경우가 많고, 기업은 부서별 비용 배분 리포트를 요구한다 [가정].

## 방식별 차이

| 방식 | 비용 구조 |
|------|-----------|
| 규칙·NLP | 거의 고정비 |
| RAG | 검색·임베딩·색인 저장 + 생성 토큰. 근거 문서가 길수록 입력 토큰 증가 |
| 로컬 LLM | GPU·운영 인력 고정비. 사용량이 많을수록 유리, 적으면 불리 |
| 클라우드 LLM | 토큰당 변동비. 캐싱·라우팅 효과 큼 |

## 에듀테크 PM 적용

- [ ] 예산 단위와 알림 단계를 P09에 정한다
- [ ] 사용자·교사·기관·API 키 한도를 정하고 요금제와 연결한다 (A12, P09)
- [ ] 호출 로그에 비용 귀속 필드를 넣는다 (A13)
- [ ] 모델 하향 규칙과 제외 대상(안전·평가)을 A11·P09에 적는다
- [ ] 캐시 허용·금지 기준을 정한다 (개인 정보 포함 응답 금지)
- [ ] 고비용 기능 승인 기준을 정한다 (A12)
- [ ] 비용 대시보드와 월간 마진 검토를 운영 일정에 넣는다 (A13, S06)

**관련 산출물**: A12(주: 원가·과금), P09(주: 운영 정책), A11, A13, A14·P08(안전 호출은 하향 제외), P07(하향·한도 고지), E13(비용 로그의 개인정보 최소화), S06, S03.

## 흔한 오해

- "로컬 모델은 공짜" — GPU·인력·갱신 비용이 있다 (가이드 10).
- "단가가 계속 내려가니 걱정 없다" — 사용량·맥락 길이·기능 수가 더 빨리 늘 수 있다.
- "비용이 오르면 가드레일 호출부터 줄인다" — 안전 사고 비용이 훨씬 크다.
