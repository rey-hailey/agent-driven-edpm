# 학원 프랜차이즈 운영 (본부 학습관리 시스템)

> 본부가 커리큘럼·교재·학습관리 시스템을 공급하고 가맹 학원이 수업하는 **매쓰홀릭형** 범주를 다룬다. 이름은 형태 설명용이며, 특정 회사의 계약·수치·기능을 주장하지 않는다. 이 페이지는 법률 자문이 아니다.

## 핵심 요약

- 구조는 **본부(가맹본부) – 가맹 학원(가맹점사업자) – 강사 – 학생·학부모**의 4층이다. PM이 만드는 시스템의 1차 고객은 원장, 매일 쓰는 사용자는 강사, 결과를 보는 사람은 학부모다.
- 가맹본부는 가맹희망자에게 등록된 **정보공개서**와 인근가맹점 현황문서를 준 날부터 **14일**(변호사·가맹거래사 자문을 받으면 7일)이 지나기 전에는 가맹금을 받거나 계약을 맺을 수 없다 (가맹사업법 제7조, 조문 인용 출처 https://www.lawtalk.co.kr/posts/177406). [확인 필요: law.go.kr 현행 조문 대조]
- 정보공개서 등록 여부는 공정거래위원회 가맹사업거래 홈페이지(https://franchise.ftc.go.kr)에서 확인한다. 가맹금 예치 제도(예치기관 또는 피해보상보험)가 있다 (https://www.sidae.com/article/2014040409238018125). [확인 필요: 현행 예치 기간·대상]
- 학원은 30일 이상 교습과정으로 일정 수(시행령상 동시 10명) 이상에게 교습하는 시설이며, 시설·설비를 갖춰 **교육감에게 등록**해야 한다 (학원법 제2조·제6조, https://www.nepla.ai/law/학원의설립·운영및과외교습에관한법률). 등록 주체는 가맹 학원 각각이다. [verified 2026-10-12: 2차 법령 사이트, 원문 대조 권장]
- 학생 데이터: 학생·학부모와 계약하는 쪽은 보통 가맹 학원이므로 학원이 개인정보처리자이고, 본부의 학습관리 시스템은 **수탁자**가 되는 구조가 일반적이다. 위탁은 법정 사항을 담은 문서로 하고 수탁자를 공개해야 한다 (개인정보 보호법 제26조, https://itwiki.kr/w/개인정보_보호법_제26조). 본부가 데이터를 자기 목적(브랜드 통계·마케팅)으로 쓰면 위탁 범위를 넘으므로 별도 근거가 필요하다 [확인 필요: 법무 검토].

## 상세

### 본부와 가맹 학원의 역할

| 영역 | 본부 | 가맹 학원 |
|------|------|-----------|
| 커리큘럼·교재 | 개발, 개정, 공급 | 반 편성, 진도 운영 |
| 강사 | 연수·인증, 수업 매뉴얼 | 채용, 근태, 급여 |
| 시스템 | LMS·원장 관리자·학부모 앱 개발·운영 | 사용, 원생 데이터 입력 |
| 마케팅 | 브랜드, 전국 캠페인 | 지역 홍보, 설명회 |
| 학원법 | 지원·교육 | 등록, 교습비 게시·반환, 강사 신고 |
| 수익 | 가맹비·교육비·로열티·교재비 [가정: 계약별] | 교습비 |

### 콘텐츠 공급과 강사 연수

- 교재·문항·진단 평가를 본부가 공급하고 개정 주기를 정한다 ([[domain/2022개정교육과정적용일정]]).
- 강사 연수: 신규 강사 온보딩, 교재 개정 연수, 수업 관찰 피드백. 연수 이수를 시스템에서 관리하면 품질 관리 지표가 된다 ([[domain/교사참여설계]]).
- 교재 저작권은 본부 소유, 가맹 학원은 계약 범위 내 이용 ([[domain/강사계약과콘텐츠권리]]).

### 가맹 학원용 LMS·관리자

- 원장 화면: 원생 현황(재원·신규·퇴원), 반 편성, 수납, 강사 배정, 상담 기록, 본부 공지·교재 주문.
- 강사 화면: 오늘 수업, 출결, 과제·테스트 채점, 학생별 진도·취약 단원 ([[domain/교사대시보드IA]]).
- 본부 화면: 가맹점별 KPI, 연수 이수, 교재 주문, 지원 티켓. **원생 개인 단위 열람은 위탁 범위와 계약에 맞춰 제한**한다.
- 권한 모델: 본부 관리자 / 지역 관리자 / 원장 / 강사 / 학부모 / 학생의 6역할과 학원 단위 데이터 격리.

### 학부모 리포트

- 주기(주간·월간), 내용(출결, 진도, 테스트 결과, 강사 코멘트), 채널(앱 푸시·알림톡).
- 강사 코멘트 작성 부담이 크므로 템플릿·AI 초안 + 강사 승인 흐름을 둔다 ([[domain/AI적용기회맵]]).
- 리포트의 비교 표현(반 평균 대비)은 낙인·과열 위험을 검토한다.

## 핵심 비즈니스 로직

- 본부 수익원은 계약마다 다르며(가맹비, 교육비, 정액·정률 로열티, 교재 판매, 시스템 사용료) 정보공개서에 기재된다 [가정: 공개 정보공개서로 확인 가능].
- 가맹 학원 손익: 교습비 수입 − 임대료·강사 인건비·로열티·교재비. 원생 수와 재원 기간이 핵심 변수다.
- 교습비 반환은 학원법 시행령 별표 4 기준을 따른다 ([[domain/환불정책]]).

## 주요 화면·기능

- 원장 대시보드, 원생·반 관리, 수납·미납, 상담 기록, 강사 앱(출결·채점), 학부모 앱(리포트·공지·수납), 본부 콘솔(가맹점 KPI·공지·연수·교재 주문).

## 지표

| 구분 | 지표 [가정: 업계 일반 용어, 정의는 회사별 확정] |
|------|------|
| 원생 | 재원생 수, 신규 등록, 퇴원율, **재원율**(기간 초 원생 중 기간 말 재원 비율), 평균 재원 기간 |
| 영업 | 상담→등록 전환율, 설명회 참석→등록 |
| 학습 | 진단 평가 성취 변화, 과제 완료율 |
| 가맹점 | 가맹점 수, 신규 개원·폐원, 점당 원생 수, 연수 이수율 |
| 시스템 | 강사 주간 활성, 리포트 발송률, 학부모 앱 열람률 |

## 규제·리스크

- 가맹사업법: 정보공개서 등록·제공, 14일 숙고 기간, 가맹금 예치, 불공정거래 금지. 시스템 사용료·교재 구입 강제 조항은 법무 검토 대상이다 [확인 필요].
- 학원법: 등록, 교습비 게시·반환, 강사 관련 의무는 가맹 학원 단위. 본부 시스템이 교습비 게시·반환 계산을 지원하면 법정 기준과 맞는지 검증한다.
- 개인정보: 위탁 계약서, 수탁자 공개, 본부 열람 범위, 가맹 해지 시 데이터 반환·파기 ([[domain/아동개인정보보호]] 만 14세 미만 동의).
- 가맹 해지·브랜드 전환 시 원생 기록 이관 요구가 생긴다. 계약에 데이터 반환 형식을 적어 둔다.

## 에듀테크 PM 적용

**체크리스트**

- [ ] 본부·학원·강사·학부모 역할별 권한과 데이터 격리를 정한다 (E09, E12)
- [ ] 개인정보 처리 주체(학원)와 수탁자(본부·시스템 사업자) 관계를 E13에 적는다
- [ ] 본부의 원생 데이터 열람·통계 활용 범위를 법무와 확인한다 (E13)
- [ ] 재원율·퇴원율 정의를 SQL로 고정한다 (E07)
- [ ] 학부모 리포트 템플릿과 강사 승인 흐름을 정한다 (E10, A05)
- [ ] 교습비 반환 계산을 학원법 기준으로 검증한다 (P01)
- [ ] 가맹 해지 시 데이터 반환·파기 절차를 정한다 (P05)

**관련 산출물·유형**: AT06. E07, E09, E10, E12, E13, P01, P05, S04, S06, L04, A05, F00~F04(원장용 학부모 리포트 개선), N01~N03(온라인 관리형 신규 브랜드).

## 흔한 오해

- "본부 시스템에 있으니 원생 데이터는 본부 것" — 계약 주체와 위탁 구조에 따라 다르다.
- "학원 등록은 본부가 한 번 하면 된다" — 등록은 학원 시설 단위다.
- "가맹 상담 당일 계약해도 된다" — 정보공개서 제공 후 숙고 기간이 있다.
