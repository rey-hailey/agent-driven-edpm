# AI 저작권 정책

> **법률 자문이 아니다.** 교육 목적 이용(저작권법 제25조)은 [[domain/교육저작권]], 강사 콘텐츠의 AI 이용 동의는 [[domain/강사계약과콘텐츠권리]]에 있다. 이 페이지는 학습 데이터, RAG, AI 생성물의 권리와 표시를 다룬다.

## 핵심 요약

- 한국 저작권법은 저작물을 "인간의 사상 또는 감정을 표현한 창작물"로 정의한다 (제2조 제1호, https://casenote.kr/법령/저작권법/제2조). [verified 2026-10-12]
- 문화체육관광부는 2023.12.27. **생성형 AI 저작권 안내서**를 발표했다. AI 사업자·권리자·이용자 유의사항과 산출물 등록 안내로 구성되고, 인간의 창작적 개입이 없는 AI 산출물은 등록할 수 없다는 입장이다 (경향신문 https://www.khan.co.kr/article/202312271731001). [verified 2026-10-12: 보도 기준]
- 2025.6. 문체부·한국저작권위원회는 **「생성형 AI 활용 저작물의 저작권 등록 안내서」**와 **「생성형 인공지능 결과물에 의한 저작권 분쟁 예방 안내서」**를 냈다. 등록 요건은 인간의 창작적 기여이고, 효력은 인간 기여 부분에만 미치며, 신청 시 AI 산출물과 인간 창작 부분을 구분해 적어야 한다 (한국콘텐츠진흥원 https://www.kocca.kr/trendott/vol04/trend_1.html ; 헤럴드 https://www.heraldk.com/article/2025110215591135596). [verified 2026-10-12: 2차 자료 기준] 6월 정확한 발표일은 [확인 필요].
- 2026.2.26. 문체부·한국저작권위원회는 **「생성형 AI 저작물 학습 공정이용 안내서」**를 발간해 학습의 공정이용 판단 4요소(이용 목적·성격, 저작물 종류·용도, 이용 비중, 시장 영향)를 제시했다 (아시아경제 https://view.asiae.co.kr/article/2026022609294663830). [verified 2026-10-12: 보도 기준] 법적 구속력은 없는 안내서로 보는 것이 일반적이나 원문 [확인 필요].
- 미국 저작권청은 AI 보고서 Part 2(저작물성, 2025.1.29.)에서 충분한 인간의 표현적 기여가 있을 때만 보호되며 **프롬프트만으로는 부족**하다고 보았다. Part 3(학습)은 2025.5.9. 사전 공개본만 있고 최종본은 미발간 상태다 (https://copyright.gov/ai/). [verified 2026-10-12] 미 연방항소법원(D.C. Cir.)은 2025.3.18. Thaler v. Perlmutter에서 인간 저작자 요건을 확인했다 (https://ipwatchdog.com/2025/03/24/d-c-circuit-upholds-human-authorship-requirement-thaler-v-perlmutter/). [verified 2026-10-12]

## 상세

### 쟁점별 정리

| 쟁점 | 현재 정리 | 에듀테크 판단 |
|------|-----------|---------------|
| 학습 데이터 | 한국은 2026 공정이용 안내서의 4요소 종합 판단, 미국은 Part 3 사전 공개본에서 논의 | 자체 모델 학습·미세조정 데이터의 출처·권리 원장 필수 |
| RAG 근거 문서 | 검색·인용을 위한 복제·저장이 일어남 | 교과서·참고서·지문은 라이선스 범위(AI 이용, 매체, 기간) 확인 |
| 생성물 저작물성 | 인간 창작 기여 부분만 보호 (한·미 같은 방향) | AI 생성 문항·해설은 독점 권리 주장이 약할 수 있음. 사람 편집 기록 보존 |
| 출력 유사성 | 기존 저작물과 동일·유사한 출력은 침해 위험 (2023 안내서가 사업자에 유사 출력 방지 노력 요구로 보도) | 기존 문항·지문과 유사도 검사 |
| 표시 | AI 기본법 제31조 ② 생성물 표시 | 저작권과 별개의 의무 |

### RAG와 교과서·참고서

- 교과서는 교과서 발행사 권리와 지문 원저작자 권리가 겹친다. 제25조의 교과용도서 관련 허용은 발행자의 본래 목적 범위에 한정되므로 제3자의 AI 서비스 근거가 되기 어렵다 ([[domain/교육저작권]]) [확인 필요: 개별 사안].
- 라이선스 계약에 넣을 항목: AI 검색 색인 허용, 생성 답변 내 인용 분량, 출력물 저장·공유 허용 범위, 계약 종료 시 색인 삭제, 모델 학습 금지 또는 허용 [가정: 계약 실무].
- 교사가 업로드한 자료를 학급 RAG에 쓰는 것과 전체 서비스 학습에 쓰는 것은 다른 이용이다. 기본값은 해당 학급 범위.

### 강사·교사 콘텐츠의 AI 이용

- 강사 계약에서 (a) RAG 근거, (b) 자체 미세조정, (c) 외부 제공을 나눠 동의를 받는다 ([[domain/강사계약과콘텐츠권리]]).
- 음성 복제·AI 강사 영상은 저작권 외에 음성·초상 문제가 있고, AI 기본법 제31조 ③의 가상 콘텐츠 고지 대상이 될 수 있다.

### 표절·유사성 위험 관리

| 위험 | 통제 |
|------|------|
| 생성 지문이 기존 지문을 재현 | n-gram·임베딩 유사도 검사, 임계값 초과 시 폐기 |
| 기출·타사 문항과 유사 | 문항 은행 대조 ([[domain/문항자동생성]]) |
| 학생이 AI 생성물을 과제로 제출 | 학업 윤리 정책, AI 탐지기 단독 판정 금지 ([[domain/과제와평가설계]]) |

## 에듀테크 맥락

- **미성년**: 학생 창작물(글, 그림)은 학생이 저작자다. 학생 작품을 모델 학습에 쓰려면 저작권과 개인정보(보호자 동의) 양쪽을 본다.
- **학생 평가**: AI 생성 문항으로 시험을 치르면 유사 문항 유출·저작권 분쟁이 시험 신뢰도 문제로 번진다.
- **고객 요구**: 출판사·교육청은 AI 학습 금지 조항을, 기업은 산출물 권리 귀속과 면책(배상) 조항을 요구하는 경우가 많다 [가정].

## 방식별 차이

| 방식 | 저작권 특성 |
|------|-------------|
| 규칙·NLP | 템플릿 자체는 자체 저작물. 사전·말뭉치 라이선스 확인 |
| RAG | 근거 문서 라이선스가 핵심. 인용 분량 통제 |
| 로컬 LLM | 오픈 모델 가중치 라이선스(상업 이용·사용자 수 제한) 확인 [확인 필요: 모델별] |
| 클라우드 LLM | 업체 약관의 산출물 권리·면책 조항 확인 [확인 필요: 업체별] |

## 에듀테크 PM 적용

- [ ] AI가 쓰는 모든 데이터(학습·RAG·예시)의 권리 원장을 만든다 (A14, E11)
- [ ] 교과서·참고서 라이선스에 AI 이용 조항을 넣는다 (P02, P07)
- [ ] AI 생성 콘텐츠에 사람 편집 기록(누가·무엇을 고쳤는지)을 남긴다 (A13)
- [ ] 생성물 유사도 검사와 임계값을 정한다 (A14)
- [ ] 생성물 표시 방식(라벨·메타데이터)을 정한다 (P07)
- [ ] 오픈 모델·업체 약관의 산출물 권리·면책 조항을 E13·P07에 기록한다
- [ ] 국내 안내서 3종과 미국 저작권청 보고서 상태를 180일마다 재확인한다

**관련 산출물**: P07(주), P02, A14, A13, P08(유사 출력 신고 처리), A12(라이선스 비용), A08, E11, E13.

## 흔한 오해

- "AI가 만든 건 우리 회사 저작물" — 인간 창작 기여가 없으면 보호가 약하다. 계약상 권리와 저작권은 다르다.
- "공정이용 안내서가 나왔으니 학습은 합법" — 4요소 종합 판단이며 개별 사안마다 결론이 다르다.
- "RAG는 학습이 아니니 라이선스 불필요" — 색인 저장·출력 인용 자체가 이용이다.
