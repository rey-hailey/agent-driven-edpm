# 레벨드 리딩과 영어 독서 서비스

> 유아·초등 대상 영어 원서·리더스 읽기 프로그램(**리딩게이트·리딩앤형** 범주)을 다룬다. 이름은 형태 설명용이며, 특정 회사의 내부 구조·수치·기능을 주장하지 않는다.

## 핵심 요약

- 서비스의 중심은 **레벨 체계 + 레벨 테스트 + 레벨별 도서관 + 이해 확인 + 독서 기록**이다. 레벨 체계는 외부 지표(Lexile, ATOS, F&P)와 자체 레벨을 함께 쓰는 경우가 많다.
- **Lexile**: 독자 측정치와 텍스트 측정치를 같은 척도에 두며, 0L 미만(BR, Beginning Reader)부터 1600L 이상까지 범위를 가진다. 측정치가 같으면 약 75% 이해를 기대하고, 성장 권장 범위는 독자 측정치보다 100L 낮은 곳부터 50L 높은 곳까지다 (https://metametricsinc.com/wp-content/uploads/2020/08/Lexile-Measures-Overview.pdf). [verified 2026-10-12]
- **ATOS**: Renaissance의 가독성 공식으로 Accelerated Reader의 책 레벨을 정한다. 책 전체 텍스트를 스캔해 문장 길이·단어 길이·어휘 난이도를 반영하고, 결과는 학년 척도로 표시한다. 내용 적합성은 별도의 Interest Level(LG·MG·MG+·UG)이 맡는다 (https://www.arbookfind.com/popups/advsearch_helppopup.aspx). [verified 2026-10-12]
- **F&P(Guided Reading) 레벨**: A~Z(+) 문자 단계로, 소그룹 수업에서 교재를 고르는 교사용 도구다. 저자들은 레벨을 아동에게 붙이는 표지나 성적표에 쓰지 말라고 했다 (https://www.schoollibraryjournal.com/story/fountas-pinnell-say-librarians-guide-readers-interest-not-level). [verified 2026-10-12]
- 지표 간 환산표(Lexile↔AR↔F&P↔CEFR)는 공식 기관이 정한 1:1 대응이 아니다. 제3자 환산표는 참고만 하고 [확인 필요]로 둔다.

## 상세

### 레벨 체계 비교

| 체계 | 운영 주체 | 측정 대상 | 표기 | 주의 |
|------|-----------|-----------|------|------|
| Lexile | MetaMetrics | 독자·텍스트 (같은 척도) | 예: 650L, BR100L | 텍스트 측정치는 내용 성숙도를 반영하지 않음 |
| ATOS | Renaissance | 텍스트 난이도 | 학년 척도 예: 3.5 | 책 레벨 ≠ 학년, Interest Level과 함께 |
| F&P | Fountas & Pinnell (Heinemann) | 텍스트 (교사 판단 포함) | A~Z | 아동 표지 사용 반대 |
| CEFR | Council of Europe | 언어 사용 능력 전반 | Pre-A1, A1~C2 | 읽기 텍스트 난이도 척도가 아님 |

- CEFR과 리딩 레벨의 대응은 시험·출판사마다 다르게 제시한다 [확인 필요: 공식 대응표 없음].
- 자체 레벨을 만들면 각 레벨에 **외부 지표 범위 + 어휘 수 + 문장 패턴 + 그림 의존도**를 함께 적어 둔다 (E11).

### 레벨 테스트

- 형태: 적응형 어휘·문장 이해 문항, 짧은 지문 이해, 소리 내어 읽기(유창성) 중 조합.
- 결과는 **시작 레벨 추천**이며 확정값이 아니다. 첫 2~3권의 이해 퀴즈 결과로 자동 보정한다 [가정].
- 너무 높게 배치하면 좌절, 너무 낮으면 지루함. 오배치 지표(첫 주 레벨 조정률)를 둔다.
- 유아는 화면 문항보다 보호자 관찰 질문을 섞는다 ([[domain/유아초등학습UX]]).

### 전자책 라이브러리와 출판사 라이선스

- 계약 단위 [가정: 일반 실무 유형]: 타이틀별 영구 이용, 기간 구독(카탈로그 전체), 이용 횟수·동시 열람 제한, 매출 배분형.
- 계약서 확인 항목: 지역(국내·해외), 채널(가정 B2C·학원 B2B 모두인지), 기기 수, 오프라인 저장, 오디오·TTS 생성 허용, 퀴즈·워크시트 2차 제작 허용, 계약 종료 시 이미 본 책·기록 처리, AI 학습 이용 여부 ([[domain/강사계약과콘텐츠권리]]).
- 출판사 원본 오디오가 없을 때 TTS로 낭독을 만들면 2차적 이용이 될 수 있어 별도 허락이 필요하다 [확인 필요: 계약별].
- 권리 만료일을 CMS에서 관리하고 만료 30일 전 알림 ([[domain/콘텐츠CMSIA]]).

### 오디오·따라 읽기 (read-along)

- 단어 하이라이트 동기화(타임스탬프), 속도 조절, 단어 탭 시 발음·뜻.
- 녹음해서 다시 듣기, 유창성 측정(분당 정확 단어 수 등)은 음성 데이터 처리이므로 [[domain/음성AI스피킹학습]]의 동의·보존 규칙을 따른다.

### 이해 퀴즈

- 책별 3~10문항, 사실 확인 + 추론 + 어휘. 문항은 출판사 허락 범위에서 자체 제작.
- 통과 기준(예: 정답률) 미달 시 다시 읽기 제안, 연속 미달 시 레벨 하향 제안 [가정].
- 퀴즈를 "포인트 획득 수단"으로만 만들면 훑어 읽고 찍는 행동이 생긴다 ([[domain/동기설계]]).

### 독서 기록과 보상 (해로운 게이미피케이션 피하기)

- 권장: 읽은 권수·분량, 레벨 성장 그래프, 좋아한 책 기록, 다음 책 추천.
- 피할 것: 친구·반 공개 랭킹, 끊기면 사라지는 스트릭, 쉬운 책 반복으로 포인트 쌓기, 보상 상점 의존. 레벨이 낮은 아동의 낙인 위험이 크다 ([[domain/수강생대시보드]]).
- 흥미 기반 선택권: F&P 저자들의 권고처럼 레벨 밖 책도 고를 수 있게 둔다.

## 핵심 비즈니스 로직

- **이중 채널**: 학원 B2B2C(원장 계약, 반 단위 계정, 강사용 관리 화면)와 가정 B2C(보호자 결제, 구독). 같은 콘텐츠라도 라이선스 조건·가격·리포트 수신자가 다르다 ([[domain/세그먼트별의사결정구조]]).
- 학원 채널: 원생 수 기준 과금, 학원 전용 리포트, 원생 퇴원 시 계정·기록 이관 규칙.
- 가정 채널: 형제 계정, 월·연 구독, 체험 후 전환. 환불은 [[domain/환불정책]].
- 원가: 출판사 라이선스(고정 + 변동), 오디오 제작, 퀴즈 제작, 레벨 태깅 인건비.

## 주요 화면·기능

- 학습자: 오늘의 책, 내 레벨 서가, 책 읽기 뷰어(오디오·하이라이트), 퀴즈, 독서 기록.
- 보호자: 주간 리포트(읽은 책, 이해 정답률, 레벨 변화), 알림 설정.
- 학원 강사: 반별 독서 현황, 미독서 학생, 레벨 조정 승인, 상담용 출력 ([[domain/교사대시보드IA]]).

## 지표

| 구분 | 지표 |
|------|------|
| 학습 | 레벨 상승 속도(분포), 퀴즈 정답률, 정기 재측정 결과 |
| 참여 | 주간 독서 일수, 책 완독률, 레벨 밖 자율 선택 비율 |
| 품질 | 레벨 테스트 후 조정률, 퀴즈 문항 오류 신고 |
| 사업 | 채널별 유지율, 학원당 활성 원생, 라이선스 원가율 |

## 규제·리스크

- 만 14세 미만 회원가입·녹음·리포트 발송은 법정대리인 동의가 필요하다 ([[domain/아동개인정보보호]]). 학원 채널에서는 학원과 서비스 제공자 간 위탁 관계를 계약에 적는다 ([[domain/학원프랜차이즈운영]]).
- 앱 마켓 아동 카테고리 정책 ([[domain/유아초등학습UX]]).
- 라이선스 만료로 책이 사라지면 독서 기록·포인트가 깨진다. 기록은 남기고 열람만 막는다.
- 효과 주장("N개월에 Lexile 몇 상승")은 자체 측정 근거 없이 쓰지 않는다 ([[domain/효과크기와증거수준]]).

## 에듀테크 PM 적용

**체크리스트**

- [ ] 자체 레벨 정의표에 외부 지표 범위·근거를 적는다 (E11)
- [ ] 레벨 테스트 보정 규칙과 오배치 지표를 정한다 (E09, E07)
- [ ] 출판사 계약의 채널·오디오·2차 제작·종료 처리 범위를 확인한다 (P02)
- [ ] 랭킹·스트릭 대신 개인 성장 중심 보상을 설계한다 (E08)
- [ ] 학원·가정 채널별 리포트 수신자와 동의를 분리한다 (E12, E13)
- [ ] 환불·구독 해지 규칙을 채널별로 정한다 (P01)

**관련 산출물·유형**: AT07 + AT06. E07, E08, E09, E10, E11, E12, E13, P01, P02, L01, S06, F01~F04(레벨 테스트 정확도, 학부모 알림), N01~N03(유아 신규 앱).

## 흔한 오해

- "Lexile·AR·F&P는 서로 정확히 환산된다" — 측정 방식이 다르고 공식 1:1 대응이 없다.
- "레벨이 높을수록 좋은 책" — 텍스트 난이도는 내용 성숙도·흥미를 반영하지 않는다.
- "포인트가 많을수록 많이 읽는다" — 쉬운 책 반복·찍기 같은 보상 해킹이 생긴다.
