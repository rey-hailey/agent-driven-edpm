# 학습 데이터 프라이버시 (성인 학습자·임직원 중심)

> **법률 자문이 아니다.** 아동·학생(만 14세 미만 동의, 학교 선정 기준, COPPA·FERPA)은 [[domain/아동개인정보보호]]에서 다룬다. 이 페이지는 성인 학습자, 기업교육 임직원, AI 기능에서 생기는 쟁점을 다룬다.

## 핵심 요약

- 학습 기록(진도, 점수, 오답, 질문 내용, 접속 시간, 음성·영상)은 계정과 연결되면 개인정보다. **AI 튜터 대화 로그**에는 학습자가 스스로 쓴 건강·가족·직장 고민 같은 민감한 내용이 섞인다.
- **가명정보**는 통계작성, 과학적 연구, 공익적 기록보존 등을 위해 동의 없이 처리할 수 있다 (개인정보 보호법 제28조의2 제1항, https://casenote.kr/법령/개인정보_보호법/제28조의2). 학습 분석 연구에 쓸 수 있는 통로지만, 재식별 금지·안전조치 의무가 따른다. [verified 2026-10-12]
- **국외 이전**(해외 LLM API 포함)은 원칙적으로 금지되고, 별도 동의, 계약 이행에 필요한 처리위탁·보관으로서 처리방침 공개 등, 인증, 적정성 인정 등 예외 요건을 갖춰야 한다 (제28조의8, 2023.9.15. 시행, https://casenote.kr/법령/개인정보_보호법/제28조의8). [verified 2026-10-12]
- **자동화된 결정**: 완전히 자동화된 시스템(AI 포함)의 결정이 권리·의무에 중대한 영향을 미치면 정보주체는 거부·설명을 요구할 수 있다 (제37조의2, 2024.3.15. 시행, https://www.jipyong.com/newsletter_alert/240329_2/index.html). AI 자동 채점으로 수료·승진이 정해지는 구조가 쟁점. [verified 2026-10-12: 시행일·취지]
- 기업교육에서 **고용주가 임직원 학습 데이터를 어디까지 보는가**는 법적 허용 여부와 별개로 신뢰 문제다. 목적(이수 확인)과 범위(이수 여부·점수만, 대화 내용 제외)를 미리 정해 고지한다.

## 상세

### 어떤 학습 데이터가 개인정보인가

| 데이터 | 개인정보 여부 | 위험 수준 | 메모 |
|--------|---------------|-----------|------|
| 계정·연락처·소속 | 예 | 중 | 기업교육은 사번·부서 포함 |
| 진도·이수·점수 | 예 (계정 연결 시) | 중 | 인사 평가 연계 시 높음 |
| 문항별 응답·오답 | 예 | 중 | 역량 프로파일링 근거 |
| AI 튜터 대화 원문 | 예 | **높음** | 민감정보가 섞일 수 있음 |
| 음성(말하기 연습)·웹캠 영상 | 예 | **높음** | 생체 특징 처리 시 민감정보 쟁점 [확인 필요: 제23조 해석] |
| 집계 통계(과정별 평균 완료율) | 아니오 (재식별 불가 시) | 낮음 | 소집단 셀은 재식별 위험 |

### 목적 제한과 이차 이용

| 이용 목적 | 처리 근거 후보 | 주의 |
|-----------|----------------|------|
| 학습 서비스 제공(진도 저장, 이어보기) | 계약 이행 | 최소 수집 |
| 수료증·환급 과정 증빙 | 계약·법령 [확인 필요: 훈련 규정의 보존 의무] | 보존 기간 명시 |
| 고객사(고용주)에 이수 현황 제공 | 고객사와의 위탁·제공 구조 정리, 학습자 고지 | 대화·오답 상세는 기본 제외 |
| 서비스 개선 분석 | 가명처리 후 통계 (제28조의2) 또는 동의 | 재식별 시도 금지 |
| AI 모델 학습·미세조정 | 별도 동의 또는 가명정보 연구 해당성 검토 [확인 필요] | 옵트아웃 제공, 대화 원문 사용 최소화 |
| 마케팅·맞춤 광고 | 별도 동의 | 학습 성적 기반 광고는 신뢰 훼손 |

### 기업교육: 고용주 접근 범위 설계

- **기본값**: 고객사 관리자에게 이수 여부, 진도율, 최종 점수, 수료일만 제공. 문항별 응답, AI 대화, 체류 시간 상세는 제공하지 않는다.
- **집계 리포트**: 부서별 리포트는 최소 인원(예: 5명 미만 셀 숨김)을 둔다 [가정: 임계값은 조직 합의].
- **인사 평가 연계**: 학습 데이터를 평가·승진에 쓰면 근로자 측 협의, 고지, 자동화된 결정 대응이 필요할 수 있다 [확인 필요: 근로기준법·근로자참여법 관련].
- 학습자에게 "회사가 볼 수 있는 항목" 화면을 보여 준다.

### 보존과 파기

- 보존 기간을 데이터 종류별로 정한다: 계정(탈퇴 시까지), 수료 기록(증빙 기간), AI 대화 원문(짧게, 예: 30~90일 후 요약·삭제 [가정]), 감독 영상(분쟁 처리 기간).
- 고객사 계약 종료 시 데이터 반환·파기 방법과 기한을 계약에 쓴다.

### 분석·프로파일링·이탈 예측

- 이탈 예측·추천은 프로파일링이다. 목적 고지, 개입 방식(넛지인지 불이익인지) 구분이 필요하다 ([[domain/학습이탈예측]]).
- 예측 점수를 고용주에게 보내 "이 직원은 이탈 위험"으로 쓰지 않는다. 학습자 본인 지원에만 쓴다.

### LLM 업체와 국외 처리

| 확인 항목 | 질문 |
|-----------|------|
| 입력 데이터 학습 사용 | API 입력이 업체 모델 학습에 쓰이는가, 기본값은? |
| 보존 기간 | 남용 모니터링 목적 보존 기간과 삭제 옵션 |
| 처리 지역 | 국내·해외 리전, 하위 처리자 목록 |
| 국외 이전 근거 | 제28조의8 어느 요건으로 처리하는가 (처리방침 공개 항목: 이전 국가, 시기·방법, 받는 자, 목적, 항목, 보유기간, 거부 방법) [확인 필요: 제2항 항목 대조] |
| 가명처리 | 이름·사번·이메일을 보내기 전에 치환하는가 |

### 학습자 권리

- 한국: 열람(제35조), 정정·삭제(제36조), 처리정지(제37조), 자동화된 결정 거부·설명 요구(제37조의2) [확인 필요: 제35~37조 조문 대조]. AI 대화 기록 열람·삭제 기능을 설계한다.
- EU(GDPR): 접근(제15조), 삭제(제17조), 이동(제20조), 반대(제21조), 자동화된 개별 결정(제22조), 고위험 처리 시 영향평가(제35조), 국외 이전(제5장) (https://gdpr-info.eu) [확인 필요: 서비스별 적용 대상]. 고용 맥락은 회원국 법이 추가 규율할 수 있다 (제88조) [확인 필요].

| 유형 | 핵심 쟁점 |

| AT02 기업교육 | 고용주 접근 범위, HRIS 연동, 환급 과정 증빙 보존 |
| AT03 부트캠프 | 채용 연계 시 기업에 성적·포트폴리오 제공 동의 |
| AT08 고등·평생교육 | 학적·성적의 교육기관 규정 [확인 필요] |

## 에듀테크 PM 적용

**체크리스트 (E13, A04, A09와 연결)**

- [ ] 데이터 목록에 위험 수준과 처리 목적을 붙인다 (E12 → E13)
- [ ] 고용주(고객사) 제공 항목 기본값을 정하고 학습자에게 보여 준다
- [ ] AI 대화 원문 보존 기간과 요약·삭제 규칙을 정한다 (E14 5장, A04)
- [ ] LLM 업체 5개 확인 항목을 E13 (a)에 기록하고 국외 이전 근거를 정한다
- [ ] 모델 학습 이용은 별도 동의 또는 가명정보 해당성을 법무 검토하고 옵트아웃을 둔다
- [ ] 이탈 예측 점수의 사용처를 학습자 지원으로 제한한다 (A09)
- [ ] 열람·삭제·처리정지 요청 처리 흐름을 P05 CS 정책에 넣는다
- [ ] 자동 채점·자동 판정이 수료·인사에 영향을 주면 사람 검토와 설명 절차를 둔다 (L04, E14)
- [ ] 글로벌 서비스면 GDPR 영향평가 필요 여부를 검토한다

**관련 산출물**: E13(주), E12, E14, A00(위험 칸), A04, A07(음성 데이터), A09, P03(감독 데이터), P05.

## 흔한 오해

- "성인이니 동의 하나면 끝" — 목적별 근거, 국외 이전, 이차 이용이 따로 걸린다.
- "회사가 돈을 냈으니 회사가 다 볼 수 있다" — 제공 구조와 고지가 필요하고, 신뢰를 잃으면 학습 참여가 떨어진다.
- "가명처리하면 AI 학습에 마음대로 써도 된다" — 목적 요건(통계·연구 등)과 안전조치, 재식별 금지가 따른다.
- "API는 학습에 안 쓰니 국외 이전이 아니다" — 해외 서버로 전송·보관되면 국외 이전 요건을 검토해야 한다.
