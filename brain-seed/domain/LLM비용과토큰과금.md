# LLM 비용과 토큰 과금

> A12 AI비용·과금설계서, S03 가격·견적서, S06 수익모델설계서를 쓸 때 참고. AI 기능은 **사용할수록 원가가 늘어나는** 기능이다. 학습자당 월 원가를 모르고 요금제를 정하면 많이 쓰는 고객이 적자를 만든다.

## 핵심 요약

- 클라우드 LLM은 **입력 토큰과 출력 토큰을 따로** 과금하며 출력 단가가 더 비싸다. 반복되는 앞부분(시스템 프롬프트·교재 근거)은 **캐시 읽기** 단가가, 실시간이 아닌 작업은 **배치** 할인이 적용된다.
- 원가 공식: 요청당 원가 = Σ(토큰 종류별 토큰 수 × 단가). 학습자당 월 원가 = 요청당 원가 × 학습자당 월 요청 수. 여기에 검색·임베딩·가드레일 호출·재시도 비용을 더한다.
- 절감 수단: **FAQ·규칙으로 앞 단계 해결**, **작은 모델로 라우팅**, **캐싱**, **문맥 축소**, **배치**, **출력 길이 제한**.
- 로컬 GPU 원가 = **시간당 GPU 비용 ÷ 시간당 실제 처리 토큰 수**. 가동률이 낮으면 단가가 급격히 오른다.
- 사용자 과금: **포함량(요금제에 월 N회)**, **크레딧**, **등급별 요금제**, **공정 사용 정책**. 원가 상위 사용자 분포를 보고 상한을 정한다.

## 상세

### 단가 구조 (공개 예: Claude API, 2026-10-12 확인)

| 모델 | 입력 (100만 토큰당) | 출력 | 캐시 읽기 | 배치 입력/출력 |
|------|-----:|-----:|-----:|-----:|
| Claude Opus 5.5 | $4 | $20 | $0.20 | $2 / $10 |
| Claude Sonnet 5.5 | $2 | $10 | $0.10 | $1 / $5 |
| Claude Haiku 5.5 (프롬프트 10만 토큰 이하) | $0.10 | $0.50 | $0.01 | $0.05 / $0.25 |

- 출처: https://platform.claude.com/docs/en/about-claude/pricing (verified: 2026-10-12). 배치 API는 입력·출력 모두 50% 할인, 5분 캐시 쓰기는 기본 입력가의 1.25배, Opus 5.5·Sonnet 5.5의 캐시 읽기는 기본 입력가의 0.05배로 명시. 미국 내 추론 지정(`inference_geo`) 시 1.1배 등 추가 배수가 있다. Haiku 5.5는 10만 토큰 초과 프롬프트에 더 높은 단가가 적용된다.
- **가격은 바뀐다**. A12에는 확인 날짜와 출처를 함께 적고, `automation/scripts/model_prices.json`을 갱신해 `ai_cost.py`로 다시 계산한다. 다른 공급사 단가는 각 공식 가격 페이지에서 확인한다 [확인 필요].
- 같은 한국어 문장도 모델(토크나이저)마다 토큰 수가 다르다. 위 문서는 Claude 4.7 이후 모델의 새 토크나이저가 같은 텍스트에 약 30% 더 많은 토큰을 낸다고 밝힌다. **자사 실제 요청 표본으로 토큰 수를 측정**한다.

### 원가 공식

```text
요청당 원가 = (캐시 안 된 입력 토큰 × 입력 단가)
            + (캐시 읽기 토큰 × 캐시 읽기 단가)
            + (캐시 쓰기 토큰 × 캐시 쓰기 단가)
            + (출력 토큰 × 출력 단가)
            + 검색·임베딩·가드레일 호출 원가

학습자당 월 원가 = Σ 기능별 (요청당 원가 × 월 요청 수) × (1 + 재시도·오류 비율)
월 총 AI 원가 = 학습자당 월 원가 × 활성 학습자 수 (사용량 분포가 치우치면 분위수별로 계산)
```

**계산 예 [가정: 요청 형태는 가상, 단가는 위 표]**: Sonnet 5.5, 요청당 입력 2,000토큰(이 중 1,500토큰은 캐시 읽기) + 출력 300토큰.
- 입력 500 × $2/1M = $0.0010, 캐시 읽기 1,500 × $0.10/1M = $0.00015, 출력 300 × $10/1M = $0.0030 → **요청당 약 $0.0042** (캐시 쓰기 비용 제외).
- 학습자가 월 60회 쓰면 약 $0.25. 같은 요청을 Haiku 5.5로 보내면 입력 2,000 × $0.10/1M + 출력 300 × $0.50/1M ≈ $0.00035 (캐시 미적용 기준).
- 대화형 튜터는 턴이 쌓일수록 이전 대화가 입력에 다시 들어가 요청당 입력 토큰이 커진다. 대화 요약·턴 상한을 설계한다.

### 절감 수단

| 수단 | 효과 | 주의 |
|------|------|------|
| FAQ·규칙 앞 단계 해결 (M1~M3) | LLM 호출 자체 감소 | 해결률 측정 ([[domain/AI방식스펙트럼]]) |
| 모델 라우팅 | 쉬운 요청은 작은 모델 | 품질 저하 감시 ([[domain/모델선택과라우팅]]) |
| 프롬프트 캐싱 | 고정 앞부분 단가 인하 | 고정 부분을 앞에, 변하는 부분을 뒤에 배치 |
| 문맥 축소 | 검색 근거 수·대화 이력 축소 | 근거 충실도 확인 ([[domain/RAG설계]]) |
| 배치 처리 | 50% 할인(위 공급사 기준) | 실시간 아님: 리포트·문항 초안·야간 피드백 |
| 출력 길이 제한 | 출력 토큰 감소 | 학습에 필요한 설명까지 자르지 않기 |
| 응답 재사용 | 같은 질문 결과 캐시 | 학습자 맥락이 다르면 재사용 불가 |

### 로컬 GPU 원가 모델

```text
출력 100만 토큰당 원가 = 시간당 GPU 비용 ÷ (초당 처리 토큰 × 3,600 × 가동률) × 1,000,000
```

- 예 [가정: 모든 수치 가상]: 시간당 $2, 동시 처리 합계 초당 1,000토큰, 가동률 50% → 시간당 180만 토큰 → 100만 토큰당 약 $1.1. 가동률이 10%면 약 $5.6.
- 여기에 운영 인력, 예비 장비, 전력·상면(온프레미스), 모델 갱신 작업을 더한다 ([[domain/로컬LLM과온프레미스]]). 학교 수업 시간대에 사용이 몰리고 방학에 줄어 **가동률이 계절적**이다 ([[domain/학사일정]]).

### 사용자 과금 설계

| 모델 | 설명 | 적합 |
|------|------|------|
| 요금제 포함 | 월 N회·N분 포함, 초과 시 제한 또는 추가 구매 | 소비자 구독 |
| 크레딧 | 기능별 차감 (튜터 대화 1, 리포트 5) | 기능 원가 차이가 클 때 |
| 등급별 | 기본(작은 모델·횟수 제한) / 프리미엄 | B2C |
| 좌석·기관 라이선스 + 공정 사용 | 학생당 연 단가, 기관 전체 월 상한 | B2S·B2G ([[domain/세그먼트별의사결정구조]]) |

- **마진 보호**: 원가 상위 5%·1% 사용자의 원가를 따로 계산하고 [가정: 분위수 선택], 상한·속도 제한(P09)·작은 모델 전환 규칙을 둔다. 견적(S03)에는 사용량 가정을 명시한다.
- 아동 대상 서비스는 "AI 크레딧 구매" 같은 과금 유도가 보호자 동의·앱 마켓 정책과 충돌하지 않는지 확인한다 ([[domain/유아초등학습UX]]).

## 에듀테크 맥락

- **K-12 학교 납품**: 학생 수 × 연 단가 고정 계약이 많아 사용량이 늘수록 마진이 줄어든다. 계약에 공정 사용 범위를 넣는다 [가정].
- **학교망·시간대**: 수업 시간에 동시 요청이 몰려 속도 제한·대기열이 필요하다.
- **교사 기능**: 교사용 자료 생성은 요청 수는 적고 토큰은 많다. 기능별로 따로 계산한다.
- **학습 효과**: 원가 절감이 교육적 품질(힌트 사다리, 근거 인용)을 깎지 않는지 E14 평가로 확인한다.

## 에듀테크 PM 적용

**체크리스트 (A12)**

- [ ] 기능별 요청당 토큰(입력·캐시·출력)을 실제 표본으로 측정하고 단가 확인 날짜를 적는다
- [ ] 학습자당 월 원가를 평균과 상위 분위수로 계산한다 (`ai_cost.py`)
- [ ] 절감 수단별 예상 효과와 품질 영향 확인 방법을 적는다
- [ ] 과금 모델·포함량·상한을 S03·S06과 맞추고, 속도 제한·예산 알림을 P09에 넣는다
- [ ] 로컬 대안이 있으면 GPU 원가 모델로 손익분기 사용량을 계산한다

**관련 산출물**: A12(주), A11, S03, S06, P09, A13.

## 흔한 오해

- "토큰 단가가 싸니 무시해도 된다" — 대화 이력 누적·재시도·상위 사용자가 원가를 키운다.
- "로컬이 항상 싸다" — 가동률이 낮으면 더 비싸다.
- "무제한 요금제가 전환에 유리하다" — 상위 사용자가 마진을 잠식한다.
