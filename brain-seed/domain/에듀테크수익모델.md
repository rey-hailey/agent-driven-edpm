# 에듀테크 수익 모델

## 핵심 요약

- 에듀테크의 수익 모델은 **누가 돈을 내는가(학습자·보호자·기업·기관·정부)** 와 **무엇에 대해 내는가(콘텐츠·접근 기간·좌석·성과·서비스)** 의 조합이다. 사용자·결정자·결제자가 다르면 모델도 달라진다 ([[domain/세그먼트별의사결정구조]]).
- 교육은 **완료와 재구매가 별개**다. 수료율이 높아도 재구매·갱신이 낮을 수 있고, 반대도 있다. 단위경제는 갱신(renewal)과 코호트 잔존으로 본다 [가정].
- 정부 지원 훈련은 수요가 안정적이지만 **규정 준수와 수료 인원**에 매출이 묶인다 (원격훈련 지원금은 훈련수료인원 기준 산정, https://www.hrdkorea.or.kr/1/1/2/2) [verified 2026-10-12].
- 미성년 대상 서비스의 광고 모델은 개인정보·맞춤형 광고 규제와 보호자 신뢰 문제로 신중해야 한다 ([[domain/아동개인정보보호]]).

## 상세

### 모델 목록

| 모델 | 결제자 | 매출 단위 | 핵심 위험 |
|------|--------|-----------|-----------|
| B2C 단과 판매 | 학습자 | 과정당 | 재구매 유도, 할인 의존 ([[domain/과정가격전략]]) |
| 구독 | 학습자·보호자 | 월·연 | 이탈, 카탈로그 깊이 |
| 멤버십 | 학습자 | 기간 + 혜택(라이브·커뮤니티) | 혜택 운영 비용 |
| 프리미엄(freemium) | 일부 학습자 | 유료 기능·콘텐츠 | 무료 사용자 비용, 낮은 전환 |
| 마켓플레이스 수수료 | 학습자(플랫폼이 강사와 배분) | 판매 수수료 | 강사 이탈, 유입 채널별 배분 ([[domain/강사정산모델]]) |
| B2B 좌석·라이선스 | 기업 | 좌석·연간 계약 | 활성 좌석률, 갱신 |
| B2B 엔터프라이즈 | 기업 | 플랫폼 + 맞춤 제작 + 연동 | 맞춤 요구로 제품 분산 |
| B2G 조달 | 교육청·공공기관 | 사업 계약 | 예산 주기, 입찰, 요구사항 변동 ([[domain/학사일정]]) |
| B2B2C | 학원·기관 → 학습자 | 기관당 또는 학생당 | 기관 영업, 최종 사용자와 거리 |
| 정부 지원 훈련 | 고용보험·국비 + 일부 자부담 | 수료 인원·훈련시간 | 규정 변경, 부정 수급 위험 ([[domain/학습진도관리]]) |
| 자격·인증 시험 응시료 | 학습자·기업 | 응시 건당 | 공신력 확보, 시험 보안 |
| 튜터링·코칭 업셀 | 학습자 | 회당·패키지 | 인력 비용, 품질 편차 |
| 콘텐츠 라이선싱 | 다른 플랫폼·기관 | 라이선스료·로열티 | 채널 갈등, 권리 범위 (P02) |
| 광고 | 광고주 | 노출·클릭 | 학습 방해, 미성년 규제 |

### 단위경제 (unit economics)

| 지표 | 정의 | 교육 서비스에서 볼 점 |
|------|------|------------------------|
| CAC | 신규 유료 고객 1명 획득 비용 | 시즌(학기·시험) 따라 크게 변동 [가정] |
| LTV | 고객 생애 순이익(또는 매출 × 이익률) | 학습 목표 달성 후 이탈(졸업 이탈)을 반영 |
| LTV/CAC | 회수 배수 | 기준값은 업계 통념일 뿐, 회사 실적으로 정한다 [가정] |
| 회수 기간(payback) | CAC를 회수하는 데 걸리는 개월 수 | 연간 선결제 비중이 크면 짧아짐 |
| 코호트 잔존 | 가입 월별 N개월 후 유지율 | 방학·시험 후 급락 패턴 확인 |
| 순매출 유지율(B2B, NRR) | 기존 고객의 갱신·확장 후 매출 비율 | 좌석 확장 vs 축소 |
| 수료율 vs 갱신율 | 학습 성과 지표와 사업 지표 | 둘을 섞지 않는다 ([[domain/학습분석지표]]) |
| 공헌이익 | 매출 − 변동비(강사 배분, PG·앱 수수료, 채점·튜터 인력, 인프라) | 튜터링·채점이 많은 모델은 마진이 낮음 |

- 앱 결제 수수료가 순매출을 크게 줄일 수 있다. 예: Udemy는 강사 배분 기준에서 Apple·Google 30% 수수료 등을 뺀다고 설명 (https://support.udemy.com/hc/en-us/articles/229605008) [검색 결과 요약 기준].
- AI 기능은 사용량 비례 원가(모델 호출)가 생기므로 구독 가격에 사용량 상한이나 원가 모니터링이 필요하다 [가정].

### 모델 선택 질문

1. 결제자는 누구이며, 학습 성과를 결제자가 직접 확인할 수 있나?
2. 학습 목표가 끝나는가(시험 합격) 지속되는가(어학·직무 역량)? → 끝나면 단과·기간제, 지속되면 구독.
3. 변동비의 대부분이 사람(강사·튜터·채점)인가? → 규모의 경제가 약하다.
4. 정부·기관 의존도가 몇 %인가? 규정 변경 시 버틸 수 있나?

## 서비스 유형별 차이

| 유형 | 주된 모델 | 보조 모델 |
|------|-----------|-----------|
| AT01 이러닝 마켓플레이스 | 단과 판매 + 마켓플레이스 수수료 | 구독, B2B 카탈로그 라이선스 |
| AT02 기업교육 LMS | B2B 좌석·라이선스, 정부 지원 훈련 | 맞춤 제작, 콘텐츠 라이선싱 |
| AT03 부트캠프 | 고가 코호트, 국비 지원 | 기업 위탁 교육, 채용 연계 수수료 [가정] |
| AT04 라이브·튜터링 | 회당·패키지 | 구독형 정기 수업 |
| AT05 K-12 코스웨어 | B2G·B2S 기관 구매 | 가정용 B2C 버전 |
| AT06 학원·사교육 | B2B2C(학원 이용료) | 학부모 직접 결제 |
| AT07 소비자 학습앱 | 프리미엄 + 구독 | 가족 플랜, 제한적 광고 |
| AT09 자격증·시험대비 | 기간제 패스 | 모의고사 단건, 응시료 |

## 에듀테크 PM 적용

- [ ] 사용자·결정자·결제자를 구분하고 모델을 S06에 썼다
- [ ] 변동비 항목을 모두 나열하고 공헌이익을 계산했다 (S06)
- [ ] 단위경제 지표와 측정 방법을 E07 사업 지표에 넣었다
- [ ] 학습 성과 지표와 매출 지표를 분리했다 (E07, E19)
- [ ] 정부 지원 과정 비중과 규정 변경 위험을 M03 위험대장에 올렸다
- [ ] 미성년 대상 광고·결제 모델은 E13 검토를 받았다
- [ ] 가격(S03)·정산(S07)·환불(P01)이 같은 매출 정의를 쓰는지 확인했다

## 흔한 오해

- "구독이 가장 좋은 모델" — 학습 목표가 끝나는 상품(시험 대비)은 구독 이탈이 구조적으로 크다 [가정].
- "수료율이 높으면 갱신도 높다" — 별개 지표다. 각각 측정한다.
- "B2B는 한 번 팔면 안정적" — 활성 사용률이 낮으면 갱신에서 좌석이 줄어든다.
- "광고로 무료화하면 된다" — 학습 방해와 미성년 규제 비용을 함께 계산해야 한다.
