# 블룸 분류체계 (개정판)

## 핵심 요약

- 1956년 Bloom 등이 만든 교육목표 분류체계를 Anderson & Krathwohl(2001)이 개정했다. 개정판은 **지식 차원**과 **인지 과정 차원**의 2차원 표로 구성된다 (Krathwohl, 2002, https://doi.org/10.1207/s15430421tip4104_2).
- 인지 과정 6단계: 기억하다 → 이해하다 → 적용하다 → 분석하다 → 평가하다 → 창안하다 (명사형에서 동사형으로 바뀌고, 최상위가 '종합'에서 '창안'으로 바뀜).
- PM에게는 학습 목표·문항·AI 생성 문제의 난이도와 인지 수준을 일관되게 태깅하는 공통 언어다.

## 상세

### 2차원 분류표

| 지식 차원 \ 인지 과정 | 기억 | 이해 | 적용 | 분석 | 평가 | 창안 |
|---|---|---|---|---|---|---|
| 사실적 지식 (용어, 세부 사실) | | | | | | |
| 개념적 지식 (분류, 원리, 모형) | | | | | | |
| 절차적 지식 (기능, 기법, 방법) | | | | | | |
| 메타인지 지식 (전략, 자기 인식) | | | | | | |

출처: Krathwohl (2002).

### 원판 대비 주요 변화 (Krathwohl, 2002)

- 범주 이름을 동사형으로 바꿨다 (예: Knowledge → Remember).
- '평가'와 '종합'의 순서를 바꾸고 '종합'을 '창안(Create)'으로 바꿨다.
- 지식을 별도 차원으로 분리하고 메타인지 지식을 추가했다.

### 목표 진술 예시 (중학 수학)

| 인지 과정 | 예시 목표 |
|-----------|-----------|
| 기억 | 일차방정식의 정의를 말할 수 있다 |
| 적용 | 일차방정식을 풀 수 있다 |
| 분석 | 문장제에서 미지수와 등식 관계를 찾아낼 수 있다 |
| 평가 | 두 풀이 중 오류가 있는 풀이를 판단하고 근거를 댈 수 있다 |
| 창안 | 주어진 답을 갖는 문장제를 만들 수 있다 |

## 에듀테크 PM 적용

- [ ] 문항·콘텐츠 메타데이터에 `cognitive_level`(6단계)과 `knowledge_type`(4종) 필드를 둔다 (E11, E12)
- [ ] 문항은행의 인지 수준 분포를 점검한다. 자동 생성·객관식 위주 제품은 '기억·이해'에 쏠리기 쉽다 [가정]
- [ ] AI 문제 생성 프롬프트에 목표 인지 수준을 명시하고, 생성 결과를 사람이 샘플 검수한다 (E14)
- [ ] 학습 목표 문장은 관찰 가능한 동사로 쓴다 ("이해한다" 대신 "설명할 수 있다")
- 인지 수준 태그는 난이도와 같지 않다. 난이도는 응답 데이터(정답률, IRT 모수)로 따로 측정한다 ([[domain/학습분석지표]]).

## 흔한 오해

- "엄격한 위계라 아래 단계를 다 끝내야 위로 간다" — 개정판은 누적 위계 가정을 완화했고, 과정들은 겹칠 수 있다 (Krathwohl, 2002).
- "기억 수준은 가치가 낮다" — 상위 사고에는 기초 지식이 필요하다. 인출연습 대상의 상당수가 사실·개념 지식이다.
- "블룸 단계 = 문항 난이도" — 높은 인지 수준 문항도 쉬울 수 있고, 기억 문항도 어려울 수 있다.
