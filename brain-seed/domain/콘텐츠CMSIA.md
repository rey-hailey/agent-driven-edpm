# 콘텐츠 CMS IA (저장소·메타데이터·검수·배포)

## 핵심 요약

- 학습 콘텐츠 CMS는 "파일 보관함"이 아니라 **메타데이터 + 버전 + 권리 + 배포 상태**를 관리하는 시스템이다. 검색·재사용·개정·만료 대응이 모두 메타데이터 품질에 달려 있다.
- 최소 단위를 정한다: 자산(영상·자막·문서·이미지) → 학습 객체(레슨·문항) → 묶음(과정·단원). 재사용은 학습 객체 단위에서 일어난다 (L01).
- 공개 중인 콘텐츠를 고칠 때 진행 중 학습자의 진도·성적이 깨지지 않도록 버전을 분리한다. "수정 = 덮어쓰기"는 가장 흔한 사고 원인이다 [가정].
- 권리(저작권·초상권·라이선스 만료) 정보를 자산에 붙여 두지 않으면 만료 콘텐츠가 계속 판매된다 ([[domain/교육저작권]], P02).

## 상세

### IA 트리

```text
콘텐츠 CMS
├─ 홈: 내 작업(검수 대기, 반려, 만료 임박 권리, 처리 실패)
├─ 저장소
│  ├─ 과정·단원 트리
│  ├─ 학습 객체 목록(레슨, 활동, 문항)
│  ├─ 자산 라이브러리(영상, 자막, 문서, 이미지, 오디오)
│  └─ 문항은행(문항, 지문 세트, 해설)
├─ 메타데이터·분류체계
│  ├─ 분류 트리(주제, 직무, 교과·성취기준, 난이도, 블룸 수준)
│  └─ 필수 필드·허용값 관리
├─ 워크플로
│  ├─ 검수 대기함(역할별: 내용 검수, 편집, 접근성, 법무)
│  └─ 버전 이력·비교
├─ 가져오기·내보내기
│  ├─ SCORM 1.2/2004, cmi5 패키지 가져오기
│  ├─ QTI 문항 가져오기·내보내기
│  └─ 대량 메타데이터 CSV
├─ 현지화: 언어별 버전, 자막·번역 상태
├─ 배포: 공개 예약, 채널(앱, B2B 카탈로그, 외부 LMS), 지역 제한
├─ 권리 관리: 출처, 라이선스, 만료일, 사용 범위
└─ 감사 로그
```

### 주요 화면과 컴포넌트

| 화면 | 핵심 컴포넌트 | 설계 포인트 |
|------|---------------|-------------|
| 저장소 목록 | 검색, 패싯 필터(유형·상태·분류·언어·권리 만료), 일괄 작업 | 상태 배지(초안·검수 중·승인·공개·보관). 사용처(어느 과정에 쓰였나) 컬럼 |
| 학습 객체 상세 | 미리보기, 메타데이터 패널, 연결 자산, 사용처, 버전 이력 | 사용처가 여러 곳이면 수정 시 영향 범위 경고 |
| 메타데이터 편집 | 필수 필드 표시, 분류 선택기, 성취기준 검색 ([[domain/교육과정지식그래프]]) | 자유 입력 태그보다 통제된 어휘. 누락 시 검수 제출 차단 |
| 자산 라이브러리 | 업로드, 처리 상태, 자막 트랙(언어별 WebVTT), 썸네일 | 자막 없는 영상은 공개 차단 옵션 ([[domain/접근성]] WCAG 1.2.2) |
| 문항은행 | 문항 유형, 정답·해설, 난이도, 사용 횟수, 노출 통제 | 시험용 문항은 노출 횟수 관리, 접근 권한 분리 (L04, P03) |
| 검수 워크플로 | 단계별 담당자, 체크리스트, 코멘트(위치 지정), 승인·반려 | 단계 예: 내용 검수 → 편집 → 접근성 → 권리 확인 → 승인 (P04) |
| 버전 비교 | 두 버전 차이, 변경 사유, 적용 범위(신규 수강생만/전체) | 메이저(구조 변경)·마이너(오탈자) 구분 |
| 패키지 가져오기 | 업로드, manifest 검증, 추적 항목(완료·점수) 미리보기, 테스트 실행 | SCORM 버전별 완료·점수 보고 방식이 다름을 표시 ([[domain/상호운용표준]]) |
| 현지화 | 원본 대비 번역 상태, 언어별 공개 여부 | 원본 개정 시 번역본 "갱신 필요" 자동 표시 |
| 배포 | 공개 일시 예약, 채널 선택, 지역·기관 제한, 철회 | 예약 공개는 타임존 명시 |
| 권리 관리 | 출처, 라이선스 유형, 만료일, 사용 범위(지역·채널·AI 학습 허용) | 만료 D-30 알림, 만료 시 자동 비공개 규칙 |
| 감사 로그 | 누가·언제·무엇을·어떻게 | 문항은행·성적 영향 변경은 필수 기록 |

### 버전 적용 규칙 예시 [가정]

| 변경 유형 | 진행 중 학습자 | 신규 학습자 |
|-----------|----------------|-------------|
| 오탈자·자막 수정 | 즉시 반영 | 반영 |
| 영상 교체(길이 변경) | 반영하되 해당 레슨 진도 재계산 규칙 필요 (L03) | 반영 |
| 레슨 추가·삭제·순서 변경 | 기존 버전 유지 또는 옵트인 | 새 버전 |
| 채점에 쓰인 문항 정답 수정 | 재채점 정책 결정 필요 (L04) | 새 버전 |

## 서비스 유형별 차이

| 유형 | 차이 |
|------|------|
| AT01 마켓플레이스 | 강사가 직접 올림. 플랫폼 검수와 권리 확인이 중심 ([[domain/강사대시보드IA]]) |
| AT02 기업교육 | 외부 SCORM 패키지 가져오기와 자체 제작 혼합. 고객사별 공개 범위 |
| AT05 K-12 코스웨어 | 성취기준 메타데이터 필수, 교과서·저작물 권리 확인, 교사 검수 |
| AT09 시험대비 | 문항은행 중심. 문항 노출 통제, 개정 시험 범위 반영, 해설 버전 |
| AT10 AI 튜터 | AI 학습·검색 근거로 쓰일 콘텐츠의 사용 허용 범위와 출처 메타데이터 (A07·A08 연계) |

## 상태·예외

| 상황 | 처리 |
|------|------|
| 빈 저장소 | 가져오기 경로(업로드, 패키지, CSV) 안내 |
| 처리 실패(인코딩·패키지 검증) | 실패 사유와 사양 안내, 재시도 |
| 필수 메타데이터 누락 | 검수 제출 차단, 누락 필드 하이라이트 |
| 동시 편집 충돌 | 잠금 또는 충돌 알림과 병합 선택 |
| 권리 만료 | 자동 비공개 + 사용처 목록 + 담당자 알림. 진행 중 학습자 처리 규칙 필요 |
| 권한 없음 | 역할별 단계만 편집 가능, 나머지 읽기 전용 표시 |
| 패키지 추적 불일치 | 미리보기에서 완료·점수 보고 실패 경고 |

## 에듀테크 PM 적용

- [ ] 콘텐츠 계층(자산 → 학습 객체 → 묶음)과 필수 메타데이터 목록이 L01에 정의되었는가
- [ ] 검수 단계와 담당 역할이 L02·P04와 일치하는가
- [ ] 버전 적용 규칙(진행 중/신규 학습자)이 L03 진도·L04 재채점 규칙과 맞물리는가
- [ ] 권리 메타데이터(만료일·사용 범위·AI 학습 허용)가 자산에 붙는가 (P02)
- [ ] 자막 없는 영상, 대체 텍스트 없는 이미지의 공개 차단 여부를 정했는가 (E13 접근성)
- [ ] 가져오는 표준 패키지 버전과 추적 항목이 L05에 정의되었는가
- [ ] 와이어프레임: 저장소 목록, 학습 객체 상세, 검수 대기함, 버전 비교를 P0로 (PC 시나리오)

## 흔한 오해

- "태그는 자유 입력이 편하다" — 동의어·오타로 검색이 무너진다. 통제된 어휘를 쓴다.
- "SCORM이면 어디서나 똑같이 동작한다" — 버전·LMS 구현에 따라 완료·점수 보고가 다르다. 가져오기 테스트가 필요하다.
- "CMS는 내부 도구라 UX가 덜 중요하다" — 검수 병목이 출시 일정을 결정한다 [가정].
