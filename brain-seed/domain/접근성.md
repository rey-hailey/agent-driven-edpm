# 접근성 (WCAG 2.2, KWCAG)

## 핵심 요약

- **WCAG 2.2**는 2023년 10월 5일 W3C 권고안이 되었다. WCAG 2.1에 9개 성공기준을 추가했고, 4.1.1 Parsing을 삭제했다 (https://www.w3.org/TR/WCAG22/). [verified 2026-10-12]
- WCAG 2.2는 ISO/IEC 40500으로도 국제표준화되었다 (2025년 공표로 보고됨, https://www.iso.org/standard/94018.html) [확인 필요: 공표 연월].
- 한국에는 국가표준 **한국형 웹 콘텐츠 접근성 지침(KWCAG)**이 있다. 최신판이 KWCAG 2.2(KS X OT0003 계열, 2022년 개정)라는 것이 업계 통념이나 이번 조사에서 공식 원문을 확인하지 못했다 [확인 필요: 버전, 표준번호, 검사항목 수].
- 학습앱에서 접근성은 장애 학생뿐 아니라 저사양 기기, 소음 환경, 난독·주의 문제를 가진 학습자 모두에게 영향을 준다.

### 한국 법·제도 맥락 [확인 필요]

- 장애인차별금지법은 웹사이트 등 정보 접근에서 정당한 편의 제공을 요구하며, 지능정보화 기본법은 웹·모바일 접근성 보장을 규정한다 [확인 필요: 조문 번호와 민간 사업자 적용 범위].
- 공공기관 조달·웹 접근성 품질인증에서 KWCAG가 기준으로 쓰인다 [확인 필요].
- 교육 분야: 특수교육대상 학생 지원, 공교육 납품 시 접근성 요구가 계약 조건에 포함될 수 있다 [가정].

## 에듀테크 PM 적용 (학습앱 실무 체크리스트)

- [ ] 목표 준거를 정한다: WCAG 2.2 AA (국내 공공 납품이면 KWCAG 최신판 동시 충족)
- [ ] 모든 학습 이미지·도형·그래프에 대체 텍스트. 수식은 MathML 등 스크린리더가 읽을 수 있는 형식 [확인 필요: 대상 보조기기 지원]
- [ ] 영상 강의 자막(한국어), 음성 전용 콘텐츠의 대본 제공
- [ ] 드래그 앤 드롭·그리기·매칭 문항에 키보드·탭 대안 (2.5.7)
- [ ] 시간 제한 퀴즈에 시간 연장·해제 옵션 (2.2.1 Timing Adjustable)
- [ ] 정답·오답을 색만으로 표시하지 않기 (아이콘·텍스트 병행), 명도 대비 확보
- [ ] 보기 버튼·체크박스 터치 영역 확보 (2.5.8), 태블릿 학급 사용 환경 고려
- [ ] 학생 로그인: 그림 비밀번호·QR·학급 코드 등 인지 부담 낮은 인증 (3.3.8)
- [ ] 자동 재생·깜빡임 애니메이션·과도한 보상 효과 끄기 옵션
- [ ] 화면 확대 200%에서 레이아웃 유지, 글자 크기 조절
- [ ] 스크린리더(VoiceOver, TalkBack, 센스리더 등) 실기 테스트를 릴리즈 기준에 포함 (E16)
- [ ] 자동 검사 도구 결과만으로 합격 처리하지 않는다. 자동 도구는 일부 기준만 판정할 수 있다

## 흔한 오해

- "장애 학생이 적어서 우선순위가 낮다" — 공교육 납품 요건이 될 수 있고, 모든 학습자 사용성이 함께 좋아진다.
- "WCAG 2.2가 나오면 2.1은 무효" — W3C는 2.2가 이전 버전을 폐기하지 않는다고 밝힌다. 다만 최신 버전 사용을 권고한다.
- "자막 = 중복 효과로 학습 방해" — 끄고 켤 수 있게 하면 접근성과 [[domain/인지부하이론]]을 함께 충족한다.
