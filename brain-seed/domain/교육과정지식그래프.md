# 교육과정 지식그래프 (2022 개정 국가 교육과정 온톨로지)

## 핵심 요약

- 2022 개정 국가 교육과정의 성취기준을 세부 학습 토픽과 선수 관계로 연결한 공개 데이터셋 세 가지가 있다: 초등 학습지도, 중등 학습지도, 전환기 격차 지도 (모두 DECK 작성, MIT 라이선스) (https://github.com/DECK6).
- 성취기준 원문은 담지 않고 코드, 저장소가 쓴 요약, 공식 고시 문서의 위치(별책·쪽), 해시만 담는다.
- 선수 관계는 **공식 근거 관계(official)** 와 **저장소가 제안한 권장 순서(pedagogical-candidate)** 로 나뉜다. 둘을 섞어 쓰면 안 된다.
- 교육부·국가교육위원회·NCIC의 공식 자료가 아니며, 개별 학습자를 진단하지 않는다고 명시한다.

## 상세

| 데이터셋 | 범위 (2026-09 기준) | 주요 내용 |
|----------|---------------------|-----------|
| 초등 학습지도 (v0.5) | 11개 교과(국어·수학·과학·사회·영어·도덕·실과·통합교과·미술·음악·체육), 학년군 1-2·3-4·5-6 | 성취기준 620, 세부 토픽 1,956(성취기준마다 anchor 1개 + facet), 토픽마다 관찰 가능한 달성 증거·평가 예시·오개념 1~2개, 공식 선수 관계 416, 권장 순서 1,877, 학습 묶음 152(학부모용 요약 포함) |
| 중등 학습지도 (v0.6 candidate) | 중학교 24과목, 고교 일반 231과목, 직업계 528과목 | 중 성취기준 714·토픽 2,160(증거·평가 예시·오개념 포함), 고 일반 성취기준 3,124(토픽은 템플릿 수준), 공식 선수 관계(중 56·고 171·직업계 298), 권장 순서, 고교 과목 간 권장 순서 39, 이수학점 규칙·선택 묶음·예시 경로, 초→중 연결(공식 290·후보 3,699), 중→고 연결 175 |
| 전환기 격차 지도 (v0.1) | 초→중 24과목, 중→고 공통 37과목 | 과목별 격차 점수(연계되지 않은 성취기준 비율·학습량 배율·과목 분화), 신규 도입 성취기준 1,046과 학부모용 쉬운 설명(AI 초안), 연계 근거 317, 국가수준 학업성취도 평가 기초학력 미달 비율 참고 |

**공통 구조**
- 토픽 역할: anchor(성취기준 핵심, 성취기준당 1개) / facet(관점별 세부: 개념·절차·표현·적용·의사소통·탐구·성찰) / auxiliary(다른 토픽으로 접어 보여줌)
- 정렬 관계: assesses(직접 평가) / supports / extends / introduces
- 선수 관계 근거: 내용 체계표의 학년 진행, 성취기준 해설·적용 시 고려 사항에 명시된 연결 (공식) / 코드 순서·분해 순서·영역 연속 (권장 순서)
- 두 학습지도는 같은 핵심 어휘(k12-core 온톨로지)를 공유하고, 중등 저장소의 bridges가 초등 토픽 ID를 그대로 참조해 초→중을 잇는다.

| 시장·영업 | 전환기 연계가 약한 과목 = 브리지 기회, 제안서 정합표 | E04, S02, S05 |

체크리스트:
- [ ] 산출물에 데이터 릴리스(버전)를 기록했다 — 코드 의미가 버전 간 바뀔 수 있다
- [ ] 후보 관계를 "필수 선수"로 표현하지 않았다
- [ ] 평가 예시·오개념·쉬운 설명(초안)을 교과 전문가 검토 후 사용했다
- [ ] 제품·문서에 MIT 저작권 표시와 공식 근거 문서 출처를 남겼다
- [ ] 대상 학년이 2022 개정을 적용받는지 확인했다 ([[domain/2022개정교육과정적용일정]])

## 흔한 오해

- "공식 교육과정 데이터베이스다" → 아니다. 공개 고시 문서를 바탕으로 개인이 만든 데이터이며 공식 승인·해석이 아니다.
- "선수 관계가 모든 성취기준에 있다" → 공식 문서가 관계를 명시한 경우만 공식 관계로 기록된다. 중학교 24과목 중 15과목, 고교 일반 231과목 중 87과목만 공식 선수 관계가 있다. 관계 없음 ≠ 독립.
- "전환기 격차 점수가 높으면 학생들이 어려워한다" → 문서상 연계가 명시되지 않았다는 뜻이다. 성취도와는 별개다.
- "고교 토픽에도 오개념이 있다" → 고교 일반 과목 토픽은 템플릿 수준이며 오개념·평가 예시가 없다.
- "교과서 단원·쪽과 연결돼 있다" → 아니다. 쪽 번호는 교육과정 고시 문서(별책)의 쪽이다.

## 상충하는 근거

- 중등 저장소: LICENSE는 MIT, 온톨로지 메타데이터는 CC0 1.0 표기. 보수적으로 MIT 조건(저작권 표시 유지)을 따른다.
- 초등 저장소 문서별 집계(후보 1,875 vs 1,877, 묶음 153 vs 152)가 다르다. 데이터 manifest 값을 기준으로 한다.
- 전환기 격차 지도는 초등 v0.4·중등 v0.5 기준으로 만들어졌다. 최신 학습지도와 함께 쓸 때 ID 연결을 점검한다 (EdPM `kg_build.py` 연결 점검: 2026-10-12 고정 버전 기준 모두 연결됨).
